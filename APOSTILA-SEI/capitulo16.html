Projeto Integrador — Monitoramento com ESP32

Encerramento do 4º Bimestre • Integração de Wi‑Fi, Servidor Web e Sensor

Neste capítulo final do bimestre, você irá desenvolver um projeto integrador reunindo todos os conceitos estudados: conexão Wi‑Fi, servidor web no ESP32 e leitura de sensores. O objetivo é construir um sistema funcional de monitoramento acessível pelo navegador, simulando aplicações reais de IoT.

Projeto Final ESP32 IoT Servidor Web
EntregaProjeto funcional + explicação do funcionamento + registro simples.
FormatoIndividual ou em dupla, conforme orientação do professor.
Tempo2 aulas para desenvolvimento e ajustes.
AvaliaçãoFuncionamento, organização, clareza e autoria.

1. Descrição do projeto

Desafio
Desafio: criar um sistema com ESP32 que leia um sensor e exiba seus dados em uma página web acessada pelo navegador.

Requisitos mínimos

  • ESP32 conectado ao Wi‑Fi
  • Leitura de pelo menos um sensor
  • Servidor web ativo
  • Página exibindo dados do sensor
  • Funcionamento demonstrável

Sugestões de sensores

  • Potenciômetro
  • LDR (sensor de luz)
  • Sensor de temperatura (simulado)
  • Botão como entrada digital

2. Orientações de desenvolvimento

Guia
  1. Planeje o circuito e o sensor a ser utilizado.
  2. Reaproveite o código-base dos capítulos 14 e 15.
  3. Crie uma página clara e organizada.
  4. Teste o acesso pelo navegador.
  5. Prepare-se para explicar o projeto.
