Projeto Avaliativo do 2º Bimestre

Sistema Automatizado Local com Arduino • Integração dos capítulos 5, 6 e 7

Neste capítulo, você vai desenvolver um projeto avaliativo que integra os conhecimentos do segundo bimestre: estrutura do programa, variáveis e decisões e entradas/saídas digitais e analógicas. A proposta é criar um sistema automatizado local com Arduino, em que o circuito responda a uma entrada do usuário ou do ambiente e controle uma saída de forma perceptível.

Projeto avaliativo 2º bimestre Arduino + Tinkercad Integração teoria + prática
Produto esperadoProtótipo funcional automatizado com entrada, processamento e saída, acompanhado de explicação curta.
Competências mobilizadasAplicar solução em hardware e software e organizar um protótipo funcional com Arduino.
Tempo sugerido1 aula para planejamento e início + 1 aula para conclusão, testes, ajustes e entrega.
FerramentasArduino Uno, LED, botão, potenciômetro, resistor, protoboard, jumpers e Tinkercad.

1. Proposta do projeto

Situação-problema
Desafio: construir um protótipo simples de automação local capaz de receber uma entrada, processar essa informação e controlar uma ou mais saídas sem depender de internet ou aplicativos externos.

Possibilidades de projeto

  • Iluminação automática simples
  • Mini painel de controle com botão e LED
  • Alerta visual com potenciômetro
  • Controle manual de intensidade de LED
  • Mini semáforo com padrões de tempo

O professor pode propor um único tema para toda a turma ou permitir pequenas variações controladas.

O que o projeto deve demonstrar

  • Estrutura básica correta do programa
  • Uso de variável e decisão
  • Pelo menos uma entrada e uma saída
  • Leitura digital ou analógica
  • Saída digital ou PWM
  • Montagem organizada e explicável

2. Revisão dos conhecimentos aplicados

Integração do bimestre

2.1 Estrutura do programa

O projeto precisa usar corretamente a organização mínima do Arduino, com setup() para configurações iniciais e loop() para o comportamento contínuo do sistema.

Essa estrutura é a base do funcionamento do microcontrolador durante toda a execução.

2.2 Variáveis e decisões

O protótipo deve guardar leituras ou estados em variáveis e usar estruturas como if / else para decidir o que fazer com base nessas informações.

É isso que transforma o circuito em um sistema que responde ao que acontece.

2.3 Entradas e saídas

O projeto precisa usar pelo menos uma entrada (como botão ou potenciômetro) e uma saída (como LED), mostrando a relação entre leitura, processamento e ação.

Se houver PWM, o aluno também demonstra compreensão do controle gradual de saída.

3. Roteiro do projeto — modelo-base

Execução orientada

O modelo-base sugerido é um controle local de brilho do LED com potenciômetro. Ele integra leitura analógica, variável, conversão de valor e saída PWM. Também pode ser adaptado para incluir botão e lógica de ativação.

Objetivo do modelo: girar o potenciômetro para controlar o brilho de um LED e, opcionalmente, usar um botão para ativar/desativar essa função.
1

Planeje o circuito

Antes de montar, liste os componentes: Arduino, LED, resistor, potenciômetro, protoboard e jumpers. Se quiser ampliar o desafio, inclua também um botão para habilitar o controle de brilho.

Aplicação pedagógica: planejar evita ligações por tentativa e erro sem entender o circuito.

2

Monte a saída

Conecte o LED em série com o resistor a um pino PWM do Arduino, como o pino 9. Ligue o outro lado ao GND.

Aplicação do conceito: essa será a saída controlada pelo programa.

3

Monte a entrada analógica

Conecte o potenciômetro ao pino A0 e aos pinos de alimentação adequados. Essa entrada permitirá ler um valor variável, em vez de apenas ligado/desligado.

Aplicação do conceito: leitura analógica do ambiente/controle manual.

4

Escreva o código-base

Use o seguinte exemplo como ponto de partida:

int valor = 0;

void setup() {
  pinMode(9, OUTPUT);
}

void loop() {
  valor = analogRead(A0);
  valor = map(valor, 0, 1023, 0, 255);
  analogWrite(9, valor);
}

Aplicação do conceito: a leitura analógica é convertida em um valor adequado para PWM.

5

Teste e ajuste

Inicie a simulação e gire o potenciômetro. Observe o LED variando de brilho. Se não funcionar, confira o pino analógico, o pino PWM e a montagem do LED com resistor.

Dica de depuração: revise primeiro o circuito físico e depois compare os pinos do código.

6

Adicione uma pequena autoria

Após o modelo-base funcionar, faça uma adaptação: use um botão para permitir ou bloquear o brilho, adicione um segundo LED ou crie um comportamento alternativo em determinadas condições.

Entrega valorizada: o aluno que adapta demonstra compreensão mais consistente.

7

Documente o projeto

Escreva um registro curto informando: componentes usados, como o circuito foi montado, o que o sistema faz e quais adaptações foram realizadas.

Entrega mínima: protótipo funcional + explicação clara do funcionamento.

Resultado esperado: um protótipo local automatizado, com entrada e saída integradas e código coerente com o comportamento observado.

4. Sugestões de variações do projeto

Autoria do aluno

Variações simples

  1. Ativação por botão: usar um botão para permitir ou bloquear o controle do brilho.
  2. Dois LEDs: um LED controlado pelo potenciômetro e outro indicando um limite.
  3. Painel de estado: LED principal + LED indicador ligado/desligado.

Variações com mais desafio

  1. Mini semáforo local: usar repetições e tempos diferentes para um padrão automático.
  2. Lógica com limiar: acender outro LED quando a leitura passar de determinado valor.
  3. Dois modos de funcionamento: manual e automático com seleção por botão.

5. Critérios de avaliação sugeridos

Rubrica

Funcionamento

O protótipo executa a função proposta e responde corretamente às entradas.

Código

O programa apresenta estrutura correta, uso coerente de variáveis e lógica apropriada.

Montagem

A organização física do circuito facilita leitura, teste e compreensão da solução.

Explicação

O aluno consegue descrever o circuito, o código e a relação entre entrada e saída.

7. Sugestões de pesquisa complementar

Aprofundamento

  • Explore projetos introdutórios com botão + LED, potenciômetro + LED e semáforo no Tinkercad.

  • Observe como pequenas alterações na lógica do código podem mudar bastante o comportamento de um circuito.
