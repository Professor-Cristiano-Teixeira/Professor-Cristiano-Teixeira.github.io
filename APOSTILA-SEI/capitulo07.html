1. Conceitos fundamentais

Teoria
Ideia central: entradas permitem que o Arduino perceba o ambiente; saídas permitem que ele atue sobre esse ambiente.

Entrada digital

Uma entrada digital só possui dois estados possíveis: ligado ou desligado. No Arduino, isso é representado por HIGH ou LOW. Botões e chaves são exemplos clássicos de entradas digitais.

Saída digital

Uma saída digital também trabalha apenas com dois estados. LEDs, relés e buzzer simples podem ser controlados dessa forma, ligando ou desligando conforme o comando do programa.

Entrada analógica

Entradas analógicas permitem ler valores graduais, não apenas dois estados. Um potenciômetro, por exemplo, pode gerar vários níveis diferentes, lidos no Arduino como valores numéricos.

Saída analógica (PWM)

O Arduino simula saídas analógicas usando PWM. Com isso, é possível controlar o brilho de um LED ou a velocidade de um motor variando o sinal enviado.

Conversão de valores

Leituras analógicas costumam variar de 0 a 1023. Muitas vezes, é necessário converter esse valor para outro intervalo, como 0 a 255, para uso em PWM.

Aplicações práticas

Esses conceitos são usados em controles de iluminação, volume, temperatura, velocidade e muitos outros sistemas automatizados.

2. Prática guiada — Potenciômetro controlando brilho do LED

Passo a passo

Nesta prática, um potenciômetro será usado como entrada analógica para controlar o brilho de um LED usando saída PWM.

Você vai aplicar: analogRead(), analogWrite() e conversão de valores.
  1. Monte o circuito com Arduino, LED + resistor e potenciômetro.
  2. Ligue o potenciômetro ao pino A0 e o LED a um pino PWM (ex: 9).
  3. Use o código abaixo:
int valor = 0;

void setup() {
  pinMode(9, OUTPUT);
}

void loop() {
  valor = analogRead(A0);
  valor = map(valor, 0, 1023, 0, 255);
  analogWrite(9, valor);
}
Resultado esperado: ao girar o potenciômetro, o brilho do LED varia suavemente.
