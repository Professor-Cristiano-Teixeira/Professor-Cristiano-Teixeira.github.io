Introdução ao ESP32 e Comunicação Wi‑Fi

Bimestre 4 • Capítulo 13 • Começando a trabalhar com conectividade

Neste capítulo, você vai iniciar o estudo de uma placa muito importante para projetos de Internet das Coisas: o ESP32. Diferentemente do Arduino Uno usado até aqui, o ESP32 já possui recursos de Wi‑Fi integrados, o que o torna ideal para sistemas conectados. A proposta é entender o que muda em relação ao Arduino, por que o ESP32 é tão usado em IoT e como criar uma primeira comunicação simples via rede.

1. Conceitos fundamentais

Teoria
Ideia central: o ESP32 amplia as possibilidades dos sistemas embarcados porque une controle de hardware com recursos de conectividade, permitindo que o protótipo troque dados em rede.

O que é o ESP32?

O ESP32 é uma placa baseada em microcontrolador muito utilizada em projetos de IoT. Ela é compacta, poderosa para aplicações didáticas e traz recursos integrados de comunicação, como Wi‑Fi e Bluetooth, o que facilita a criação de sistemas conectados.

No contexto do curso, ele será a ponte entre o que o aluno já sabe sobre circuitos e programação e o universo de aplicações em rede.

Diferença entre Arduino Uno e ESP32

O Arduino Uno é excelente para aprender lógica, entradas, saídas e programação embarcada básica. Já o ESP32 amplia esse cenário ao incluir conectividade nativa e mais recursos de processamento. Isso não significa substituir totalmente o Arduino, mas sim avançar para projetos com novas possibilidades.

Em outras palavras, o Arduino ajuda a construir a base; o ESP32 permite explorar aplicações mais próximas da IoT real.

Por que o Wi‑Fi é importante?

Com Wi‑Fi, um dispositivo pode enviar dados, receber comandos e se integrar a páginas web, aplicativos e outros sistemas. Em um projeto de IoT, isso faz toda a diferença, porque o objeto deixa de ser apenas local e passa a interagir em rede.

No curso, o Wi‑Fi será usado de forma introdutória para mostrar essa conexão entre o circuito e o mundo digital.

IoT na prática

Internet das Coisas é justamente a ideia de conectar objetos físicos a sistemas digitais. Quando um sensor envia dados para uma interface web ou um dispositivo recebe comandos remotamente, temos um exemplo típico de IoT.

Ao usar o ESP32, o aluno começa a enxergar que os sistemas embarcados não precisam ficar isolados do restante da rede.

Monitor serial e depuração

Mesmo em projetos conectados, o monitor serial continua sendo um recurso valioso. Ele permite acompanhar mensagens do programa, verificar se a conexão foi iniciada corretamente e observar respostas durante os testes.

Isso ajuda muito na fase inicial de configuração e aprendizagem.

Ambiente de simulação

Para atividades escolares, o simulador Wokwi costuma ser uma ferramenta prática porque permite trabalhar com ESP32 e visualizar o comportamento do projeto sem depender imediatamente do hardware físico. Isso torna os testes mais acessíveis e repetíveis.

Neste capítulo, o simulador ajuda a iniciar a comunicação Wi‑Fi de forma mais segura e simples.

3. Prática guiada — Primeiro acesso com ESP32 e Wi‑Fi

Passo a passo

Nesta prática, você vai simular um projeto com ESP32 que cria uma conexão inicial via Wi‑Fi e mostra mensagens no monitor serial.

Você vai aplicar: configuração básica do ESP32, uso de biblioteca Wi‑Fi, conexão a rede e depuração no monitor serial.
1

Abra o simulador adequado

Abra o Wokwi (ou ambiente equivalente) e crie um novo projeto com uma placa ESP32. Observe a interface, o espaço do código e o monitor serial, pois eles serão usados durante toda a prática.

Objetivo pedagógico: reconhecer que o ambiente muda um pouco em relação ao Arduino Uno, mas a lógica de programação continua familiar.

2

Observe a estrutura do código

Assim como no Arduino, o programa continua usando setup() e loop(). Isso mostra que parte importante do conhecimento anterior permanece útil no novo contexto.

Aplicação do conceito: a base da programação embarcada continua válida, mesmo quando adicionamos conectividade.

3

Insira o código inicial

Use um exemplo introdutório como o seguinte:

// Exemplo introdutório de conexão Wi‑Fi com ESP32
#include <WiFi.h>

const char* ssid = "Wokwi-GUEST";
const char* password = "";

void setup() {
  Serial.begin(115200);
  Serial.println("Conectando ao Wi‑Fi...");

  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  Serial.println("\nWi‑Fi conectado!");
  Serial.print("IP: ");
  Serial.println(WiFi.localIP());
}

void loop() {
  delay(1000);
}

Aplicação do conceito: o código usa uma biblioteca pronta, inicia a conexão e informa o resultado no monitor serial.

4

Entenda o que está acontecendo

#include <WiFi.h> inclui a biblioteca responsável pela comunicação Wi‑Fi. WiFi.begin() inicia a conexão. O bloco while aguarda até que o ESP32 se conecte, e o monitor serial mostra o andamento do processo.

Conclusão parcial: aqui o aluno percebe que a placa agora pode se conectar em rede, abrindo espaço para novos tipos de projeto.

5

Teste no monitor serial

Inicie a simulação e abra o monitor serial. Observe a mensagem de conexão e o IP mostrado após o ESP32 se conectar. Esse momento é importante porque mostra claramente a entrada do projeto no contexto de rede.

Aplicação prática: o monitor serial passa a ser um apoio importante para verificar o estado da comunicação.

6

Faça uma adaptação simples

Depois de validar a conexão, altere alguma mensagem do monitor serial ou acrescente uma linha informando que o sistema está pronto para próximos testes. Isso ajuda a reforçar que o código pode ser adaptado e compreendido pelo aluno.

Resultado esperado: o aluno reconhece a lógica da conexão e se familiariza com o ESP32.

Resultado esperado: compreender que o ESP32 pode se conectar à rede e que essa conectividade será a base dos próximos projetos de IoT.

Projetos web locais

Com a conexão Wi‑Fi funcionando, os próximos capítulos poderão mostrar como o ESP32 cria páginas web simples, recebe comandos do navegador e exibe dados em tempo real.

O aluno começa a enxergar que sensores e atuadores podem fazer parte de sistemas acessíveis pela rede, o que aproxima bastante o conteúdo de aplicações reais de IoT.
