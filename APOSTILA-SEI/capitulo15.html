Leitura de Sensores e Exibição de Dados no Navegador

Bimestre 4 • Capítulo 15 • Monitoramento simples com ESP32

Neste capítulo, você vai evoluir o servidor web criado anteriormente para algo ainda mais próximo da Internet das Coisas real: ler dados de um sensor conectado ao ESP32 e exibir essas informações diretamente no navegador. Esse tipo de aplicação é muito comum em projetos de monitoramento, automação e coleta de dados.

1. Conceitos fundamentais

Teoria
Ideia central: sensores permitem que o sistema embarcado observe o ambiente, e o servidor web possibilita mostrar essas informações de forma acessível.

O que é um sensor?

Um sensor é um componente capaz de detectar alguma grandeza do ambiente, como luz, temperatura ou posição, e convertê-la em um sinal elétrico. Esse sinal pode ser lido pelo microcontrolador e transformado em informação útil.

No ESP32, sensores simples costumam ser lidos por entradas digitais ou analógicas.

Leitura analógica no ESP32

Entradas analógicas permitem ler valores variados, normalmente representados por números. Um exemplo clássico é o potenciômetro, que gera valores diferentes conforme sua posição.

Esses valores podem ser exibidos no monitor serial ou enviados para uma página web.

Atualização de dados no navegador

Uma página web hospedada no ESP32 pode mostrar dados atualizados sempre que for recarregada. Em um primeiro momento, essa atualização manual já é suficiente para entender o fluxo de dados.

Mais adiante, técnicas mais dinâmicas poderão ser exploradas.

Servidor como intermediário

O servidor web no ESP32 funciona como intermediário entre o sensor e o navegador. Ele lê o valor do sensor e monta uma resposta HTML que inclui esse valor.

Assim, o navegador passa a ser uma interface de visualização dos dados coletados.

Aplicações de monitoramento

Esse modelo é muito usado em monitoramento de temperatura, umidade, luminosidade e outros parâmetros. Mesmo com sensores simples, o aluno já consegue simular aplicações reais de IoT.

O importante é compreender o caminho do dado: sensor → ESP32 → página web.

Limitações iniciais

No início, o sistema não precisa ser extremamente preciso ou rápido. O foco está na integração dos elementos e na clareza do funcionamento.

Com o tempo, melhorias podem ser aplicadas ao projeto.

2. Prática guiada — Exibindo valor de um sensor no navegador

Passo a passo

Nesta prática, você vai usar um sensor simples (como um potenciômetro) e mostrar seu valor em uma página web.

Você vai aplicar: leitura analógica, servidor web e geração dinâmica de HTML.
1

Monte o circuito

Conecte um potenciômetro ao ESP32: uma extremidade ao 3.3V, outra ao GND e o pino central a uma entrada analógica, como o pino 34.

Aplicação do conceito: o potenciômetro simula um sensor analógico simples.

2

Inclua as bibliotecas

#include <WiFi.h>
#include <WebServer.h>
3

Defina rede e servidor

const char* ssid = "Wokwi-GUEST";
const char* password = "";

WebServer server(80);
int sensorPin = 34;
4

Crie a página com valor do sensor

void handleRoot() {
  int valor = analogRead(sensorPin);
  String pagina = "<html><body>";
  pagina += "<h1>Leitura do Sensor</h1>";
  pagina += "<p>Valor: " + String(valor) + "</p>";
  pagina += "<p><a href='/'>Atualizar</a></p>";
  pagina += "</body></html>";
  server.send(200, "text/html", pagina);
}
5

Configure o setup()

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }
  server.on("/", handleRoot);
  server.begin();
}
6

Complete o loop()

void loop() {
  server.handleClient();
}
7

Teste no navegador

Acesse o IP do ESP32 pelo navegador e observe o valor do sensor mudar conforme você gira o potenciômetro.

Resultado: o navegador passa a exibir dados reais do circuito.

Resultado esperado: uma página web mostrando, em tempo real simples, o valor lido de um sensor.
