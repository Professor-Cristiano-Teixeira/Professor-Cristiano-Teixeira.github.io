Variáveis, Tipos, Operadores e Estruturas de Controle

Bimestre 2 • Capítulo 6 • Tomando decisões e controlando o comportamento do circuito

Neste capítulo, você vai aprofundar a programação de microcontroladores trabalhando com variáveis, tipos de dados, operadores e estruturas de decisão e repetição. Esses elementos permitem que o programa deixe de ser apenas uma sequência fixa de ações e passe a tomar decisões, comparar valores, guardar informações e repetir comportamentos de forma mais inteligente.

1. Conceitos essenciais

Base teórica
Ideia central: a partir deste ponto, o programa começa a “pensar” melhor sobre o que está acontecendo. Ele pode guardar valores, verificar condições e decidir o que fazer com base em entradas e resultados.

1.1 Variáveis

Uma variável é um espaço usado para guardar um valor que pode ser consultado ou alterado durante a execução do programa. Em vez de escrever sempre um número diretamente no código, podemos armazená-lo em uma variável para facilitar a leitura, a organização e futuras mudanças.

Na prática com Arduino, isso é útil para guardar o estado de um botão, a contagem de repetições, um tempo de espera ou qualquer outro dado necessário ao comportamento do circuito.

1.2 Tipos de dados

O tipo de dado indica que tipo de valor uma variável vai guardar. Por exemplo, podemos guardar números inteiros, valores com casas decimais, caracteres ou estados verdadeiro/falso. No Arduino, alguns tipos muito comuns são int, float, char e bool.

Escolher o tipo adequado ajuda o programa a usar a informação da forma correta. Neste capítulo, os exemplos mais comuns serão com int e bool, pois são adequados para contagens e estados simples do circuito.

1.3 Operadores aritméticos

Operadores aritméticos permitem fazer contas, como somar, subtrair, multiplicar e dividir. Eles são usados quando o programa precisa atualizar valores numéricos, contar eventos ou ajustar tempos e medidas.

Mesmo em projetos simples, isso já aparece quando queremos aumentar um contador, reduzir um valor ou manipular variáveis ao longo da execução.

1.4 Operadores de comparação e lógicos

Os operadores de comparação permitem verificar relações entre valores, como “é igual?”, “é maior?”, “é diferente?”. Já os operadores lógicos ajudam a combinar condições, como em “e” ou “ou”. Esses recursos são fundamentais para que o programa tome decisões.

Por exemplo, um botão pressionado pode gerar uma condição verdadeira; a partir disso, o programa decide se deve acender um LED ou não.

1.5 Estruturas de decisão

As estruturas de decisão, como if e else, permitem que o programa siga caminhos diferentes conforme uma condição. Isso é essencial para criar comportamento adaptável: se algo acontecer, o circuito faz uma coisa; se não acontecer, faz outra.

Na prática embarcada, estruturas de decisão aparecem o tempo todo, principalmente quando o sistema precisa reagir a botões, sensores ou estados internos.

1.6 Estruturas de repetição

As estruturas de repetição permitem executar um bloco de instruções várias vezes. Alguns exemplos comuns são for e while. Elas são úteis quando queremos repetir um padrão de acendimento, contar ciclos ou executar ações até que uma condição mude.

Embora o próprio loop() já repita o programa, as repetições internas ajudam a controlar sequências mais específicas dentro da lógica do sistema.

3. Prática guiada — Botão controlando LED com variável e decisão

Passo a passo

Nesta prática, você vai usar uma variável para guardar o estado de um botão e uma estrutura de decisão para controlar um LED com base nessa leitura.

O que você vai aplicar aqui: variável, tipo de dado, leitura simples, comparação e if / else.
Dica importante: primeiro monte o circuito e depois compare, com calma, os pinos usados no código e na montagem física.
1

Monte o circuito

No Tinkercad, crie um circuito com Arduino Uno, protoboard, um botão, um LED, um resistor para o LED e os jumpers necessários. Ligue o LED a um pino digital de saída e o botão a um pino digital de entrada.

Aplicação do conceito: o botão será a entrada; o LED será a saída.

2

Crie uma variável para o botão

No código, crie uma variável para guardar o valor lido do botão. Um tipo adequado pode ser int ou bool, dependendo da abordagem didática adotada. Aqui, vamos usar int para facilitar a relação com leitura digital.

int estadoBotao = 0;

Aplicação do conceito: a variável servirá para armazenar o valor lido no pino do botão.

3

Configure os pinos no setup()

Defina o pino do botão como entrada e o do LED como saída:

void setup() {
  pinMode(2, INPUT);
  pinMode(13, OUTPUT);
}

Aplicação do conceito: o Arduino precisa saber qual pino recebe informação e qual controla um componente.

4

Leia o botão dentro do loop()

Agora, dentro do loop(), faça a leitura do botão e guarde o resultado na variável:

void loop() {
  estadoBotao = digitalRead(2);
}

Aplicação do conceito: o valor do botão passa a ser tratado como dado do programa.

5

Use uma decisão para controlar o LED

Adicione uma estrutura if / else para verificar o valor lido:

int estadoBotao = 0;

void setup() {
  pinMode(2, INPUT);
  pinMode(13, OUTPUT);
}

void loop() {
  estadoBotao = digitalRead(2);

  if (estadoBotao == HIGH) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}

Aplicação do conceito: se a condição for verdadeira, o LED acende; caso contrário, ele apaga.

6

Teste e observe

Inicie a simulação e pressione o botão. Observe o LED respondendo à condição definida no programa. Esse é um dos primeiros exemplos claros em que o código toma uma decisão com base em uma entrada real do circuito.

Resultado esperado: botão pressionado → LED aceso; botão solto → LED apagado.

Resultado esperado: um circuito em que a leitura de uma entrada altera o comportamento da saída por meio de decisão lógica.

4. Exemplo simples com repetição

Ampliação do conceito

Além da decisão, o programa também pode repetir uma ação várias vezes de forma controlada. Veja este exemplo com for:

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  for (int i = 0; i < 3; i++) {
    digitalWrite(13, HIGH);
    delay(300);
    digitalWrite(13, LOW);
    delay(300);
  }

  delay(1000);
}

Nesse caso, o LED pisca três vezes dentro do for e depois espera um pouco antes de repetir tudo novamente. O importante é perceber que a repetição interna controla um padrão específico dentro do programa.

5. Atividades sugeridas para o aluno

Prática orientada

Atividades de continuação

  1. Dois LEDs com decisão: use um LED para quando o botão estiver pressionado e outro para quando estiver solto.
  2. Contador simples: crie uma variável contador e faça com que ela aumente em determinadas repetições do programa.
  3. Pisca controlado: use for para fazer o LED piscar 5 vezes antes de parar por um instante.

Desafios de adaptação

  1. Dois botões: planeje um circuito em que um botão acenda o LED e outro o apague.
  2. Padrão com repetição: crie uma sequência curta usando for ou while para variar o ritmo do LED.
  3. Registro de lógica: explique, com suas palavras, por que a variável do botão é útil no programa.
