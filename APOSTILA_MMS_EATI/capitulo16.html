Projeto Integrador Final — Sistema Embarcado Completo

Este capítulo encerra o curso com o Projeto Integrador Final, consolidando todos os conhecimentos desenvolvidos ao longo do ano: lógica, Arduino, decisões, repetição, funções, variáveis e temporização sem delay.

Objetivos de aprendizagem

  • Integrar todos os conteúdos estudados.
  • Desenvolver um sistema embarcado completo.
  • Planejar, implementar e testar um projeto real.
  • Documentar corretamente uma solução técnica.

Pré-requisitos

  • Capítulos 01–15 concluídos.
  • Conhecimentos básicos de Arduino e lógica.

1) Descrição geral do projeto

O projeto integrador final consiste no desenvolvimento de um sistema embarcado funcional, capaz de tomar decisões, controlar saídas e operar com temporização não bloqueante.

Exemplos de temas: semáforo inteligente, sistema de alarme, controle de acesso, temporizador programável.

2) Requisitos mínimos

  • Uso de pelo menos 2 entradas (botões/sensores).
  • Uso de pelo menos 2 saídas (LEDs, buzzer ou relé simulado).
  • Uso de if / else.
  • Uso de for ou while.
  • Uso de funções.
  • Uso de millis() (sem delay).

3) Entregáveis

  • Código completo e comentado.
  • Diagrama ou foto da montagem.
  • Relatório técnico (15 a 20 linhas).

Roteiro de desenvolvimento sugerido

  • Definir o problema e o objetivo do sistema.
  • Listar entradas, saídas e regras de funcionamento.
  • Desenhar o diagrama do circuito.
  • Dividir o código em funções.
  • Implementar temporização com millis().
  • Testar e corrigir falhas.
Dica: comece simples e evolua o projeto gradualmente.
