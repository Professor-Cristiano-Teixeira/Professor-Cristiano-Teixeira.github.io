Portas Lógicas e Tabelas Verdade

Neste capítulo você aprende as principais portas lógicas (AND, OR, NOT, NAND, NOR, XOR, XNOR), constrói e interpreta tabelas verdade e começa a escrever regras em forma de expressões lógicas. No passo a passo, você monta um “laboratório de portas” com botões e LEDs no Tinkercad/Arduino e valida os resultados gerando a tabela verdade no Serial Monitor.

Objetivos de aprendizagem

  • Reconhecer e explicar o comportamento de AND, OR, NOT, NAND, NOR, XOR e XNOR.
  • Construir tabela verdade para 1 ou 2 entradas.
  • Relacionar tabela verdade ↔ expressão lógica (leitura e escrita básicas).
  • Implementar portas lógicas em um microcontrolador (lógica em código) e validar com testes.
  • Identificar aplicações em TI: decisões, permissões, alarmes, validações e diagnósticos.

Pré-requisitos

  • Cap. 05: binário, níveis lógicos, limiar e pull-up/pull-down.
  • Noções básicas de if/else e operadores lógicos (AND/OR/NOT) em programação.
Ferramentas: Tinkercad (Arduino + botões + LEDs) ou bancada real. Observação: no Cap. 07 você vai aprofundar expressões e simplificação (álgebra booleana).

1) Porta lógica: o que é e por que existe

Uma porta lógica é um bloco que recebe entradas digitais (0/1) e produz uma saída digital (0/1) de acordo com uma regra. Essa regra é descrita por uma tabela verdade. Portas lógicas são a base de circuitos digitais: processadores, memórias e controladores são construídos a partir de bilhões de portas/elementos lógicos.

Onde vou aplicar isso: ao projetar decisões (se/então) em automação, e ao entender como sinais digitais são combinados em hardware e em código.

2) Tabela verdade: a “prova” do comportamento lógico

A tabela verdade lista todas as combinações possíveis das entradas e mostra a saída correspondente. Para 1 entrada, há 2 combinações (0 e 1). Para 2 entradas, há 4 combinações (00, 01, 10, 11). Para n entradas, há 2ⁿ combinações.

Onde vou aplicar isso: no passo a passo, você vai gerar a tabela verdade no Serial Monitor e comparar com os LEDs.

3) As portas básicas (com tabelas verdade)

Vamos usar A e B como entradas e Y como saída. Considere que 1 = verdadeiro/ligado e 0 = falso/desligado.

3.1 NOT (inversor)

A porta NOT inverte a entrada: se A=1, Y=0; se A=0, Y=1.

AY = NOT A
01
10
Onde vou aplicar isso: em botões com pull-up (pressionado vira 0) e em condições invertidas (alarme quando NÃO há sinal).

3.2 AND (E)

AND só dá 1 quando todas as entradas são 1.

ABY = A AND B
000
010
100

Onde vou aplicar isso: permissões e segurança (só libera se duas condições forem verdadeiras).

3.3 OR (OU)

OR dá 1 quando pelo menos uma entrada é 1.

ABY = A OR B
000
011
101
111
Onde vou aplicar isso: alarmes e monitoramento (dispara se qualquer sensor detectar problema).

3.4 XOR (OU exclusivo)

XOR dá 1 quando as entradas são diferentes. É muito usado em comparação e paridade.

ABY = A XOR B
000
011
101
110
Onde vou aplicar isso: detectar diferença entre dois sinais (comparação), e em lógica de alternância (toggle).

4) Portas derivadas: NAND, NOR e XNOR

Portas derivadas são versões invertidas (negadas) das portas básicas. Elas são muito importantes porque, na prática, NAND e NOR são consideradas portas universais: é possível construir qualquer circuito lógico usando apenas NAND ou apenas NOR. Você vai aprofundar isso no Capítulo 07.

AB NAND = NOT(A AND B) NOR = NOT(A OR B) XNOR = NOT(A XOR B)
00111
01100
10100
11001
Onde vou aplicar isso: em expressões negadas, alarmes invertidos e no projeto de circuitos com componentes limitados (apenas NAND/NOR).

5) Expressões lógicas (introdução) e relação com programação

Uma expressão lógica descreve uma regra. Ex.: Y = A AND B. Em programação, isso corresponde a operadores lógicos. No Arduino/C/C++: && (AND), || (OR) e ! (NOT). Para bits, existem operadores bitwise: &, |, ^.

Cuidado: && e || são lógicos (true/false). &, |, ^ operam bit a bit (números).
Onde vou aplicar isso: no passo a passo, ao implementar AND/OR/XOR com botões (entradas) e LEDs (saídas).
Conexão com o próximo capítulo: no Capítulo 07 você vai aprender a simplificar expressões (álgebra booleana) e reduzir circuitos.

Passo a passo prático (Tinkercad/Arduino): “Laboratório de Portas Lógicas” com 2 botões e LEDs

Objetivo: usar dois botões como entradas A e B e quatro LEDs como saídas de AND, OR, XOR e NOT(A). Depois, gerar a tabela verdade automaticamente no Serial Monitor.

Componentes e ideia do circuito

Você vai montar:

  • Arduino UNO
  • 2 botões (A e B)
  • 4 LEDs (AND, OR, XOR, NOT A) + resistores 220 Ω
  • Jumpers e protoboard
Aplicação do conceito: botões geram 0/1; LEDs mostram 0/1; isso permite validar tabelas verdade na prática.

Ligar os botões com pull-up interno (sem entrada flutuante)

Conecte cada botão entre o pino e o GND. No código, use INPUT_PULLUP:

  • Botão A: pino 2 ↔ botão ↔ GND
  • Botão B: pino 3 ↔ botão ↔ GND
Lembrete: com pull-up, solto = 1 (HIGH) e pressionado = 0 (LOW). Vamos inverter no código para ficar intuitivo (pressionado = 1).

Ligar os LEDs de saída

Monte 4 LEDs com resistor (220 Ω) em série para cada saída:

  • LED AND → pino 8
  • LED OR → pino 9
  • LED XOR → pino 10
  • LED NOT(A) → pino 11
  • Cátodos (lado curto) → GND
Segurança: sempre use resistor em série com LED para limitar corrente.

Código: calcular portas e imprimir tabela verdade

O código abaixo:

  • Lê botões A e B (normaliza para 0/1 com pressionado=1)
  • Calcula AND/OR/XOR/NOT
  • Atualiza LEDs
  • Imprime estado atual e, ao iniciar, imprime a tabela verdade completa
// EATI - Capítulo 06
// Laboratório de Portas Lógicas com Arduino

const int BTN_A = 2;
const int BTN_B = 3;

const int LED_AND = 8;
const int LED_OR  = 9;
const int LED_XOR = 10;
const int LED_NOTA = 11;

bool tabelaImpressa = false;

void printTruthTable() {
  Serial.println("\nTABELA VERDADE (A, B) -> AND OR XOR NAND NOR XNOR");
  Serial.println("A B | AND OR XOR | NAND NOR XNOR");
  for (int A = 0; A <= 1; A++) {
    for (int B = 0; B <= 1; B++) {
      int ANDv = A && B;
      int ORv  = A || B;
      int XORv = (A != B);
      int NANDv = !ANDv;
      int NORv  = !ORv;
      int XNORv = !XORv;

      Serial.print(A); Serial.print(" ");
      Serial.print(B); Serial.print(" |  ");
      Serial.print(ANDv); Serial.print("   ");
      Serial.print(ORv);  Serial.print("   ");
      Serial.print(XORv); Serial.print("  |   ");
      Serial.print(NANDv); Serial.print("    ");
      Serial.print(NORv);  Serial.print("    ");
      Serial.println(XNORv);
    }
  }
  Serial.println("----------------------------------------");
}

void setup() {
  pinMode(BTN_A, INPUT_PULLUP);
  pinMode(BTN_B, INPUT_PULLUP);

  pinMode(LED_AND, OUTPUT);
  pinMode(LED_OR, OUTPUT);
  pinMode(LED_XOR, OUTPUT);
  pinMode(LED_NOTA, OUTPUT);

  Serial.begin(9600);
}

void loop() {
  if (!tabelaImpressa) {
    printTruthTable();
    tabelaImpressa = true;
  }

  // Com pull-up: solto = HIGH (1), pressionado = LOW (0).
  // Vamos inverter para ficar intuitivo: pressionado = 1.
  int A = (digitalRead(BTN_A) == LOW) ? 1 : 0;
  int B = (digitalRead(BTN_B) == LOW) ? 1 : 0;

  int ANDv = A && B;
  int ORv  = A || B;
  int XORv = (A != B);
  int NOTA = !A;

  digitalWrite(LED_AND, ANDv);
  digitalWrite(LED_OR, ORv);
  digitalWrite(LED_XOR, XORv);
  digitalWrite(LED_NOTA, NOTA);

  Serial.print("A=" ); Serial.print(A);
  Serial.print(" B=" ); Serial.print(B);
  Serial.print(" | AND=" ); Serial.print(ANDv);
  Serial.print(" OR=" );  Serial.print(ORv);
  Serial.print(" XOR=" ); Serial.print(XORv);
  Serial.print(" NOTA=" );Serial.println(NOTA);

  delay(200);
}
Dica: no Serial Monitor, observe a tabela verdade impressa e compare com os LEDs quando você pressiona os botões.

Testes (validação com tabela verdade)

Teste as 4 combinações:

  • A=0, B=0 (nenhum pressionado)
  • A=1, B=0 (apenas A)
  • A=0, B=1 (apenas B)
  • A=1, B=1 (A e B)

Verifique se os LEDs batem com as tabelas verdade do capítulo (AND/OR/XOR/NOT).

Aplicação do conceito: você está validando a lógica comparando a saída real (LED) com a tabela verdade (teoria).
