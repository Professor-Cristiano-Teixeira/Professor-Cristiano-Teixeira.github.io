Capítulo 05 — Instalação do Windows 11 no VirtualBox (Guia Completo)

Este capítulo marca o início das práticas. Você vai instalar o Windows 11 em uma máquina virtual usando VirtualBox, e vai finalizar a instalação com conta local (sem conta Microsoft), usando um recurso de terminal durante o OOBE. O objetivo é que você consiga repetir o processo sozinho, com segurança, registrando evidências e entendendo as decisões que tomou.

Objetivos de aprendizagem e pré‑requisitos

Ao final deste capítulo você será capaz de:

  • Criar e configurar uma VM adequada para Windows 11 no VirtualBox (RAM, CPU, disco, rede).
  • Instalar o Windows 11 com instalação personalizada (disco vazio).
  • Finalizar a instalação com usuário local, sem conta Microsoft, usando o comando do OOBE.
  • Executar um checklist de pós‑instalação: versão, drivers básicos, updates e organização inicial.
  • Registrar evidências (prints + checklist) para comprovar a instalação.

Pré‑requisitos

  • VirtualBox instalado no host.
  • Virtualização por hardware habilitada (VT‑x/AMD‑V) — Cap. 03.
  • Arquivo ISO do Windows 11 disponível localmente.
  • Conceitos de UEFI/GPT e edições — Cap. 04.
Recomendação: tenha pelo menos 8 GB de RAM no host para rodar uma VM com 4 GB sem travar.

Teoria essencial (o que você está fazendo — e por quê)

1) ISO e boot

Uma ISO é uma imagem de instalação — pense como um “DVD digital” do Windows. A VM precisa dar boot por essa ISO para iniciar o instalador. Onde vou aplicar: ao iniciar a VM, você seleciona a ISO como unidade óptica virtual.

2) VM, recursos e desempenho

A VM compartilha CPU e RAM com o host. Se você der recursos demais para a VM, o host pode travar; se der recursos de menos, a VM fica lenta. Onde vou aplicar: ao definir RAM (ex.: 4 GB) e CPU (ex.: 2 núcleos).

3) Particionamento automático

Em uma instalação limpa, o instalador cria automaticamente partições necessárias (EFI/MSR/Recuperação e a principal). Onde vou aplicar: ao escolher “Instalação personalizada” e apontar o disco vazio.

4) OOBE (Out‑Of‑Box Experience)

O OOBE é a etapa final onde você define país, teclado, rede e conta do usuário. Em versões recentes, o Windows costuma incentivar fortemente o uso de conta Microsoft. Em laboratório, porém, é comum usar conta local. Onde vou aplicar: você abrirá o terminal com Shift + F10 e executará OOBE\BYPASSNRO.

5) Conta local vs Conta Microsoft (visão prática de suporte)

Conta local é simples e ideal para laboratório: independe de internet, reduz distrações e facilita padronização. Conta Microsoft facilita sincronização e integração com serviços online, mas pode ser desnecessária no laboratório. Onde vou aplicar: ao finalizar o OOBE, você criará um usuário local.

Meta do capítulo: terminar com um Windows 11 funcional, com usuário local, pronto para os capítulos de configuração, discos e ferramentas administrativas.

Checklist de entrada

  • ✅ ISO do Windows 11 baixada e localizada
  • ✅ VirtualBox instalado
  • ✅ Virtualização habilitada no BIOS/UEFI do host
  • ✅ Espaço em disco no host (pelo menos 70 GB livres)
  • ✅ Tempo estimado: primeira instalação pode levar mais por updates

Decisões que você precisa tomar

  • Edição: Pro é recomendada para laboratório técnico.
  • Nome da VM: padronizado (ex.: FGSO‑W11‑Base).
  • Partições: deixe o instalador criar automaticamente (mais seguro).
  • Conta: usar conta local (aplicaremos o bypass no OOBE).

Configuração do VirtualBox (criação e ajustes da VM)

Nesta seção você cria a VM e confere ajustes que evitam erros comuns. Mesmo que sua tela seja levemente diferente, os conceitos e objetivos são os mesmos.

Criar a VM

  • Abra o VirtualBox e clique em Novo.
  • Nome: FGSO-W11-Base (sugestão).
  • Tipo: Microsoft Windows • Versão: Windows 11 (64-bit) (ou equivalente).

Definir recursos (RAM e CPU)

  • RAM: 4096 MB (4 GB) como base (se o host permitir, 6–8 GB melhora).
  • CPU: 2 núcleos (se host tiver folga, 4 núcleos pode melhorar).
  • Mantenha margem para o host não travar.
Regra prática: não aloque mais de ~50% da RAM do host para a VM.

Criar disco virtual

  • Escolha Criar um disco rígido virtual agora.
  • Tipo: VDI (padrão do VirtualBox).
  • Armazenamento: Dinâmico (cresce conforme uso).
  • Tamanho: 64 GB (mínimo confortável para updates e ferramentas).

Conferir configurações importantes

  • Selecione a VM → Configurações.
  • Sistema: confirme a ordem de boot (Óptico antes do Disco, se necessário).
  • Armazenamento: anexe a ISO do Windows 11 no drive óptico.
  • Rede: use NAT (seguro e simples para laboratório).
Onde vou aplicar isso: a ISO no armazenamento garante que a VM inicialize o instalador.

Snapshot (recomendado)

  • Antes de iniciar a instalação, crie um snapshot chamado 05-antes-instalacao.
  • Assim você pode “voltar no tempo” se errar um passo.

Instalação do Windows 11 (passo a passo — instalador)

A instalação a seguir é para disco vazio (VM nova). Se sua VM já tiver algo instalado, você deverá apagar partições — neste curso, não faça isso em máquinas reais sem backup.

Iniciar a VM e dar boot pela ISO

  • Clique em Iniciar na VM.
  • Se o VirtualBox perguntar a ISO, selecione a ISO do Windows 11.
  • Aguarde a tela de idioma/teclado do instalador.

Idioma, teclado e início

  • Escolha idioma e teclado conforme seu laboratório.
  • Clique em Instalar agora.

Chave de produto e edição

  • Se pedir chave, selecione Não tenho uma chave de produto (laboratório).
  • Escolha uma edição (recomendado: Windows 11 Pro para laboratório técnico).
Atenção: instalar a edição errada pode exigir reinstalação para ter recursos de administração.

Termos e tipo de instalação

  • Aceite os termos.
  • Selecione Instalação personalizada (avançada).

Escolha do disco (VM nova)

  • Selecione o disco vazio (geralmente “Unidade 0 Espaço não alocado”).
  • Clique em Avançar.
  • O instalador criará as partições necessárias automaticamente.

Cópia de arquivos e reinicializações

  • Aguarde copiar e instalar.
  • A VM reiniciará automaticamente.
  • Se aparecer “Pressione qualquer tecla para inicializar do CD/DVD”, não pressione (deixe bootar do disco).
Você terminou o instalador. Agora começa o OOBE (configuração inicial) — onde faremos a instalação sem conta Microsoft.

Finalização (OOBE) sem conta Microsoft — método recomendado do curso

Em muitas instalações recentes, o Windows tenta forçar a conexão e login com conta Microsoft. No laboratório, vamos usar um procedimento conhecido para liberar a opção de conta local.

Quando aplicar: use este procedimento quando o Windows pedir Internet/conta e você quiser seguir com conta local.

Abrir o terminal no OOBE

  • Na tela do OOBE, pressione Shift + F10.
  • Um Prompt de Comando será aberto.

Executar o comando de bypass

  • Digite o comando abaixo e pressione Enter:
OOBE\BYPASSNRO
  • A máquina reiniciará automaticamente.

Escolher configuração limitada (sem Internet)

  • Após reiniciar, avance até aparecer a etapa de rede.
  • Selecione Não tenho Internet.
  • Em seguida, clique em Continuar com configuração limitada.

Criar usuário local

  • Crie um nome de usuário local (ex.: aluno ou fgso).
  • Defina senha (recomendado) e perguntas de segurança, se solicitado.
  • Finalize as telas de privacidade (veja recomendações no próximo tópico).
Resultado esperado: você entra na área de trabalho com um usuário local, sem precisar de conta Microsoft.

Pós‑instalação: configurações recomendadas (para laboratório)

Esta etapa não é “enfeite”: ela evita problemas nos próximos capítulos (drivers, updates e desempenho). Faça com calma e marque no checklist.

Configurações iniciais recomendadas

  • Nome do PC: padronize (ex.: FGSO-W11-01).
  • Fuso/idioma: ajuste se necessário (para logs e horários corretos).
  • Windows Update: verifique atualizações (pode demorar na 1ª vez).
  • Armazenamento: confira espaço livre no disco.

Privacidade e usabilidade (laboratório)

  • Desative opções que você não precisa no laboratório (conforme política local).
  • Mantenha segurança básica ativa (Windows Security).
  • Crie uma pasta de laboratório em C:\FGSO (por enquanto).
  • Snapshot pós‑instalação: 05-ponto-limpo.

Problemas comuns e soluções (sem professor)

Problema 1: A VM não dá boot pela ISO boot
  • Verifique se a ISO está anexada em Armazenamento (drive óptico).
  • Confirme ordem de boot: Óptico antes do Disco.
  • Se necessário, reinicie e use o menu de boot do VirtualBox (quando disponível).
Problema 2: A VM está muito lenta recursos
  • Aumente RAM (se o host permitir) e/ou vCPU.
  • Feche programas no host.
  • Verifique se VT-x/AMD-V está habilitado no BIOS/UEFI do host.
  • Use SSD no host, se possível (impacto grande).
Problema 3: Shift+F10 não abre o terminal no OOBE atalho
  • Em VM, confirme que o teclado está capturado pela VM (clique dentro da janela).
  • Tente Fn + Shift + F10 (alguns notebooks usam Fn).
  • Tente usar o teclado virtual do Windows (caso exista) para enviar F10.
Problema 4: Não aparece “Continuar com configuração limitada” OOBE
  • Garanta que você executou OOBE\BYPASSNRO e reiniciou.
  • Volte até a etapa de rede e procure “Não tenho Internet”.
  • Se necessário, repita o comando no OOBE (Shift+F10).
Segurança: não baixe ferramentas aleatórias para “resolver” instalação. Use recursos nativos e, em VM, volte ao snapshot.
