Capítulo 13 — Fundamentos de Rede + CMD Essencial (GUI + Linha de Comando)

Bem-vindo ao 4º bimestre. Antes de avançar para rede, usuários e políticas, você precisa dominar duas coisas: (1) os fundamentos de rede (IP, gateway, DNS) e (2) o CMD essencial para navegar, criar evidências e executar comandos com segurança. Este capítulo traz um passo a passo de CMD (o que faltava para “operar” de verdade) e uma tabela revisando todos os comandos já apresentados na apostila.

IP • Gateway • DNS Redirecionamento ( > >> | ) Arquivos/Pastas (cd/dir/mkdir) Diagnóstico (ipconfig/ping/tracert) Logs e evidências

Objetivos de aprendizagem e pré‑requisitos

Ao final deste capítulo você será capaz de:

  • Explicar (e identificar) IP, máscara, gateway e DNS em um PC Windows.
  • Executar comandos básicos do CMD: navegar, criar pastas, copiar/mover arquivos, ver conteúdo e salvar logs.
  • Usar redirecionamento e pipes (>, >>, |) para criar evidências.
  • Rodar diagnóstico básico de rede (ping, tracert, ipconfig, netstat) e interpretar resultado.
  • Consultar a tabela de comandos já vistos e usar como “cola” de suporte.

Pré‑requisitos

  • Capítulos 05–12 (principalmente 09–11).
  • Ter acesso a um Windows 11 (VM ou máquina real).
  • Conta local com permissões administrativas (para alguns comandos avançados).
Observação: CMD não substitui PowerShell, mas é essencial para operar em qualquer Windows e entender instruções de suporte.

Conceitos de rede (rápido e aplicável)

Endereço IP (IPv4)

O IP é o “endereço” do seu computador na rede. Em redes locais comuns, ele costuma ser privado (ex.: 192.168.x.x). Onde vou aplicar: em ipconfig você vai identificar o IPv4 do seu adaptador.

Máscara / Prefixo

A máscara define o tamanho da rede local (ex.: 255.255.255.0). Ela determina quem está na “mesma rede”. Onde vou aplicar: também aparece no ipconfig /all.

Gateway padrão

Gateway é a “saída” da rede local para outras redes (ex.: Internet). Em geral é o roteador. Onde vou aplicar: se você consegue pingar o gateway mas não navega, o problema pode estar depois do roteador (DNS/Internet).

DNS

DNS traduz nomes (www...) para IP. Às vezes a Internet “parece lenta” porque o DNS está falhando. Onde vou aplicar: compare ping 8.8.8.8 (IP) com ping www.microsoft.com (nome).

Diagnóstico rápido (método): IP ok? → Gateway responde? → DNS resolve? → Rota ok? (ping/tracert).

CMD essencial: passo a passo (o mínimo para operar instruções)

Esta é a parte que normalmente falta: saber se mover no CMD e gerar evidências. Você vai praticar: navegação, arquivos/pastas, redirecionamento, variáveis e ajuda.

Abrir CMD e entender o prompt

  • Abra: Menu Iniciar → digite cmd → Enter.
  • O prompt mostra algo como: C:\\Users\\seuUsuario> (isso é o diretório atual).
  • Onde vou aplicar: saber o diretório atual evita salvar evidências no lugar errado.

Ajuda e documentação rápida

  • Use help para listar comandos.
  • Use comando /? para ver parâmetros.
help
ipconfig /?
robocopy /?

Navegar por pastas (cd, dir)

  • dir lista arquivos/pastas.
  • cd muda de diretório.
  • cd .. volta um nível.
  • cd \ vai para a raiz do disco.
dir
cd ..
cd \
cd Users
cd %USERNAME%
Dica: caminhos com espaço exigem aspas: cd "Program Files"

Criar e remover pastas (mkdir, rmdir)

  • mkdir cria pasta.
  • rmdir remove pasta vazia.
  • rmdir /s remove pasta com conteúdo (cuidado!).
mkdir C:\FGSO\cap13
mkdir C:\FGSO\cap13\logs
rmdir C:\FGSO\cap13\pasta_vazia

Criar e ver conteúdo de arquivos (echo, type, more)

  • echo escreve texto.
  • type exibe o conteúdo de um arquivo.
  • more pagina a saída (útil para logs grandes).
echo Relatorio Cap13 > C:\FGSO\cap13\relatorio.txt
echo Data: %DATE% %TIME% >> C:\FGSO\cap13\relatorio.txt
type C:\FGSO\cap13\relatorio.txt

Copiar, mover e renomear (copy, move, ren, del)

  • copy copia arquivos.
  • move move arquivos.
  • ren renomeia.
  • del apaga (use com cuidado).
copy C:\FGSO\cap13\relatorio.txt C:\FGSO\cap13\logs\relatorio_copia.txt
ren C:\FGSO\cap13\logs\relatorio_copia.txt relatorio_final.txt
move C:\FGSO\cap13\logs\relatorio_final.txt C:\FGSO\cap13\

Redirecionamento e pipes (essencial para evidências)

  • > cria/substitui arquivo com a saída.
  • >> adiciona ao final (append).
  • | envia a saída de um comando para outro (pipe).
ipconfig /all > C:\FGSO\cap13\logs\ipconfig.txt
netstat -ano > C:\FGSO\cap13\logs\netstat.txt

tasklist | findstr /i "svchost" > C:\FGSO\cap13\logs\svchosts.txt
Onde vou aplicar isso: suporte profissional exige evidências em arquivo para relatório e auditoria.

Variáveis de ambiente (para não depender do nome do usuário)

  • Variáveis ajudam scripts e comandos a funcionar em qualquer PC.
  • Exemplos: %USERNAME%, %USERPROFILE%, %TEMP%.
echo Usuario: %USERNAME%
echo Perfil: %USERPROFILE%
cd %USERPROFILE%\Documents

Limpar e sair (cls, exit) + boas práticas

  • cls limpa a tela. exit fecha o CMD.
  • Boa prática: nunca rode comandos destrutivos (del/rmdir /s) sem conferir o caminho com dir.
cls
exit
Checklist mental (CMD): Onde estou? (cd) • O que existe aqui? (dir) • Para onde vai a saída? (>/>>)

Passo a passo prático: diagnóstico de rede + geração de logs (GUI + CMD)

Objetivo: coletar evidências de rede em arquivos, usando o que você aprendeu no CMD. Você vai salvar tudo em C:\\FGSO\\cap13.

Antes de começar: se estiver em VM, confira a rede (NAT) e se o Windows tem acesso à internet.

Criar pasta e arquivo de relatório

  • Abra CMD e execute:
mkdir C:\FGSO\cap13
mkdir C:\FGSO\cap13\logs

echo Relatorio de Rede - Cap13 > C:\FGSO\cap13\relatorio.txt
echo Data: %DATE% %TIME% >> C:\FGSO\cap13\relatorio.txt

Coletar configuração de rede (ipconfig)

  • Salve a saída completa:
ipconfig /all > C:\FGSO\cap13\logs\ipconfig.txt
  • Abra o arquivo e identifique: IPv4, gateway e DNS.
  • Registre no relatório (copiar/colar é permitido):
type C:\FGSO\cap13\logs\ipconfig.txt | more

Teste de conectividade: IP x DNS

  • Ping por IP (conectividade geral):
ping 8.8.8.8 > C:\FGSO\cap13\logs\ping_ip.txt
  • Ping por nome (testa DNS):
ping www.microsoft.com > C:\FGSO\cap13\logs\ping_dns.txt
  • No relatório, escreva uma conclusão curta: “IP ok/DNS ok” ou “IP ok/DNS falha”.

Rota até um destino (tracert)

  • Gerar evidência de rota:
tracert www.microsoft.com > C:\FGSO\cap13\logs\tracert.txt
  • No relatório, anote: quantos saltos (hops) apareceram e se houve timeouts.

Conexões ativas (netstat) e filtro com findstr

  • Salvar conexões:
netstat -ano > C:\FGSO\cap13\logs\netstat.txt
  • Filtrar linhas com “ESTABLISHED” (conexões estabelecidas):
type C:\FGSO\cap13\logs\netstat.txt | findstr /i ESTABLISHED > C:\FGSO\cap13\logs\netstat_established.txt
  • Explique no relatório: “netstat mostra conexões e PID (para correlacionar com processos)”.

Final: validar pacote de evidências

  • Verifique se existem estes arquivos:
    • relatorio.txt
    • logs\\ipconfig.txt
    • logs\\ping_ip.txt e logs\\ping_dns.txt
    • logs\\tracert.txt
    • logs\\netstat.txt e logs\\netstat_established.txt
  • Use dir para conferir e tire 1 print do Explorer com a pasta completa (opcional, recomendado).
dir C:\FGSO\cap13
dir C:\FGSO\cap13\logs
Resultado esperado: você sabe operar CMD e coletar evidências de rede em arquivos — base para os próximos capítulos.
