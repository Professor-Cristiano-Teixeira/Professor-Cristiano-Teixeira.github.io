Projeto Integrador 4 (B4) — Kit de Implantação e Provisionamento (Sysprep + DISM)

Este PI finaliza o curso com uma entrega de padrão corporativo: um Kit de Implantação. Você vai produzir uma imagem WIM a partir de uma máquina de referência (Sysprep) e documentar como capturar/aplicar (DISM) e tornar bootável (bcdboot). A correção considera organização, evidências e clareza do runbook.

VM Referência (REF) Sysprep /generalize DISM Capture/Apply diskpart (UEFI) bcdboot README + checklist

Objetivos e pré‑requisitos

Objetivos

  • Entregar um kit repetível de implantação por imagem.
  • Produzir e/ou documentar uma imagem WIM (captura) e uma implantação (aplicação).
  • Escrever um runbook claro com riscos, validação e rollback.
  • Organizar evidências e facilitar auditoria (prints/logs).

Pré‑requisitos

  • Cap. 16 (Sysprep + DISM) concluído ou em execução.
  • VM recomendada (VirtualBox/Hyper‑V) e ISO do Windows.
  • Conhecimentos de CMD/PowerShell para registrar evidências (Cap. 13–15).
Segurança: não execute em disco físico sem saber reverter. Use VM.

Conceitos essenciais (e onde vou aplicar isso)

Máquina de referência (REF)

É a instalação “modelo” (limpa, atualizada e com apps essenciais) que servirá de base para a imagem. Onde vou aplicar isso: você vai documentar o baseline da REF e criar snapshot antes do Sysprep.

Sysprep (/generalize + /oobe)

Generaliza a instalação removendo identificadores específicos e prepara para o OOBE. Onde vou aplicar isso: no runbook e nas evidências de execução do Sysprep (REF desligada).

DISM (Capture/Apply)

Captura a partição do Windows para WIM e aplica o WIM em um disco alvo. Onde vou aplicar isso: logs/prints do Capture-Image e Apply-Image.

UEFI e boot (diskpart + bcdboot)

Após aplicar a imagem, é necessário criar partição EFI e configurar o boot. Onde vou aplicar isso: evidência do diskpart (EFI=S:) e do bcdboot.

Evidência e auditoria

O objetivo é provar o processo, não apenas o resultado. Onde vou aplicar isso: prints do CMD/WinPE, lista de volumes, dir do WIM e OOBE iniciando no alvo.

Regra do PI: seu kit deve funcionar como manual de implantação — alguém executa seguindo seu texto.

Entregável e critérios mínimos

Você vai entregar

  • Runbook (PDF/TXT) explicando captura e aplicação (com riscos).
  • Scripts (BAT) comentados para captura e aplicação (recomendado).
  • Evidências (prints + logs): Sysprep, DISM capture, diskpart, DISM apply, bcdboot, OOBE.
  • Checklist (10+ itens) preenchido.
  • README (mapa do pacote).
  • ZIP com tudo (recomendado).

Critérios mínimos

  • Runbook com etapas claras e comandos essenciais (Sysprep, DISM, diskpart, bcdboot).
  • Ao menos 8 evidências (prints) organizadas e nomeadas (01_, 02_, ...).
  • Um registro de validação: OOBE iniciando no alvo + winver.
  • Checklist completo e um parágrafo de “lições aprendidas”.
  • Se o WIM for grande demais para a plataforma, entregue runbook + evidências + scripts (obrigatório) e documente tamanho/local.
Dica: evidência mais forte = print do OOBE no alvo + print do dir do arquivo WIM.

Passo a passo de montagem e validação

Este roteiro é direto e evita esquecer itens da entrega.

Criar pasta do PI (B4)

mkdir C:\FGSO\PI_B4_Implantacao
mkdir C:\FGSO\PI_B4_Implantacao\imagem
mkdir C:\FGSO\PI_B4_Implantacao\runbook
mkdir C:\FGSO\PI_B4_Implantacao\scripts
mkdir C:\FGSO\PI_B4_Implantacao\evidencias
mkdir C:\FGSO\PI_B4_Implantacao\evidencias\prints
mkdir C:\FGSO\PI_B4_Implantacao\evidencias\logs

Preparar REF, executar Sysprep e registrar evidência

  • REF atualizada + snapshot antes.
  • Sysprep:
C:\Windows\System32\Sysprep\sysprep.exe /generalize /oobe /shutdown
  • Salve print: 01_sysprep_cmd.png e print da VM desligada (opcional).

Capturar WIM no WinPE/Setup e registrar (DISM)

  • Boot pela ISO → Shift+F10 → diskpart/list volume.
  • Capture o WIM (ajuste letras):
diskpart
list volume
exit
mkdir D:\Images

dism /Capture-Image /ImageFile:D:\Images\W11_FGSO.wim /CaptureDir:C:\ /Name:"W11_FGSO" /Compress:max /CheckIntegrity

dir D:\Images
  • Salve prints: 02_list_volume.png, 03_capture_ok.png, 04_dir_wim.png.

Preparar TARGET (diskpart UEFI), aplicar WIM e bcdboot

diskpart
select disk 0
clean
convert gpt
create partition efi size=100
format quick fs=fat32 label="SYSTEM"
assign letter=S
create partition msr size=16
create partition primary
format quick fs=ntfs label="Windows"
assign letter=C
exit

dism /Apply-Image /ImageFile:D:\Images\W11_FGSO.wim /Index:1 /ApplyDir:C:\
bcdboot C:\Windows /s S: /f UEFI
  • Salve prints: 05_diskpart_uefi.png, 06_apply_ok.png, 07_bcdboot_ok.png.

Validar implantação (OOBE + winver) e concluir

  • Reinicie a VM alvo sem ISO → OOBE deve aparecer.
  • Após configurar, rode winver e salve print.
  • Salve prints: 08_oobe.png, 09_winver.png.
winver
Validação mínima: OOBE aparece + Windows inicia + versão conferida.

Escrever Runbook + README + Checklist e empacotar

  • Crie o runbook em runbook/ (modelo abaixo).
  • Preencha checklist (10+ itens) e inclua riscos/rollback.
  • Compacte:
Compress-Archive -Path "C:\FGSO\PI_B4_Implantacao\*" -DestinationPath "C:\FGSO\PI_B4_Implantacao.zip" -Force
Dica final: se o WIM não for entregue, registre no README o tamanho e onde está armazenado no laboratório.

RUNBOOK — SYSPREP + DISM (PI B4)
Versão: 1.0  Data: __/__/____

1) Objetivo
- Implantar Windows por imagem (WIM) com padronização.

2) Pré-requisitos
- ISO Windows, VM REF e VM TARGET, disco para armazenar WIM.

3) Etapa A — Preparar REF
- Atualizar Windows
- Instalar apenas essencial
- Snapshot antes

4) Etapa B — Sysprep
- sysprep /generalize /oobe /shutdown
- Não bootar no Windows após desligar (até capturar)

5) Etapa C — Capturar WIM (WinPE/Setup)
- Shift+F10
- diskpart list volume
- dism /Capture-Image ...

6) Etapa D — Preparar TARGET (UEFI)
- diskpart: clean, convert gpt, EFI=S:, C: NTFS

7) Etapa E — Aplicar WIM + Boot
- dism /Apply-Image ...
- bcdboot C:\Windows /s S: /f UEFI

8) Validação
- OOBE inicia
- winver e apps essenciais presentes

9) Riscos e rollback
- diskpart clean apaga disco
- rollback: snapshot anterior / refazer partições

Rubrica de avaliação

Quanto mais “executável” e auditável, maior a nota.

Scripts Não entrega BATs comentados BATs + validação automática + variáveis de caminho

Meta: atingir Bom em tudo e buscar Excelente em runbook + evidências.

Atividades práticas (2–3)

Atividade 1 — Script com variáveis

Melhore os BATs usando variáveis (IMAGEFILE, CAPTUREDIR, APPLYDIR) e adicionando mensagens e log (append).

Atividade 2 — Falhas comuns (runbook)

Adicione uma seção “erros comuns” (letra de unidade errada, bcdboot, partição EFI) e como identificar e corrigir.

Atividade 3 — Checklist automático (PowerShell)

Crie um PS que verifica se prints/logs esperados existem e gera relatório “OK/FALTA” em TXT.
