Conceitos fundamentais

1) Variáveis e tipos

PHP usa tipagem dinâmica. Os tipos mais comuns neste curso: string, int, float, bool e array. Arrays podem ser indexados (0,1,2,…) ou associativos (chaves de texto). Exemplo:


<?php
$preco = 9.50;                      // float
$nome  = 'Café expresso';        // string
$popular = true;                   // bool
$categorias = ['Bebidas', 'Lanches'];   // array indexado
$item = [                          // array associativo
  'nome'=>'Cappuccino', 
  'preco'=> 9.00, 
  'categoria'=>'Bebidas', 
  'popular'=> true
];

2) Decisões (if/else, switch)

Use if/else para bifurcações e switch quando houver múltiplos casos. Exemplo de selo por categoria:


<?php
function seloCategoria($cat){
  switch($cat){
    case 'Bebidas':  return '🥤';
    case 'Lanches':  return '🥪';
    case 'Sobremesas': return '🍰';
    default: return '🍽️';
  }
}

3) Laços (for, while, foreach)

foreach é ideal para percorrer arrays. for e while se aplicam a contagens e condições específicas.


<?php
$itens = [['nome'=>'X-Salada'],['nome'=>'Pão de queijo']];
foreach($itens as $i){
  echo '- '.htmlspecialchars($i['nome'])."<br>";
}

4) Funções

Funções ajudam a organizar e reutilizar lógica. Usaremos funções para: formatar preço, escapar texto, calcular desconto e agrupar itens por categoria.


<?php
function preco($n){ return 'R$ '.number_format((float)$n,2,",","."); }
function esc($v){ return htmlspecialchars((string)$v, ENT_QUOTES, 'UTF-8'); }

Pesquisas complementares sugeridas

  • Diferenças entre arrays indexados e associativos no PHP.
  • Conversões de tipo comuns (string para número) e var_dump() para inspeção.
  • Dicas de nomenclatura e escopo de variáveis em funções.
  • Boas práticas de DRY (Don't Repeat Yourself) usando funções.

Passo a passo — Cardápio agrupado por categoria com funções

Contexto

Partindo do Cap. 01, agora vamos agrupar o cardápio por categoria e criar funções para formatação, selo de categoria e regras simples (ex.: “popular” e desconto de happy hour).

1) Estrutura base e dados

Edite public/index.php (ou crie public/cardapio.php) com o seguinte conteúdo:


<!-- public/index.php (versão Cap. 02) -->
<?php
  // 1) Dados em memória (sem banco ainda)
  $itens = [
    ['nome'=>'Café expresso',     'preco'=>6.00,  'categoria'=>'Bebidas',   'popular'=>true],
    ['nome'=>'Cappuccino',        'preco'=>9.00,  'categoria'=>'Bebidas',   'popular'=>false],
    ['nome'=>'Suco de laranja',   'preco'=>9.50,  'categoria'=>'Bebidas',   'popular'=>true],
    ['nome'=>'Pão de queijo',     'preco'=>5.50,  'categoria'=>'Lanches',   'popular'=>false],
    ['nome'=>'X-Salada',          'preco'=>18.90, 'categoria'=>'Lanches',   'popular'=>true],
    ['nome'=>'Bolo de chocolate', 'preco'=>7.50,  'categoria'=>'Sobremesas','popular'=>false],
  ];

  // 2) Funções utilitárias
  function esc($v){ return htmlspecialchars((string)$v, ENT_QUOTES, 'UTF-8'); }
  function preco($n){ return 'R$ '.number_format((float)$n, 2, ",", "."); }
  function seloCategoria($cat){
    switch($cat){
      case 'Bebidas': return '🥤';
      case 'Lanches': return '🥪';
      case 'Sobremesas': return '🍰';
      default: return '🍽️';
    }
  }
  function calcularDesconto($preco, $categoria){
    // Exemplo: happy hour em bebidas após 17h (5%)
    $hora = (int)date('H');
    if($categoria === 'Bebidas' && $hora >= 17){
      return (float)$preco * 0.95;
    }
    return (float)$preco;
  }
  function agruparPorCategoria($lista){
    $grupos = [];
    foreach($lista as $i){
      $cat = $i['categoria'] ?? 'Outros';
      if(!isset($grupos[$cat])){ $grupos[$cat] = []; }
      $grupos[$cat][] = $i;
    }
    return $grupos;
  }

  // 3) Filtro opcional por categoria via ?cat=...
  $cat = isset($_GET['cat']) ? (string)$_GET['cat'] : '';
  if($cat !== ''){
    $itens = array_values(array_filter($itens, fn($i) => $i['categoria'] === $cat));
  }

  $grupos = agruparPorCategoria($itens);
?>
<!-- HTML -->
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8"/>
  <meta name="viewport" content="width=device-width, initial-scale=1"/>
  <title>Lanchonete — Cardápio (Agrupado)</title>
  <style>
    body{font-family:Segoe UI,Arial,sans-serif;margin:0;padding:0;background:#fafafa;color:#1b1b1b}

    .grid{display:grid;grid-template-columns:repeat(3,1fr);gap:14px}
    .card{background:#fff;border:1px solid #eee;border-radius:12px;padding:12px;box-shadow:0 2px 8px rgba(0,0,0,.06)}
    .price{font-weight:700;color:#2e7d32}
    .badge{font-size:12px;background:#eee;border-radius:999px;padding:2px 8px;margin-left:6px}
    .popular{background:#ffe0b2}
    @media (max-width:768px){.grid{grid-template-columns:1fr}}
  </style>
</head>
<body>
  <header><h1>Lanchonete — Cardápio (Agrupado)</h1></header>
  <main>

  <p>
    Filtrar por: 
    <a href="index.php">Tudo</a> | 
    <a href="index.php?cat=Bebidas">Bebidas</a> | 
    <a href="index.php?cat=Lanches">Lanches</a> | 
    <a href="index.php?cat=Sobremesas">Sobremesas</a>
  </p>

  <?php $contador = 0; ?>
  <?php foreach($grupos as $categoria => $lista): ?>
    <div class="grupo">
      <h2><?= esc($categoria) ?> <span><?= seloCategoria($categoria) ?></span></h2>
      <div class="grid">
        <?php foreach($lista as $i): 
          $contador++; 
          $precoFinal = calcularDesconto($i['preco'], $i['categoria']);
          $temDesconto = ($precoFinal < $i['preco']);
        ?>
          <div class="card">
            <h3><?= esc($i['nome']) ?>
              <?php if(!empty($i['popular'])): ?>
                <span class="badge popular">Popular</span>
              <?php endif; ?>
            </h3>

            <p class="price">
              <?= preco($precoFinal) ?>
              <?php if($temDesconto): ?>
                <small>(de <s><?= preco($i['preco']) ?></s>)</small>

Atividades práticas (para concluir na aula seguinte)

  1. Contadores e médias: exiba a quantidade de itens por categoria e o preço médio da categoria, usando foreach e funções auxiliares (ex.: mediaCategoria($grupos)).
