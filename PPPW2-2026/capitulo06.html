Capítulo 06 — CRUD (Bebidas) com Prepared, Validação e Prevenção de SQLi/XSS

Implemente um CRUD completo de Bebidas usando PDO (prepared statements), validação no servidor e escape correto no HTML.

Bimestre 2 Carga: ~100 min Entrega (parcial): CRUD de Bebidas funcional
← Cap. 05 Cap. 07 → Índice

Ao final você será capaz de:

  • Construir páginas de listar, criar, editar e excluir (CRUD) com PHP + MySQL (PDO).
  • Aplicar validações e mensagens de erro no servidor.
  • Usar prepared statements e escape de saída para evitar SQL Injection e XSS.
  • Organizar o código em DAO simples e reutilizar utilitários (flash e CSRF opcional).

Objetivos de aprendizagem

  • Mapear o CRUD para a tabela item (filtrando a categoria “Bebidas”).
  • Escrever INSERT/UPDATE/DELETE parametrizados.
  • Implementar validações de nome, preço e categoria.
  • Proteger saídas com htmlspecialchars().
  • Organizar o projeto em config/, src/DAO/ e public/.
  • (Opcional) Adicionar token CSRF e mensagens flash.

Onde será aplicado: Um CRUD de Bebidas na lanchonete: listar, buscar, criar, editar e excluir itens da categoria “Bebidas”.

Conceitos fundamentais

1) CRUD e Prepared Statements

CRUD são operações básicas de dados: Create (INSERT), Read (SELECT), Update (UPDATE) e Delete (DELETE). Em PHP (PDO), sempre use prepared statements (prepare() + execute() com parâmetros) para evitar SQL Injection.

2) Validação e Sanitização

  • Valide no servidor: tamanho de nome, formato e faixas de preço, existência da categoria.
  • Ao imprimir no HTML, faça escape com htmlspecialchars() para evitar XSS.

3) Organização mínima

Separe conexão (config/db.php), acesso a dados (src/DAO) e páginas públicas (public/). Isso facilita manutenção e evolução (Cap. 10 — camadas mais formais).

Pesquisas complementares sugeridas

  • Diferença entre bindValue e execute com array de parâmetros.
  • Tratamento de erros: try/catch, códigos de status HTTP e mensagens amigáveis.
  • Princípios de UX em formulários (feedback de sucesso/erro, preservação de dados ao falhar).

2) DAO para Bebidas — src/DAO/BebidaDAO.php


<!-- src/DAO/BebidaDAO.php -->
<?php
declare(strict_types=1);

class BebidaDAO {
  private PDO $pdo;
  private int $bebidasCatId;
  public function __construct(PDO $pdo, int $bebidasCatId){
    $this->pdo = $pdo;
    $this->bebidasCatId = $bebidasCatId;
  }

  public function listar(?string $q=null): array {
    $sql = "SELECT i.id,i.nome,i.preco,i.popular,c.nome AS categoria
            FROM item i JOIN categoria c ON c.id=i.categoria_id
            WHERE i.categoria_id=:cid";
    $params = [':cid'=>$this->bebidasCatId];
    if($q){
      $sql .= " AND i.nome LIKE :q";
      $params[':q'] = '%'.$q.'%';
    }
    $sql .= " ORDER BY i.nome";
    $st = $this->pdo->prepare($sql);
    $st->execute($params);
    return $st->fetchAll();
  }

  public function buscarPorId(int $id): ?array {
    $sql = "SELECT id,nome,preco,popular FROM item WHERE id=:id AND categoria_id=:cid";
    $st = $this->pdo->prepare($sql);
    $st->execute([':id'=>$id, ':cid'=>$this->bebidasCatId]);
    $r = $st->fetch();
    return $r ?: null;
  }

  public function criar(string $nome, float $preco, int $popular=0): int {
    $sql = "INSERT INTO item (nome,preco,categoria_id,popular) VALUES (:n,:p,:cid,:pop)";
    $st = $this->pdo->prepare($sql);
    $st->execute([':n'=>$nome, ':p'=>$preco, ':cid'=>$this->bebidasCatId, ':pop'=>$popular]);
    return (int)$this->pdo->lastInsertId();
  }

  public function atualizar(int $id, string $nome, float $preco, int $popular=0): bool {
    $sql = "UPDATE item SET nome=:n, preco=:p, popular=:pop WHERE id=:id AND categoria_id=:cid";
    $st = $this->pdo->prepare($sql);
    return $st->execute([':n'=>$nome, ':p'=>$preco, ':pop'=>$popular, ':id'=>$id, ':cid'=>$this->bebidasCatId]);
  }

  public function excluir(int $id): bool {
    $sql = "DELETE FROM item WHERE id=:id AND categoria_id=:cid";
    $st = $this->pdo->prepare($sql);
    return $st->execute([':id'=>$id, ':cid'=>$this->bebidasCatId]);
  }
}

3) Utilitários (opcional) — Flash e CSRF


<!-- src/App/Flash.php -->
<?php
class Flash {
  public static function start(){ if(session_status()!==PHP_SESSION_ACTIVE) session_start(); }
  public static function set(string $msg, string $type='ok'){ self::start(); $_SESSION['flash']=['m'=>$msg,'t'=>$type]; }
  public static function get(): ?array {
    self::start(); $f = $_SESSION['flash'] ?? null; unset($_SESSION['flash']); return $f;
  }
}
          

<!-- src/App/Csrf.php -->
<?php
class Csrf {
  public static function start(){ if(session_status()!==PHP_SESSION_ACTIVE) session_start(); }
  public static function token(): string {
    self::start(); if(empty($_SESSION['csrf'])) $_SESSION['csrf']=bin2hex(random_bytes(16)); return $_SESSION['csrf'];
  }
  public static function check(string $t): bool {
    self::start(); return hash_equals($_SESSION['csrf'] ?? '', $t);
  }
}

6) Salvar (create/update) — public/bebidas_save.php


<!-- public/bebidas_save.php -->
<?php
require_once __DIR__.'/../config/db.php';
require_once __DIR__.'/../src/DAO/BebidaDAO.php';
require_once __DIR__.'/../src/App/Flash.php';
require_once __DIR__.'/../src/App/Csrf.php';

function redirect($to){ header('Location: '.$to); exit; }

try{
  if(($_SERVER['REQUEST_METHOD'] ?? '')!=='POST'){ http_response_code(405); exit('Método não permitido'); }
  $csrf = (string)($_POST['csrf'] ?? '');
  if(!Csrf::check($csrf)){ Flash::set('CSRF inválido. Recarregue o formulário.','err'); redirect('bebidas_index.php'); }

  $pdo = pdo();
  $rid = $pdo->query("SELECT id FROM categoria WHERE nome='Bebidas'")->fetch();
  if(!$rid){ throw new RuntimeException('Categoria "Bebidas" não encontrada.'); }
  $dao = new BebidaDAO($pdo, (int)$rid['id']);

  $id = filter_input(INPUT_POST,'id',FILTER_VALIDATE_INT);
  $nome = trim((string)($_POST['nome'] ?? ''));
  $preco = (string)($_POST['preco'] ?? '');
  $popular = (int)($_POST['popular'] ?? 0);

  // Validações
  $erros = [];
  if(mb_strlen($nome) < 3 || mb_strlen($nome) > 80){ $erros[]='Nome deve ter entre 3 e 80 caracteres.'; }
  $preco = str_replace(',','.', $preco);
  if(!is_numeric($preco) || (float)$preco <= 0){ $erros[]='Preço deve ser número positivo.'; }
  if($popular!==0 && $popular!==1){ $erros[]='Valor de "popular" inválido.'; }

  if($erros){
    Flash::set('Falha na validação: '.implode(' ', $erros),'err');
    redirect('bebidas_index.php');
  }

  if($id){
    $ok = $dao->atualizar((int)$id, $nome, (float)$preco, $popular);
    Flash::set($ok?'Bebida atualizada com sucesso.':'Nenhuma alteração aplicada.');
  }else{
    $novoId = $dao->criar($nome,(float)$preco,$popular);
    Flash::set('Bebida criada (ID '.$novoId.').');
  }
  redirect('bebidas_index.php');

}catch(Throwable $e){
  Flash::set('Erro ao salvar: '.$e->getMessage(),'err');
  redirect('bebidas_index.php');
}
