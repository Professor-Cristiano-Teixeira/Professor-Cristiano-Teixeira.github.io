Capítulo 01 — Arquitetura Web e Ambiente (XAMPP)

Fundamentos de scripts no lado do servidor, geração dinâmica de páginas e configuração do ambiente de desenvolvimento com Windows + VS Code + XAMPP (Apache/PHP/MySQL) para o projeto-guia da lanchonete.

Bimestre 1 Carga: ~100 min Entrega: Página dinâmica inicial
Próximo capítulo → Voltar ao índice

Ao final você será capaz de:

  • Explicar a arquitetura cliente–servidor e o papel de scripts no lado do servidor (PHP).
  • Configurar o XAMPP e o VS Code para desenvolver aplicações web locais.
  • Criar uma página dinâmica em PHP que renderiza um cardápio da lanchonete a partir de uma estrutura de dados (sem banco).
  • Entender onde QueryString e diretórios públicos (document root) se encaixam no projeto.

Objetivos de aprendizagem

  • Compreender o fluxo HTTP request/response entre navegador e servidor.
  • Reconhecer camadas básicas da aplicação (navegador, servidor web, aplicação PHP).
  • Preparar o ambiente com XAMPP (Apache/PHP/MySQL) e MySQL Workbench.
  • Criar a estrutura de pastas do projeto da lanchonete.
  • Produzir uma página dinâmica com PHP, imprimindo dados a partir de um array.
  • Praticar boas práticas iniciais (ex.: htmlspecialchars, separação de arquivos).
  • Testar a aplicação localmente via http://localhost.

Onde será aplicado: Neste capítulo, os conceitos são aplicados criando a homepage da lanchonete, renderizando uma lista de itens do cardápio dinamicamente (sem banco ainda).

Conceitos fundamentais

1) Arquitetura Web em camadas

Em uma aplicação Web típica há, no mínimo, três camadas: o cliente (navegador), o servidor Web e a aplicação. O cliente solicita páginas via HTTP. O servidor Web (Apache, no XAMPP) recebe a requisição e encaminha para o PHP quando o recurso solicitado for um script. O PHP executa o código, acessa dados (por ora em memória; mais adiante, em banco) e gera HTML dinamicamente como resposta. 


# Cliente (Navegador)  →  Servidor Web (Apache)  →  Aplicação (PHP)  →  Banco (futuro)
#            HTTP GET/POST           roteia                 executa código     persiste/consulta

Aplicação no passo a passo: você criará um script PHP que roda no Apache (XAMPP) e monta a página da lanchonete a partir de um array.

2) Scripts no lado do servidor (PHP) e geração dinâmica

Diferente do JavaScript no navegador (lado do cliente), o PHP é executado no servidor. O resultado é HTML puro que o navegador entende. A grande vantagem é poder gerar conteúdo dinâmico (por exemplo, iterar uma lista de itens e montar cards automaticamente) e, futuramente, persistir ou consultar dados no banco. 


<?php
  // Dentro do PHP você monta o HTML conforme os dados disponíveis
  $itens = [
    ["nome" => "Café expresso", "preco" => 6.00],
    ["nome" => "Suco de laranja", "preco" => 9.50]
  ];
?>
<ul>
  <?php foreach($itens as $i): ?>
    <li><?= htmlspecialchars($i["nome"]) ?> — R$ <?= number_format($i["preco"],2,",",".") ?></li>
  <?php endforeach; ?>
</ul>

Aplicação no passo a passo: usamos um array em PHP para listar bebidas e lanches.

3) Conjunto de tecnologias

  • Marcação: HTML para estrutura do conteúdo.
  • Estilo: CSS para aparência.
  • Scripts no cliente: JavaScript (interatividade no navegador, usaremos depois para AJAX).
  • Scripts no servidor: PHP (lógica, regras, acesso a dados).

Aplicação no passo a passo: PHP produzirá o HTML; CSS/JS ficam como base para capítulos seguintes.

Pesquisas complementares sugeridas

  • Como o Apache (XAMPP) encaminha .php para o interpretador PHP.
  • Document root vs. diretórios privados (public/ x src/).
  • O que é HTTP e diferenças entre GET e POST (introdução; aprofundaremos no Cap. 03).
  • Boas práticas de saída no PHP: htmlspecialchars e number_format.

Passo a passo — Ambiente e primeira página dinâmica (lanchonete)

Pré-requisitos

  • Windows com XAMPP instalado (Apache + PHP + MySQL).
  • VS Code com a extensão “PHP Intelephense” (sugerido).
  • Navegador (Chrome/Edge/Firefox).

1) Inicie o XAMPP

  1. Abra o XAMPP Control Panel.
  2. Clique em Start no Apache (e no MySQL, embora ainda não o usemos neste capítulo).
  3. Teste: acesse http://localhost/ no navegador para ver a página padrão do XAMPP.

2) Estrutura de pastas do projeto

Dentro de C:\xampp\htdocs\, crie a pasta lanchonete com a seguinte estrutura:


htdocs/
└── lanchonete/
    ├── public/
    │   └── index.php
    ├── src/
    ├── config/
    └── assets/

3) Primeira página dinâmica (public/index.php)

Abra o VS Code na pasta lanchonete e crie o arquivo public/index.php com o conteúdo abaixo:


<!-- public/index.php -->
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8"/>
  <meta name="viewport" content="width=device-width, initial-scale=1"/>
  <title>Lanchonete — Cardápio</title>
  <style>
    body{font-family:Segoe UI,Arial,sans-serif;margin:0;padding:0;background:#fafafa;color:#1b1b1b}
    header{background:#c62828;color:#fff;padding:14px 18px}
    main{max-width:960px;margin:0 auto;padding:18px}
    .grid{display:grid;grid-template-columns:repeat(3,1fr);gap:14px}
    .card{background:#fff;border:1px solid #eee;border-radius:12px;padding:12px;box-shadow:0 2px 8px rgba(0,0,0,.06)}
    .price{font-weight:700;color:#2e7d32}
    @media (max-width:768px){.grid{grid-template-columns:1fr}}
  </style>
</head>
<body>
  <header><h1>Lanchonete — Cardápio (Dinâmico)</h1></header>
  <main>
  <?php
    // Exemplo simples: lista em memória (sem banco por enquanto)
    $itens = [
      ['nome'=>'Café expresso', 'preco'=>6.00, 'categoria'=>'Bebidas'],
      ['nome'=>'Cappuccino',    'preco'=>9.00, 'categoria'=>'Bebidas'],
      ['nome'=>'Suco de laranja','preco'=>9.50, 'categoria'=>'Bebidas'],
      ['nome'=>'Pão de queijo', 'preco'=>5.50, 'categoria'=>'Lanches'],
      ['nome'=>'X-Salada',      'preco'=>18.90,'categoria'=>'Lanches'],
      ['nome'=>'Bolo de chocolate','preco'=>7.50,'categoria'=>'Sobremesas'],
    ];

    // Função de saída segura + formatação
    function esc($v){ return htmlspecialchars((string)$v, ENT_QUOTES, 'UTF-8'); }
    function preco($n){ return 'R$ '.number_format((float)$n, 2, ",", "."); }

    // (Opcional) Filtro simples por categoria via ?cat=Bebidas (Cap. 03 aprofunda GET/POST)
    $cat = isset($_GET['cat']) ? (string)$_GET['cat'] : '';
    if($cat !== ''){
      $itens = array_values(array_filter($itens, fn($i) => $i['categoria'] === $cat));
    }
  ?>

  <h2>Cardápio <?= $cat ? '— Categoria: '.esc($cat) : '' ?></h2>

  <p>
    Filtrar por: 
    <a href="index.php">Tudo</a> | 
    <a href="index.php?cat=Bebidas">Bebidas</a> | 
    <a href="index.php?cat=Lanches">Lanches</a> | 
    <a href="index.php?cat=Sobremesas">Sobremesas</a>
  </p>

  <div class="grid">
    <?php foreach($itens as $i): ?>
      <div class="card">
        <h3><?= esc($i['nome']) ?></h3>
        <p class="price"><?= preco($i['preco']) ?></p>
        <small>Categoria: <?= esc($i['categoria']) ?></small>
      </div>
    <?php endforeach; ?>
  </div>

  </main>
</body>
</html>

4) Teste no navegador

  1. Acesse: http://localhost/lanchonete/public/index.php.
  2. Troque o filtro pela QueryString: ?cat=Bebidas, ?cat=Lanches, etc.

5) (Opcional) Ative mensagens de erro em desenvolvimento

Adicione no topo do index.php (apenas para estudo/local):


<?php
  ini_set('display_errors', '1');
  error_reporting(E_ALL);
?>

6) (Opcional) Separando cabeçalho e rodapé

Crie src/View/header.php e src/View/footer.php com o HTML comum e, em index.php, use:


<?php // no início do body include __DIR__.'/../src/View/header.php'; ?>
... // conteúdo da página ...
<?php include __DIR__.'/../src/View/footer.php'; ?>
Resumo do que praticamos: arquitetura cliente-servidor, execução de scripts PHP no Apache (XAMPP), geração dinâmica de HTML, uso simples de QueryString e boas práticas de saída (escape).

Atividades práticas (para concluir na aula seguinte)

  1. Cardápio por seções: adapte o index.php para exibir os itens agrupados por categoria (ex.: título “Bebidas”, “Lanches”, “Sobremesas”, cada um com seus itens).
  2. Includes reutilizáveis: extraia o cabeçalho e o rodapé para header.php e footer.php (em src/View/) e faça o include no index.php.
  3. Novo item e formatação: acrescente 3 novos produtos ao array (com preço) e ajuste a formatação do preço (ex.: R$ 12,50) em toda a listagem, usando a função preco().

Dica: mantenha a organização de pastas; isso facilitará os próximos capítulos (CRUDs e banco de dados).
