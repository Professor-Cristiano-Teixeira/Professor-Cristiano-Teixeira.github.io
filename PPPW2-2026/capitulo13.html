Capítulo 13 — Fetch/AJAX e JSON (Comunicação Assíncrona)

Você vai aprender a fazer o navegador conversar com o servidor sem recarregar a página usando Fetch/AJAX e JSON. Vamos aplicar isso na lanchonete para adicionar itens ao carrinho e atualizar totais em tempo real.

Ao final você será capaz de:

  • Trocar dados em JSON entre front-end e PHP.
  • Criar endpoints PHP que respondem JSON com status HTTP correto.
  • Atualizar partes da tela (carrinho/total) sem recarregar a página.

Objetivos de aprendizagem

  • Tratar respostas JSON e atualizar o DOM.
  • Padronizar respostas com status e mensagens.

  • Aplicar no projeto da lanchonete.

Conceitos fundamentais

1) O que é AJAX / Fetch?

AJAX é o nome comum para “fazer requisições ao servidor sem recarregar a página”. Hoje, o jeito mais comum no JavaScript moderno é usar fetch().

2) JSON

JSON é um formato leve para troca de dados. No PHP, usamos json_encode() para responder e json_decode() para interpretar dados recebidos.

3) Boas práticas de endpoints

  • Definir Content-Type: application/json.
  • Retornar códigos HTTP coerentes (200, 201, 400, 401, 500…).
  • Não retornar HTML; retornar apenas JSON.
  • Validar dados no servidor e tratar erros com mensagem clara.

Pesquisas complementares sugeridas

  • Diferença entre fetch() e XMLHttpRequest.
  • O que é CORS e quando ele é necessário.
  • Como usar async/await com fetch.

Passo a passo — Adicionar ao carrinho via Fetch (JSON)

Visão geral

Vamos criar um endpoint public/api/carrinho_add.php que recebe JSON (id e qtd), busca o item no banco (fonte da verdade), adiciona ao carrinho (session) e retorna JSON com o novo total.

2) Endpoint: adicionar item (POST JSON) — public/api/carrinho_add.php

<!-- public/api/carrinho_add.php -->
<?php
require_once __DIR__.'/../../config/db.php';
require_once __DIR__.'/../../src/App/SessionCart.php';
use App\SessionCart;

header('Content-Type: application/json; charset=utf-8');

if(($_SERVER['REQUEST_METHOD'] ?? '') !== 'POST'){
  http_response_code(405);
  echo json_encode(['ok'=>false,'error'=>'Método não permitido']);
  exit;
}

$raw = file_get_contents('php://input');
$data = json_decode($raw, true);

$id  = isset($data['id']) ? (int)$data['id'] : 0;
$qtd = isset($data['qtd']) ? (int)$data['qtd'] : 1;
$qtd = max(1, $qtd);

if($id <= 0){
  http_response_code(400);
  echo json_encode(['ok'=>false,'error'=>'ID inválido']);
  exit;
}

try{
  $pdo = pdo();
  $st = $pdo->prepare('SELECT id,nome,preco FROM item WHERE id=:id');
  $st->execute([':id'=>$id]);
  $it = $st->fetch();

  if(!$it){
    http_response_code(404);
    echo json_encode(['ok'=>false,'error'=>'Item não encontrado']);
    exit;
  }

  SessionCart::start();
  SessionCart::add((string)$it['id'], (string)$it['nome'], (float)$it['preco'], $qtd);

  $total = SessionCart::total();
  $items = SessionCart::items();
  $count = 0;
  foreach($items as $x){ $count += (int)$x['qtd']; }

  echo json_encode([
    'ok'=>true,
    'message'=>'Item adicionado',
    'cart'=>[
      'count'=>$count,
      'total'=>$total
    ]
  ]);
}catch(Throwable $e){
  http_response_code(500);
  echo json_encode(['ok'=>false,'error'=>'Erro no servidor']);
}

4) JavaScript (Fetch) — public/assets/app.js

<!-- public/assets/app.js -->
// Utilitário de moeda simples (pt-BR)
function moedaBR(v){
  return new Intl.NumberFormat('pt-BR', {style:'currency', currency:'BRL'}).format(v);
}

// Atualiza “badge” do carrinho no topo (se existir)
function atualizarResumoCarrinho(cart){
  const elCount = document.querySelector('[data-cart-count]');
  const elTotal = document.querySelector('[data-cart-total]');
  if(elCount) elCount.textContent = cart.count;
  if(elTotal) elTotal.textContent = moedaBR(cart.total);
}

// Carrega resumo inicial do carrinho
async function carregarResumo(){
  try{
    const res = await fetch('api/carrinho_resumo.php', {headers:{'Accept':'application/json'}});
    const json = await res.json();
    if(json.ok) atualizarResumoCarrinho(json.cart);
  }catch(e){}
}

// Handler para botões “Adicionar”
async function adicionarAoCarrinho(id, qtd=1){
  const payload = {id:Number(id), qtd:Number(qtd)};
  const res = await fetch('api/carrinho_add.php', {
    method:'POST',
    headers:{'Content-Type':'application/json','Accept':'application/json'},
    body: JSON.stringify(payload)
  });

  const json = await res.json();
  if(!json.ok){
    alert(json.error || 'Falha ao adicionar');
    return;
  }
  atualizarResumoCarrinho(json.cart);
}

// Liga eventos nos botões com data-add-cart
function bindBotoes(){
  document.querySelectorAll('[data-add-cart]').forEach(btn => {
    btn.addEventListener('click', async (e) => {
      e.preventDefault();
      const id = btn.getAttribute('data-add-cart');
      const qtdInputSel = btn.getAttribute('data-qtd-input');
      let qtd = 1;
      if(qtdInputSel){
        const inp = document.querySelector(qtdInputSel);
        if(inp) qtd = Number(inp.value || 1);
      }
      await adicionarAoCarrinho(id, qtd);
    });
  });
}

document.addEventListener('DOMContentLoaded', () => {
  carregarResumo();
  bindBotoes();
});

5) Ajuste no catálogo (HTML) — botão “Adicionar” assíncrono

No seu public/catalogo_db.php, troque o form “Adicionar” por um botão com data-add-cart. Inclua também um “resumo do carrinho” no topo. 

<!-- (trecho) topo de public/catalogo_db.php -->
<div style="display:flex;gap:10px;align-items:center;justify-content:space-between;flex-wrap:wrap">
  <div><a href="carrinho.php">Carrinho</a></div>
  <div>
    Itens: <strong data-cart-count>0</strong> • Total: <strong data-cart-total>R$ 0,00</strong>
  </div>
</div>

<!-- inclua o script no final da página -->
<script src="assets/app.js"></script>
          
<!-- (trecho) dentro do loop de itens -->
<input type="number" min="1" value="1" id="qtd-{{ID}}" style="width:70px" />
<button data-add-cart="{{ID}}" data-qtd-input="#qtd-{{ID}}">Adicionar</button>

Observação: no trecho acima, substitua {{ID}} pelo ID real do item (ex.: <?= (int)$i['id'] ?>) no seu PHP.

Resumo: Agora seu catálogo adiciona itens ao carrinho via Fetch/JSON e atualiza contagem/total sem recarregar a página.

Atividades práticas (para concluir na aula seguinte)

Dica: mantenha respostas JSON padronizadas: { ok, message, error, cart }.
