Capítulo 10 — Arquitetura em Camadas (DAO, Serviços/BO e Controladores)

Refatore o projeto para uma arquitetura em camadas: DAO (acesso a dados), Serviços/BO (regras de negócio) e Controladores (fluxo web). Trate erros/exceções e use transações para operações atômicas.

Bimestre 3 Carga: ~100 min Entrega (parcial): CRUD refatorado em camadas
← Cap. 09 Cap. 11 → Índice

Ao final você será capaz de:

  • Separar responsabilidades entre DAO, Serviços (BO) e Controladores.
  • Centralizar regras de negócio (ex.: validações e políticas) na camada de serviço.
  • Tratar exceções e retornar mensagens amigáveis ao usuário.
  • Usar transações em operações que exigem atomicidade.

Objetivos de aprendizagem

  • Definir camadas e responsabilidades (DAO/Serviço/Controlador).
  • Refatorar CRUDs (Bebidas/Categorias) usando Serviços.
  • Implementar transações no PDO.
  • Padronizar tratamento de erros e mensagens (Flash).
  • (Opcional) Criar um roteador simples para controllers.

Onde será aplicado: Nos CRUDs criados (Cap. 06–08), agora usando Serviços para encapsular regras/validações e Controladores para orquestrar a web.

Conceitos fundamentais

1) Por que camadas?

Separar responsabilidades facilita manutenção, testes e evolução. O DAO foca em SQL, o Serviço/BO aplica regras e orquestra DAOs, e o Controlador mapeia requisições HTTP e respostas (redireciona, envia views).

2) Onde ficam as regras de negócio?

Em Serviços (Business Objects). Validações (ex.: limites de preço), políticas (ex.: não permitir excluir categoria em uso) e fluxos (ex.: transações) moram aqui.

3) Transações

Em operações múltiplas (várias tabelas ou vários updates), use transações para garantir tudo-ou-nada com $pdo->beginTransaction(), commit() e rollBack().

Passo a passo — DAO ➜ Serviços/BO ➜ Controladores

1) Serviço (BO) para Bebidas — src/Service/BebidaService.php

<!-- src/Service/BebidaService.php -->
<?php
declare(strict_types=1);

class BebidaService {
  private PDO $pdo;
  private BebidaDAO $dao;
  private int $catId;

  public function __construct(PDO $pdo, BebidaDAO $dao, int $categoriaBebidasId){
    $this->pdo = $pdo;
    $this->dao = $dao;
    $this->catId = $categoriaBebidasId;
  }

  /** Regras de negócio de criação */
  public function criar(string $nome, string $precoStr, int $popular=0): int {
    $nome = trim($nome);
    $this->validarNome($nome);
    $preco = $this->parsePreco($precoStr);
    $this->validarPreco($preco);
    return $this->dao->criar($nome, $preco, $popular);
  }

  /** Regras de negócio de atualização */
  public function atualizar(int $id, string $nome, string $precoStr, int $popular=0): bool {
    if($id <= 0){ throw new InvalidArgumentException('ID inválido.'); }
    $nome = trim($nome);
    $this->validarNome($nome);
    $preco = $this->parsePreco($precoStr);
    $this->validarPreco($preco);
    return $this->dao->atualizar($id, $nome, $preco, $popular);
  }

  /** Regras para exclusão */
  public function excluir(int $id): bool {
    if($id <= 0){ throw new InvalidArgumentException('ID inválido.'); }
    return $this->dao->excluir($id);
  }

  /** Busca/lista repassadas ao DAO */
  public function listar(?string $q=null): array { return $this->dao->listar($q); }
  public function buscarPorId(int $id): ?array { return $this->dao->buscarPorId($id); }

  /** Transação de exemplo: reajuste percentual em todas as bebidas */
  public function reajustarPrecos(float $percent): int {
    if($percent <= -100){ throw new InvalidArgumentException('Percentual inválido.'); }
    $this->pdo->beginTransaction();
    try{
      $atualizados = 0;
      $rows = $this->dao->listar(null);
      foreach($rows as $r){
        $novo = round(((float)$r['preco']) * (1 + $percent/100), 2);
        $this->validarPreco($novo);
        $this->dao->atualizar((int)$r['id'], (string)$r['nome'], $novo, (int)$r['popular']);
        $atualizados++;
      }
      $this->pdo->commit();
      return $atualizados;
    }catch(Throwable $e){
      $this->pdo->rollBack();
      throw $e;
    }
  }

  /* ===== Validações (regras) ===== */
  private function validarNome(string $nome): void {
    if(mb_strlen($nome) < 3 || mb_strlen($nome) > 80){
      throw new InvalidArgumentException('Nome deve ter entre 3 e 80 caracteres.');
    }
  }
  private function parsePreco(string $v): float {
    $v = str_replace(',', '.', $v);
    if(!is_numeric($v)){ throw new InvalidArgumentException('Preço inválido.'); }
    return (float)$v;
  }
  private function validarPreco(float $n): void {
    if($n <= 0){ throw new InvalidArgumentException('Preço deve ser > 0.'); }
  }
}

2) Controlador para Bebidas — public/controllers/bebidas_controller.php

<!-- public/controllers/bebidas_controller.php -->
<?php
require_once __DIR__.'/../../config/db.php';
require_once __DIR__.'/../../src/DAO/BebidaDAO.php';
require_once __DIR__.'/../../src/Service/BebidaService.php';
require_once __DIR__.'/../../src/App/Flash.php';
require_once __DIR__.'/../../src/App/Csrf.php';

function redirect(string $to){ header('Location: '.$to); exit; }

try{
  $pdo = pdo();
  $rid = $pdo->query("SELECT id FROM categoria WHERE nome='Bebidas'")->fetch();
  if(!$rid){ throw new RuntimeException('Categoria Bebidas não encontrada.'); }
  $dao = new BebidaDAO($pdo, (int)$rid['id']);
  $svc = new BebidaService($pdo, $dao, (int)$rid['id']);

  $action = $_GET['a'] ?? $_POST['a'] ?? 'index';

  if($action === 'create' && ($_SERVER['REQUEST_METHOD'] ?? '')==='POST'){
    if(!Csrf::check((string)($_POST['csrf'] ?? ''))) throw new RuntimeException('CSRF inválido.');
    $id = $svc->criar((string)($_POST['nome']??''),(string)($_POST['preco']??''),(int)($_POST['popular']??0));
    Flash::set('Bebida criada (ID '.$id.').');
    redirect('../bebidas_index.php');
  }

  if($action === 'update' && ($_SERVER['REQUEST_METHOD'] ?? '')==='POST'){
    if(!Csrf::check((string)($_POST['csrf'] ?? ''))) throw new RuntimeException('CSRF inválido.');
    $ok = $svc->atualizar((int)($_POST['id']??0),(string)($_POST['nome']??''),(string)($_POST['preco']??''),(int)($_POST['popular']??0));
    Flash::set($ok?'Bebida atualizada.':'Nenhuma alteração aplicada.');
    redirect('../bebidas_index.php');
  }

  if($action === 'delete' && ($_SERVER['REQUEST_METHOD'] ?? '')==='POST'){
    $ok = $svc->excluir((int)($_POST['id']??0));
    Flash::set($ok?'Bebida excluída.':'Não foi possível excluir.');
    redirect('../bebidas_index.php');
  }

  if($action === 'reajuste' && ($_SERVER['REQUEST_METHOD'] ?? '')==='POST'){
    if(!Csrf::check((string)($_POST['csrf'] ?? ''))) throw new RuntimeException('CSRF inválido.');
    $n = $svc->reajustarPrecos((float)($_POST['percent']??0));
    Flash::set('Preços reajustados em '.$_POST['percent'].'% ('.$n.' item(ns)).');
    redirect('../bebidas_index.php');
  }

  // default index: somente exemplo (a listagem continua em ../bebidas_index.php)
  redirect('../bebidas_index.php');

}catch(Throwable $e){
  Flash::set('Erro: '.$e->getMessage(),'err');
  redirect('../bebidas_index.php');
}

4) Serviço para Categorias — regra de unicidade e bloqueio de exclusão

<!-- src/Service/CategoriaService.php -->
<?php
declare(strict_types=1);

class CategoriaService {
  private PDO $pdo;
  private CategoriaDAO $dao;

  public function __construct(PDO $pdo, CategoriaDAO $dao){
    $this->pdo = $pdo;
    $this->dao = $dao;
  }

  public function criar(string $nome): int {
    $nome = trim($nome);
    $this->validarNome($nome);
    try{
      return $this->dao->criar($nome);
    }catch(PDOException $e){
      if($e->getCode()==='23000'){ throw new RuntimeException('Nome já existente.'); }
      throw $e;
    }
  }

  public function atualizar(int $id, string $nome): bool {
    if($id <= 0) throw new InvalidArgumentException('ID inválido.');
    $nome = trim($nome);
    $this->validarNome($nome);
    try{
      return $this->dao->atualizar($id, $nome);
    }catch(PDOException $e){
      if($e->getCode()==='23000'){ throw new RuntimeException('Nome já existente.'); }
      throw $e;
    }
  }

  public function excluir(int $id): bool {
    if($id <= 0) throw new InvalidArgumentException('ID inválido.');
    // Bloqueia exclusão se houver itens vinculados
    $st = $this->pdo->prepare("SELECT COUNT(*) t FROM item WHERE categoria_id=:id");
    $st->execute([':id'=>$id]);
    if(((int)$st->fetch()['t']) > 0){
      throw new RuntimeException('Não é possível excluir: categoria em uso.');
    }
    return $this->dao->excluir($id);
  }

  private function validarNome(string $nome): void {
    if(mb_strlen($nome) < 3 || mb_strlen($nome) > 60){
      throw new InvalidArgumentException('Nome deve ter entre 3 e 60 caracteres.');
    }
  }
}

Atividades práticas (para concluir na aula seguinte)

  1. Refatoração completa: mova todas as validações de Bebidas/Categorias para os Serviços.
  2. Transação com múltiplas tabelas: crie uma rotina (em Serviço) que duplique uma categoria e reatribua itens, garantindo atomicidade.
  3. Mensagens padrão: padronize mensagens de erro/sucesso (Flash) nos controladores.

Dica: evite acoplamento entre camadas. Controladores só chamam Serviços; Serviços usam DAOs.
