Conceitos fundamentais

1) Paginação (LIMIT/OFFSET)

Paginar evita carregar muitos registros de uma vez, melhora performance e UX. A fórmula comum é: LIMIT :pageSize OFFSET :skip, onde skip = (page-1) * pageSize. 

<?php
$page = max(1, (int)($_GET['page'] ?? 1));
$pageSize = min(50, max(1, (int)($_GET['ps'] ?? 6))); // trava 1..50
$skip = ($page - 1) * $pageSize;

$stmt = $pdo->prepare("SELECT ... FROM ... WHERE ... ORDER BY nome LIMIT :ps OFFSET :sk");
$stmt->bindValue(':ps', $pageSize, PDO::PARAM_INT);
$stmt->bindValue(':sk', $skip, PDO::PARAM_INT);
$stmt->execute();

2) Busca com LIKE parametrizado

Para filtrar por nome, use LIKE com parâmetro. Nunca concatene diretamente o termo.

<?php
$q = trim((string)($_GET['q'] ?? ''));
$sql = "SELECT id,nome FROM categoria WHERE 1=1";
$params = [];
if($q !== ''){ $sql .= " AND nome LIKE :q"; $params[':q'] = '%'.$q.'%'; }

3) Tratamento de duplicidade (UNIQUE)

Se a coluna nome for UNIQUE, ao tentar inserir um nome repetido capture a exceção (SQLSTATE 23000) e informe o usuário.

2) DAO de Categoria — src/DAO/CategoriaDAO.php

<!-- src/DAO/CategoriaDAO.php -->
<?php
declare(strict_types=1);
class CategoriaDAO {
  private PDO $pdo;
  public function __construct(PDO $pdo){ $this->pdo = $pdo; }

  public function contar(?string $q=null): int {
    $sql = "SELECT COUNT(*) AS t FROM categoria WHERE 1=1";
    $p = [];
    if($q){ $sql.=" AND nome LIKE :q"; $p[':q'] = '%'.$q.'%'; }
    $st = $this->pdo->prepare($sql);
    $st->execute($p);
    return (int)$st->fetch()['t'];
  }

  public function listar(int $limit, int $offset, ?string $q=null): array {
    $sql = "SELECT id,nome FROM categoria WHERE 1=1";
    $p = [];
    if($q){ $sql.=" AND nome LIKE :q"; $p[':q'] = '%'.$q.'%'; }
    $sql .= " ORDER BY nome LIMIT :l OFFSET :o";
    $st = $this->pdo->prepare($sql);
    if($q){ $st->bindValue(':q',$p[':q']); }
    $st->bindValue(':l',$limit,PDO::PARAM_INT);
    $st->bindValue(':o',$offset,PDO::PARAM_INT);
    $st->execute();
    return $st->fetchAll();
  }

  public function buscar(int $id): ?array {
    $st = $this->pdo->prepare("SELECT id,nome FROM categoria WHERE id=:id");
    $st->execute([':id'=>$id]);
    $r = $st->fetch();
    return $r ?: null;
  }

  public function criar(string $nome): int {
    $st = $this->pdo->prepare("INSERT INTO categoria (nome) VALUES (:n)");
    $st->execute([':n'=>$nome]);
    return (int)$this->pdo->lastInsertId();
  }

  public function atualizar(int $id, string $nome): bool {
    $st = $this->pdo->prepare("UPDATE categoria SET nome=:n WHERE id=:id");
    return $st->execute([':n'=>$nome, ':id'=>$id]);
  }

  public function excluir(int $id): bool {
    $st = $this->pdo->prepare("DELETE FROM categoria WHERE id=:id");
    return $st->execute([':id'=>$id]);
  }
}

<?php
require_once __DIR__.'/../config/db.php';
require_once __DIR__.'/../src/DAO/CategoriaDAO.php';
require_once __DIR__.'/../src/App/Flash.php';
require_once __DIR__.'/../src/App/Csrf.php';
function redirect($to){ header('Location: '.$to); exit; }

try{
  if(($_SERVER['REQUEST_METHOD'] ?? '')!=='POST'){ http_response_code(405); exit('Método não permitido'); }
  if(!Csrf::check((string)($_POST['csrf'] ?? ''))){ Flash::set('CSRF inválido.','err'); redirect('categorias_index.php'); }

  $pdo = pdo(); $dao = new CategoriaDAO($pdo);

  $id = filter_input(INPUT_POST,'id',FILTER_VALIDATE_INT);
  $nome = trim((string)($_POST['nome'] ?? ''));

  $erros = [];
  if(mb_strlen($nome) < 3 || mb_strlen($nome) > 60){ $erros[]='Nome deve ter entre 3 e 60 caracteres.'; }
  if($erros){ Flash::set('Falha na validação: '.implode(' ', $erros),'err'); redirect('categorias_index.php'); }

  if($id){
    $ok = $dao->atualizar((int)$id, $nome);
    Flash::set($ok ? 'Categoria atualizado.' : 'Nenhuma alteração aplicada.');
  }else{
    try{
      $novo = $dao->criar($nome);
      Flash::set('Categoria criada (ID '.$novo.').');
    }catch(PDOException $e){
      if($e->getCode()==='23000'){ Flash::set('Nome já existente. Escolha outro.','err'); }
      else { Flash::set('Erro ao criar: '.$e->getMessage(),'err'); }
    }
  }
  redirect('categorias_index.php');

}catch(Throwable $e){
  Flash::set('Erro: '.$e->getMessage(),'err');
  redirect('categorias_index.php');
}

Atividades práticas (para concluir na aula seguinte)

  1. Ordenação: adicione ordenação por nome (A→Z/Z→A) nas categorias e no catálogo. Para segurança, permita apenas campos/ordens pré-definidos.
  2. Feedback detalhado: ao tentar excluir uma categoria em uso (FK), mostre quantos itens dependem dela antes de bloquear a exclusão.
  3. Tamanho de página: transforme o seletor de “itens por página” em preferência do usuário usando cookie (ex.: ps_cat e ps_itens).

Dica: mantenha os filtros na URL para o aluno poder compartilhar um resultado (idempotência do GET).
