Capítulo 12 — Autorização (RBAC), Menus Condicionais e “Lembre‑me”

Implemente RBAC simples (roles), exiba menus condicionais por perfil e habilite login persistente (“lembre‑me”) usando tokens seguros.

Bimestre 3 Carga: ~100 min Entrega (parcial): RBAC + Lembre‑me funcional
← Cap. 11 Cap. 13 → Índice

Ao final você será capaz de:

  • Definir e verificar roles (ex.: admin, editor, viewer).
  • Mostrar/ocultar menus e ações conforme o perfil do usuário logado.
  • Implementar “lembre‑me” com tokens persistentes (selector + validator) e rotação/revogação segura.
  • Aplicar boas práticas: cookies HttpOnly/SameSite, expiração, revogação e proteção contra clonagem.

Objetivos de aprendizagem

  • Usar o campo role de usuario para autorização (RBAC simples).
  • Proteger páginas/rotas por role e montar menus condicionais.
  • Implementar o cookie “lembre‑me” com selector + validator (hash no banco).
  • Rotacionar e revogar tokens; configurar cookie com HttpOnly e SameSite=Lax.

Onde será aplicado: No login (Cap. 11), no Admin (Cap. 08/10) e no cabeçalho do site (menus condicionais).

Conceitos fundamentais

1) RBAC simples (Role-Based Access Control)

Controle de acesso por papéis: cada usuário tem um role e determinadas telas/ações exigem determinados papéis.

2) Menus condicionais

O menu deve refletir as permissões: exibir Admin apenas quando Auth::check() e, se for o caso, Auth::role() === 'admin'.

3) “Lembre‑me” com segurança

  • Não salve a senha no cookie; use tokens (selector + validator).
  • Guarde apenas o hash do validator no banco.
  • Rotacione o token a cada auto-login e revogue no logout.
  • Cookies: HttpOnly, SameSite e Secure em HTTPS.

Passo a passo — RBAC + Menus Condicionais + “Lembre‑me”

1) Banco — tabela de tokens persistentes

CREATE TABLE IF NOT EXISTS usuario_token (
  id INT AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  selector CHAR(16) NOT NULL UNIQUE,
  validator_hash CHAR(64) NOT NULL,
  expires_at DATETIME NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES usuario(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

2) Serviço “Lembre‑me” — src/Service/RememberMeService.php

<!-- src/Service/RememberMeService.php -->
<?php
declare(strict_types=1);

class RememberMeService {
  private PDO $pdo;
  private string $cookieName = 'rm_token';
  private int $days = 30;

  public function __construct(PDO $pdo){ $this->pdo = $pdo; }

  public function issueCookie(int $userId): void {
    $selector = bin2hex(random_bytes(8));       // 16 hex
    $validator = bin2hex(random_bytes(32));     // 64 hex
    $hash = hash('sha256', $validator);
    $exp = (new DateTime("+{$this->days} days"))->format('Y-m-d H:i:s');

    $st = $this->pdo->prepare("INSERT INTO usuario_token(user_id,selector,validator_hash,expires_at) VALUES (:u,:s,:h,:e)");
    $st->execute([':u'=>$userId, ':s'=>$selector, ':h'=>$hash, ':e'=>$exp]);

    $value = $selector.':'.$validator;
    setcookie($this->cookieName, $value, [
      'expires'  => time() + 60*60*24*$this->days,
      'path'     => '/lanchonete',
      'secure'   => false,  // true em HTTPS
      'httponly' => true,
      'samesite' => 'Lax'
    ]);
  }

  public function clearCookie(): void {
    setcookie($this->cookieName, '', [
      'expires'  => time()-3600,
      'path'     => '/lanchonete',
      'secure'   => false,
      'httponly' => true,
      'samesite' => 'Lax'
    ]);
  }

  public function tryAutoLogin(): ?array {
    $raw = $_COOKIE[$this->cookieName] ?? null;
    if(!$raw || !str_contains($raw, ':')) return null;

    [$selector,$validator] = explode(':', $raw, 2);

    $st = $this->pdo->prepare("SELECT user_id, validator_hash, expires_at FROM usuario_token WHERE selector=:s");
    $st->execute([':s'=>$selector]);
    $row = $st->fetch();
    if(!$row) return null;

    if(new DateTime($row['expires_at']) < new DateTime()) return null;
    if(!hash_equals($row['validator_hash'], hash('sha256', $validator))) return null;

    $u = $this->pdo->prepare("SELECT id,nome,email,role FROM usuario WHERE id=:id");
    $u->execute([':id'=>(int)$row['user_id']]);
    $user = $u->fetch();
    if(!$user) return null;

    // Rotaciona token
    $this->revokeBySelector($selector);
    $this->issueCookie((int)$row['user_id']);

    return ['id'=>(int)$user['id'],'nome'=>$user['nome'],'email'=>$user['email'],'role'=>$user['role']];
  }

  public function revokeBySelector(string $selector): void {
    $st = $this->pdo->prepare("DELETE FROM usuario_token WHERE selector=:s");
    $st->execute([':s'=>$selector]);
  }

  public function revokeAll(int $userId): void {
    $st = $this->pdo->prepare("DELETE FROM usuario_token WHERE user_id=:u");
    $st->execute([':u'=>$userId]);
  }
}

4) No POST do Login: emitir cookie quando marcado

<!-- (trecho) public/login.php (processo POST) -->
$pdo = pdo();
$svc = new AuthService($pdo);
$u = $svc->login((string)($_POST['email'] ?? ''),(string)($_POST['senha'] ?? ''));
if($u){
  Auth::setUser($u);
  if(($_POST['remember'] ?? '')==='1'){
    require_once __DIR__.'/../src/Service/RememberMeService.php';
    (new RememberMeService($pdo))->issueCookie((int)$u['id']);
  }
  header('Location: /lanchonete/public/admin/index.php'); exit;
}

5) Auto-login ao carregar páginas (bootstrap)

<!-- src/App/BootstrapAuth.php (carregado no início das páginas) -->
<?php
require_once __DIR__.'/../../config/db.php';
require_once __DIR__.'/Auth.php';
require_once __DIR__.'/../Service/RememberMeService.php';

Auth::start();
if(!Auth::check() && !empty($_COOKIE['rm_token'])){
  $pdo = pdo();
  $rm = new RememberMeService($pdo);
  $user = $rm->tryAutoLogin();
  if($user){ Auth::setUser($user); }
}

8) Logout — limpar sessão e tokens persistentes

<!-- public/logout.php -->
<?php
require_once __DIR__.'/../src/App/Auth.php';
require_once __DIR__.'/../config/db.php';
require_once __DIR__.'/../src/Service/RememberMeService.php';

$user = Auth::user();
$pdo = pdo();
$rm = new RememberMeService($pdo);

if($user){ $rm->revokeAll((int)$user['id']); }
$rm->clearCookie();

Auth::logout();
header('Location: /lanchonete/public/login.php'); exit;
Resumo: Você adicionou autorização por papéis (RBAC), menus condicionais por perfil e “lembre‑me” com tokens seguros (selector + validator), incluindo rotação e revogação.

Atividades práticas (para concluir na aula seguinte)

  1. RBAC granular: crie um helper can($perm) com mapa simples de permissões por role.
  2. Sessões ativas: tela para revogar tokens por dispositivo (listar tokens por usuário).
  3. HTTPS: em ambiente HTTPS, habilite secure=true e avalie SameSite=Strict.

Dica: não dependa apenas do front-end para impedir ações — sempre valide permissões no servidor.
