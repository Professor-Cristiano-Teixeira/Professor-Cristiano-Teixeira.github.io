Onde será aplicado: Implementaremos carrinho de compras usando $_SESSION e um cookie para “lembrar o nome do cliente” na lanchonete.

Conceitos fundamentais

1) Sessões (no servidor)

HTTP é sem estado. Para reconhecer o mesmo usuário em requisições diferentes, usamos sessões. No PHP, uma sessão é um array ($_SESSION) que vive no servidor e é associado a um identificador de sessão (PHPSESSID) enviado ao cliente como cookie. 


<?php
session_start(); // sempre no topo dos scripts que usam $_SESSION
$_SESSION['visitante'] = 'João';

Aplicação no passo a passo: armazenaremos o carrinho do cliente em $_SESSION.

2) Cookies (no cliente)

Cookies são dados armazenados pelo navegador e enviados a cada requisição para o mesmo domínio. Eles servem a preferências e identificação. Atributos importantes: Expires/Max-Age, Path, HttpOnly, Secure, SameSite. 


<?php
// PHP 7.3+: usar array de opções
setcookie('cliente_nome', 'Joana', [
  'expires'  => time() + 60*60*24*30, // 30 dias
  'path'     => '/',
  'secure'   => false,    // em HTTPS, use true
  'httponly' => true,     // não acessível por JS
  'samesite' => 'Lax',
]);

3) Sessões x Cookies

CaracterísticaSessãoCookie
ArmazenamentoServidorNavegador do cliente
Tamanho típicoMais flexível (no servidor)Pequeno (KB)
Uso comumLogin, carrinho, dados temporáriosPreferências (tema, nome, idioma)
SegurançaMais seguro (não expõe dados ao cliente)Evitar dados sensíveis

Pesquisas complementares sugeridas

  • Diretivas de sessão no php.ini (ex.: session.cookie_lifetime, session.save_path).
  • Diferença entre Expires e Max-Age em cookies; atributos Secure, HttpOnly e SameSite.
  • Como invalidar sessão e apagar cookies (session_destroy(), setcookie com expiração passada).

1) Utilitários de sessão — src/App/SessionCart.php


<!-- src/App/SessionCart.php -->
<?php
namespace App;

class SessionCart {
  public static function start(): void {
    if(session_status() !== PHP_SESSION_ACTIVE){ session_start(); }
    if(!isset($_SESSION['carrinho'])){ $_SESSION['carrinho'] = []; }
  }

  public static function add(string $id, string $nome, float $preco, int $qtd=1): void {
    self::start();
    if(isset($_SESSION['carrinho'][$id])){
      $_SESSION['carrinho'][$id]['qtd'] += $qtd;
    } else {
      $_SESSION['carrinho'][$id] = ['nome'=>$nome, 'preco'=>$preco, 'qtd'=>$qtd];
    }
  }

  public static function update(string $id, int $qtd): void {
    self::start();
    if(isset($_SESSION['carrinho'][$id])){
      if($qtd <= 0){ unset($_SESSION['carrinho'][$id]); }
      else { $_SESSION['carrinho'][$id]['qtd'] = $qtd; }
    }
  }

  public static function remove(string $id): void {
    self::start();
    unset($_SESSION['carrinho'][$id]);
  }

  public static function items(): array {
    self::start();
    return $_SESSION['carrinho'];
  }

  public static function total(): float {
    self::start();
    $t = 0.0;
    foreach(self::items() as $it){ $t += $it['preco'] * $it['qtd']; }
    return $t;
  }

  public static function clear(): void {
    self::start();
    $_SESSION['carrinho'] = [];
  }
}

4) Endpoint para adicionar — public/add_carrinho.php


<!-- public/add_carrinho.php -->
<?php
use App\SessionCart;
require_once __DIR__.'/../src/App/SessionCart.php';
SessionCart::start();

$id    = (string)($_POST['id'] ?? '');
$nome  = (string)($_POST['nome'] ?? '');
$preco = (float)($_POST['preco'] ?? 0);
$qtd   = (int)($_POST['qtd'] ?? 1);

if($id && $nome && $preco > 0){
  SessionCart::add($id, $nome, $preco, max(1,$qtd));
}
header('Location: carrinho.php');
Observação: neste bimestre, os preços são passados pelo formulário apenas para fins didáticos. No módulo de Banco de Dados (B2), o preço virá do servidor com consultas parametrizadas, evitando manipulação no cliente.

Atividades práticas (para concluir na aula seguinte)

  1. Quantidade no cardápio: adicione um campo numérico (min=1) no formulário “Adicionar ao carrinho”.
  2. Preferência do cliente: crie um cookie cat_pref com a categoria favorita e use-o para pré-filtrar o cardápio.
  3. Limpar nome: faça um link/botão que apague o cookie cliente_nome (dica: setcookie com expiração passada).

Capriche na UX: mensagens claras ao atualizar quantidades, links visíveis para o carrinho e para o cardápio.
