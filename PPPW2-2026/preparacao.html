Preparação do Ambiente (Windows) — XAMPP + PHP + MySQL

Siga este passo a passo para configurar o seu computador em casa e conseguir executar os exercícios da apostila: instalar o XAMPP, iniciar Apache e MySQL/MariaDB, criar a pasta do projeto em htdocs, e testar localhost.

Windows 10/11 Tempo: ~20–40 min Pré-requisito: navegador + editor
⬇ Download XAMPP (oficial) ↩ Voltar ao Índice

Dica: esta página usa o link oficial do Apache Friends para download do XAMPP.

Antes de começar

  • Tenha um editor (ex.: VS Code) e um navegador (Chrome/Edge/Firefox).
  • Use uma pasta de projeto dentro de C:\xampp\htdocs\ (padrão do XAMPP).
  • Se aparecer pergunta do Firewall do Windows, permita o Apache (rede privada).
Importante: XAMPP é indicado para desenvolvimento local (seu computador). Evite expor portas na internet (port forwarding).

1) Baixar o XAMPP (link oficial)

  1. Acesse a página oficial de downloads do XAMPP.
  2. Baixe a versão para Windows (64-bit) indicada no site.
  3. Guarde o instalador na pasta “Downloads”.
Abrir Downloads do XAMPP
O XAMPP é um pacote que inclui Apache, MariaDB (MySQL), PHP, phpMyAdmin e outros componentes, e o download é feito no site oficial do Apache Friends.

2) Instalar o XAMPP no Windows

Passo a passo recomendado

  1. Execute o instalador do XAMPP (duplo clique no arquivo baixado).
  2. Se o Windows pedir permissão, clique em Sim (UAC).
  3. Componentes: mantenha o padrão (Apache, MySQL/MariaDB, PHP, phpMyAdmin).
  4. Pasta de instalação: use C:\xampp (recomendado).
  5. Conclua a instalação e abra o XAMPP Control Panel.
Em muitos PCs, durante a instalação/início do Apache, o Windows pode pedir permissão no Firewall — clique em Allow access / Permitir acesso (rede privada).

Iniciar Apache e MySQL (MariaDB)

  1. No XAMPP Control Panel, clique em Start no Apache.
  2. Clique em Start no MySQL.
  3. Se ambos ficarem com indicador “running”, está ok.

Portas padrão comuns: Apache usa 80/443; MySQL usa 3306 (podem variar se houver conflito).

3) Testar se está funcionando

3.1) Teste do Apache (servidor web)

  1. Abra o navegador e acesse: http://localhost/
  2. Você deve ver a página inicial do XAMPP (ou dashboard).

3.2) Teste do phpMyAdmin (banco)

  1. Acesse: http://localhost/phpmyadmin/
  2. Se abrir, o MySQL/MariaDB está funcionando.

3.3) Criar pasta do projeto no htdocs

Crie a pasta do seu projeto dentro de:

C:\xampp\htdocs\lanchonete

Crie um arquivo para teste:

C:\xampp\htdocs\lanchonete\index.php

Conteúdo de teste (PHP):

<?php
echo "Olá! XAMPP está funcionando.";
?>

Agora acesse no navegador:

http://localhost/lanchonete/
Se você viu a mensagem no navegador, seu ambiente está pronto para seguir a apostila.

4) Configurações úteis (recomendadas)

4.1) Executar o XAMPP Control Panel como Administrador (se der erro)

  1. Feche o XAMPP Control Panel.
  2. Procure “XAMPP Control Panel” no menu iniciar.
  3. Clique com o botão direito → Executar como administrador.

4.2) Editor de código

  • Recomendado: Visual Studio Code (ou qualquer editor que você prefira).
  • Abra a pasta C:\xampp\htdocs\lanchonete no seu editor.

4.3) Organização de arquivos

Sugestão para acompanhar a apostila:

C:\xampp\htdocs\lanchonete\
  public\
  src\
  assets\
  database\
  README.md

5) Problemas comuns (e como resolver)

5.1) Apache não inicia (porta 80 ocupada)

Isso acontece quando outro serviço está usando a porta 80 (frequente em Windows com IIS/World Wide Web Publishing Service).

Solução A — desativar IIS (mais comum)

  1. Abra “Ativar ou desativar recursos do Windows”.
  2. Desmarque Internet Information Services (IIS) / World Wide Web Services (se estiver ativo).
  3. Reinicie o PC e tente iniciar Apache novamente.

Solução B — mudar a porta do Apache (alternativa rápida)

  1. No XAMPP Control Panel: Apache → Config → httpd.conf
  2. Procure por Listen 80 e troque para Listen 8080
  3. Procure por ServerName localhost:80 e troque para ServerName localhost:8080
  4. Salve, reinicie Apache e acesse http://localhost:8080/
Se mudar para 8080, lembre que o endereço terá “:8080” nas URLs.

5.2) Firewall bloqueando Apache

  1. Quando o Windows perguntar, clique em Permitir acesso para o Apache.
  2. Preferencialmente, marque apenas Rede privada.

5.3) phpMyAdmin abre, mas mostra aviso de root sem senha

Em ambiente local (somente no seu PC), é comum o root não ter senha por padrão. Se você quiser “endurecer” mesmo em casa, crie uma senha e ajuste o phpMyAdmin.

5.4) Instalador reclama de dependências (Visual C++ Runtime)

Se o Windows reclamar de “Visual C++ Runtime”/“MSVC”, instale o pacote mais recente do Visual C++ Redistributable (v14) pela Microsoft.
