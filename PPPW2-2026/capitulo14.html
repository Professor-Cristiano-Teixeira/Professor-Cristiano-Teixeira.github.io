Capítulo 14 — Introdução a API REST em PHP

Vamos transformar o que você fez com Fetch/JSON (Cap. 13) em uma API REST simples. Você aprenderá sobre rotas, métodos HTTP, status codes e padrões de respostas JSON. Aplicação: endpoints de itens do cardápio (lanchonete) e testes via navegador/Fetch.

Bimestre 4 Carga: ~100 min Entrega (parcial): API REST de itens
← Cap. 13 Cap. 15 → Índice

Ao final você será capaz de:

  • Explicar os princípios de REST e recursos (resources) como /api/itens.
  • Criar rotas simples em PHP e responder JSON com status HTTP corretos.
  • Implementar endpoints GET/POST/PUT/DELETE para o recurso itens.
  • Validar entrada, usar prepared statements e padronizar respostas.

Objetivos de aprendizagem

  • Entender resource, rota e método HTTP.
  • Definir estrutura de resposta JSON padrão (ok, data, error).
  • Mapear status codes: 200, 201, 400, 404, 500.
  • Criar endpoints: listar, detalhar, criar, atualizar e remover itens.
  • Testar com Fetch (frontend) ou com o navegador.
  • Aplicar segurança básica (SQL parametrizado, validação, escape no retorno quando necessário).

Onde será aplicado: A API vai alimentar o catálogo (frontend) e, no Cap. 15, vamos reforçar segurança (CSRF/XSS/cookies/sessão) e boas práticas.

Conceitos fundamentais

1) O que é REST (no básico)

REST é um estilo de arquitetura onde você manipula recursos por URLs (ex.: /api/itens) e usa métodos HTTP para definir a ação: GET (ler), POST (criar), PUT (atualizar), DELETE (remover).

2) Boas práticas de endpoints

  • URLs com substantivos no plural: /api/itens, /api/itens/10.
  • Respostas em JSON: Content-Type: application/json.
  • Status code coerente: 201 ao criar, 404 ao não encontrar.
  • Validação no servidor e SQL parametrizado.

3) Padronização de resposta

{
  "ok": true,
  "data": {...},
  "error": null
}

Pesquisas complementares sugeridas

  • Diferença entre PUT e PATCH.
  • Idempotência dos métodos HTTP.
  • Versionamento de API (ex.: /api/v1/itens).

2) DAO para a API — src/DAO/ItemApiDAO.php

<!-- src/DAO/ItemApiDAO.php -->
<?php
declare(strict_types=1);

class ItemApiDAO {
  private PDO $pdo;
  public function __construct(PDO $pdo){ $this->pdo = $pdo; }

  public function listar(?string $q=null, ?int $categoriaId=null): array {
    $sql = "SELECT i.id,i.nome,i.preco,i.popular,i.categoria_id,c.nome AS categoria
            FROM item i JOIN categoria c ON c.id=i.categoria_id
            WHERE 1=1";
    $p = [];
    if($q){ $sql .= " AND i.nome LIKE :q"; $p[':q'] = '%'.$q.'%'; }
    if($categoriaId){ $sql .= " AND i.categoria_id=:cid"; $p[':cid'] = $categoriaId; }
    $sql .= " ORDER BY c.nome, i.nome";
    $st = $this->pdo->prepare($sql);
    $st->execute($p);
    return $st->fetchAll();
  }

  public function buscar(int $id): ?array {
    $st = $this->pdo->prepare("SELECT i.id,i.nome,i.preco,i.popular,i.categoria_id,c.nome AS categoria
                               FROM item i JOIN categoria c ON c.id=i.categoria_id
                               WHERE i.id=:id");
    $st->execute([':id'=>$id]);
    $r = $st->fetch();
    return $r ?: null;
  }

  public function criar(array $data): int {
    $st = $this->pdo->prepare("INSERT INTO item(nome,preco,categoria_id,popular) VALUES (:n,:p,:cid,:pop)");
    $st->execute([
      ':n'=>$data['nome'],
      ':p'=>$data['preco'],
      ':cid'=>$data['categoria_id'],
      ':pop'=>$data['popular']
    ]);
    return (int)$this->pdo->lastInsertId();
  }

  public function atualizar(int $id, array $data): bool {
    $st = $this->pdo->prepare("UPDATE item SET nome=:n, preco=:p, categoria_id=:cid, popular=:pop WHERE id=:id");
    return $st->execute([
      ':n'=>$data['nome'],
      ':p'=>$data['preco'],
      ':cid'=>$data['categoria_id'],
      ':pop'=>$data['popular'],
      ':id'=>$id
    ]);
  }

  public function excluir(int $id): bool {
    $st = $this->pdo->prepare("DELETE FROM item WHERE id=:id");
    return $st->execute([':id'=>$id]);
  }
}

3) Roteador simples — public/api/index.php

Este arquivo decide qual “controlador” chamar com base na URL.

<!-- public/api/index.php -->
<?php
// Ex.: /lanchonete/public/api/index.php/itens ou /itens/10
$path = trim(parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH) ?? '', '/');

// Ajuste: encontre a posição do "/api" e pegue o que vem depois
$pos = strpos($path, 'api/index.php');
$after = $pos !== false ? substr($path, $pos + strlen('api/index.php')) : '';
$after = trim($after, '/');

$parts = $after === '' ? [] : explode('/', $after);
$resource = $parts[0] ?? '';
$id = isset($parts[1]) ? (int)$parts[1] : null;

if($resource === 'itens'){
  $_GET['__id'] = $id;             // passa o id para o controlador
  require __DIR__.'/itens.php';
  exit;
}

header('Content-Type: application/json; charset=utf-8');
http_response_code(404);
echo json_encode(['ok'=>false,'data'=>null,'error'=>'Recurso não encontrado']);

4) Controlador do recurso — public/api/itens.php

<!-- public/api/itens.php -->
<?php
require_once __DIR__.'/../../config/db.php';
require_once __DIR__.'/../../src/DAO/ItemApiDAO.php';

header('Content-Type: application/json; charset=utf-8');

function respond(int $status, bool $ok, $data=null, ?string $error=null){
  http_response_code($status);
  echo json_encode(['ok'=>$ok,'data'=>$data,'error'=>$error]);
  exit;
}

function readJsonBody(): array {
  $raw = file_get_contents('php://input');
  $data = json_decode($raw, true);
  return is_array($data) ? $data : [];
}

function validateItem(array $d, bool $partial=false): array {
  // retorna [ok, errors, normalized]
  $errors = [];
  $out = [];

  if(!$partial || array_key_exists('nome',$d)){
    $nome = trim((string)($d['nome'] ?? ''));
    if(mb_strlen($nome) < 3 || mb_strlen($nome) > 80) $errors[] = 'nome (3..80)';
    $out['nome'] = $nome;
  }

  if(!$partial || array_key_exists('preco',$d)){
    $p = (string)($d['preco'] ?? '');
    $p = str_replace(',','.', $p);
    if(!is_numeric($p) || (float)$p <= 0) $errors[] = 'preco (>0)';
    $out['preco'] = (float)$p;
  }

  if(!$partial || array_key_exists('categoria_id',$d)){
    $cid = (int)($d['categoria_id'] ?? 0);
    if($cid <= 0) $errors[] = 'categoria_id (>0)';
    $out['categoria_id'] = $cid;
  }

  if(!$partial || array_key_exists('popular',$d)){
    $pop = (int)($d['popular'] ?? 0);
    $out['popular'] = ($pop===1) ? 1 : 0;
  }

  return [count($errors)===0, $errors, $out];
}

try{
  $pdo = pdo();
  $dao = new ItemApiDAO($pdo);

  $method = $_SERVER['REQUEST_METHOD'] ?? 'GET';
  $id = (int)($_GET['__id'] ?? 0);

  // GET /itens? q=...&cat=...
  if($method === 'GET' && $id === 0){
    $q = isset($_GET['q']) ? trim((string)$_GET['q']) : null;
    $cat = isset($_GET['cat']) ? (int)$_GET['cat'] : null;
    $items = $dao->listar($q ?: null, $cat ?: null);
    respond(200, true, $items, null);
  }

  // GET /itens/{id}
  if($method === 'GET' && $id > 0){
    $item = $dao->buscar($id);
    if(!$item) respond(404, false, null, 'Item não encontrado');
    respond(200, true, $item, null);
  }

  // POST /itens  (body JSON)
  if($method === 'POST' && $id === 0){
    $data = readJsonBody();
    [$ok,$errors,$norm] = validateItem($data, false);
    if(!$ok) respond(400, false, ['fields'=>$errors], 'Dados inválidos');
    $newId = $dao->criar($norm);
    $created = $dao->buscar($newId);
    respond(201, true, $created, null);
  }

  // PUT /itens/{id} (body JSON)
  if($method === 'PUT' && $id > 0){
    $current = $dao->buscar($id);
    if(!$current) respond(404, false, null, 'Item não encontrado');

    $data = readJsonBody();
    // atualização completa neste exemplo (PUT)
    [$ok,$errors,$norm] = validateItem($data, false);
    if(!$ok) respond(400, false, ['fields'=>$errors], 'Dados inválidos');

    $dao->atualizar($id, $norm);
    $updated = $dao->buscar($id);
    respond(200, true, $updated, null);
  }

  // DELETE /itens/{id}
  if($method === 'DELETE' && $id > 0){
    $current = $dao->buscar($id);
    if(!$current) respond(404, false, null, 'Item não encontrado');
    $dao->excluir($id);
    respond(200, true, ['deleted'=>true,'id'=>$id], null);
  }

  respond(405, false, null, 'Método/rota não suportado');

}catch(Throwable $e){
  respond(500, false, null, 'Erro no servidor');
}

5) Testando a API (sem ferramentas extras)

Você pode testar com o navegador (GET) e com JavaScript (POST/PUT/DELETE). Exemplos:

// GET lista
fetch('api/index.php/itens').then(r=>r.json()).then(console.log);

// GET por id
fetch('api/index.php/itens/1').then(r=>r.json()).then(console.log);

// POST criar
fetch('api/index.php/itens', {
  method:'POST',
  headers:{'Content-Type':'application/json'},
  body: JSON.stringify({nome:'Refrigerante', preco:7.5, categoria_id:1, popular:1})
}).then(r=>r.json()).then(console.log);

// PUT atualizar
fetch('api/index.php/itens/1', {
  method:'PUT',
  headers:{'Content-Type':'application/json'},
  body: JSON.stringify({nome:'Café expresso', preco:6.2, categoria_id:1, popular:1})
}).then(r=>r.json()).then(console.log);

// DELETE remover
fetch('api/index.php/itens/1', {method:'DELETE'}).then(r=>r.json()).then(console.log);
