Capítulo 05 — MySQL + PHP (PDO/MySQLi): conexões e queries

Conecte o PHP ao MySQL no XAMPP, crie o schema da lanchonete e realize as primeiras consultas (SELECT) com prepared statements.

Bimestre 2 Carga: ~100 min Entrega (parcial): Leitura do cardápio via banco
← Cap. 04 Cap. 06 → Índice

Ao final você será capaz de:

  • Inicializar o MySQL no XAMPP e criar o banco lanchonete com tabelas e chaves estrangeiras.
  • Conectar o PHP ao banco usando PDO (ou MySQLi) com charset e errmode corretos.
  • Executar SELECT simples e parametrizados (prevenindo SQL Injection).
  • Listar itens do cardápio vindos do banco e filtrar por termo/categoria (GET).

Objetivos de aprendizagem

  • Configurar schema, tabelas e dados iniciais no MySQL (Workbench ou phpMyAdmin).
  • Entender DSN, usuário/senha e charset (utf8mb4).
  • Usar PDO com ERRMODE_EXCEPTION e FETCH_ASSOC.
  • Construir uma página catalogo_db.php renderizando dados do MySQL.
  • Aplicar prepared statements com LIKE e filtros opcionais.
  • Separar config e (opcional) um DAO simples para leitura.

Onde será aplicado: Transformaremos o cardápio (antes em arrays) para leitura direta do MySQL, preparando o terreno para CRUDs do Cap. 06 e Cap. 07.

Conceitos fundamentais

1) Driver e DSN (PDO)

Para conectar no MySQL via PDO, usamos um DSN (Data Source Name) com host, nome do banco e charset: 


<?php
$dsn = "mysql:host=127.0.0.1;dbname=lanchonete;charset=utf8mb4";
$user = "root"; $pass = ""; // padrão XAMPP: root sem senha (apenas DEV)
$pdo = new PDO($dsn, $user, $pass, [
  PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
  PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

Boa prática: sempre defina o charset=utf8mb4 no DSN e error mode para exceções.

2) Prepared Statements

Consultas parametrizadas separam o SQL dos valores, prevenindo injeção de SQL e erros de formatação: 


<?php
$stmt = $pdo->prepare("SELECT id, nome FROM categoria WHERE nome LIKE :q");
$stmt->execute([':q' => '%'.$termo.'%']);
$categorias = $stmt->fetchAll();

3) MySQL Workbench / phpMyAdmin

Você pode criar o banco e as tabelas pelo MySQL Workbench (modelo SQL) ou via phpMyAdmin (XAMPP). Manter InnoDB e UTF8MB4 facilita chaves estrangeiras e caracteres especiais (acentos/emoji).

Pesquisas complementares sugeridas

  • PDO::prepare vs PDO::query; nomeação de parâmetros (:nome) vs posicionais (?).
  • Escolha de tipos (INT, DECIMAL, VARCHAR, TEXT) e índices (INDEX, UNIQUE) para performance.
  • Configurações do XAMPP: porta do MySQL (geralmente 3306) e credenciais padrão do ambiente.

Passo a passo — Conexão, schema e SELECT do cardápio

Pré-requisitos

  • XAMPP em execução (MySQL iniciado).
  • MySQL Workbench (ou phpMyAdmin) disponível.
  • Projeto na pasta htdocs/lanchonete com VS Code.

1) Crie o banco e as tabelas (SQL)

Execute no Workbench (ou no phpMyAdmin → SQL):


-- Schema e tabelas da lanchonete (UTF8MB4 + InnoDB)
CREATE DATABASE IF NOT EXISTS lanchonete 
  CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE lanchonete;

CREATE TABLE IF NOT EXISTS categoria (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(60) NOT NULL UNIQUE
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS item (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(80) NOT NULL,
  preco DECIMAL(10,2) NOT NULL,
  categoria_id INT NOT NULL,
  popular TINYINT(1) NOT NULL DEFAULT 0,
  CONSTRAINT fk_item_categoria FOREIGN KEY (categoria_id) REFERENCES categoria(id)
) ENGINE=InnoDB;

2) Crie a conexão (PDO) — config/db.php


<!-- config/db.php -->
<?php
declare(strict_types=1);

function pdo(): PDO {
  $host = '127.0.0.1'; $db = 'lanchonete';
  $user = 'root'; $pass = ''; // XAMPP: root sem senha (apenas DEV)
  $dsn  = "mysql:host={$host};dbname={$db};charset=utf8mb4";
  return new PDO($dsn, $user, $pass, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES => false
  ]);
}

3) DAO simples (opcional) — src/DAO/ItemDAO.php


<!-- src/DAO/ItemDAO.php -->
<?php
declare(strict_types=1);

class ItemDAO {
  private PDO $pdo;
  public function __construct(PDO $pdo){ $this->pdo = $pdo; }

  public function buscar(?string $q, ?int $categoriaId): array {
    $sql = "SELECT i.id,i.nome,i.preco,i.popular,c.nome AS categoria
            FROM item i
            JOIN categoria c ON c.id=i.categoria_id
            WHERE 1=1";
    $params = [];
    if($q){ $sql .= " AND i.nome LIKE :q"; $params[':q'] = '%'.$q.'%'; }
    if($categoriaId){ $sql .= " AND i.categoria_id = :cid"; $params[':cid'] = $categoriaId; }
    $sql .= " ORDER BY c.nome, i.nome";

    $stmt = $this->pdo->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
  }

  public function listarCategorias(): array {
    $sql = "SELECT id, nome FROM categoria ORDER BY nome";
    return $this->pdo->query($sql)->fetchAll();
  }
}

4) Página do catálogo (via banco) — public/catalogo_db.php


<!-- public/catalogo_db.php -->
<?php
require_once __DIR__.'/../config/db.php';
require_once __DIR__.'/../src/DAO/ItemDAO.php';

function esc($v){ return htmlspecialchars((string)$v, ENT_QUOTES, 'UTF-8'); }
function preco($n){ return 'R$ '.number_format((float)$n,2,",","."); }

try{
  $pdo = pdo();
  $dao = new ItemDAO($pdo);
  $q = filter_input(INPUT_GET, 'q', FILTER_SANITIZE_SPECIAL_CHARS) ?: '';
  $cid = filter_input(INPUT_GET, 'cat', FILTER_VALIDATE_INT) ?: null;

  $categorias = $dao->listarCategorias();
  $itens = $dao->buscar($q, $cid);
}catch(Throwable $e){
  http_response_code(500);
  die('Erro de conexão/consulta ao banco: '.$e->getMessage());
}
?>

  </style>
</head>

Resumo: criamos o schema no MySQL, configuramos a conexão com PDO, executamos consultas com prepared e renderizamos o cardápio diretamente do banco.

Atividades práticas (para concluir na aula seguinte)

  1. Listar categorias: crie public/categorias.php para listar todas as categorias a partir do banco.
  2. Detalhe do item: crie public/item.php?id=... que mostra detalhes (nome, preço, categoria) de um item via SELECT parametrizado.
  3. Paginação (básica): adicione LIMIT e OFFSET em catalogo_db.php com links Anterior/Próxima.

Dica: sempre use prepared statements para parâmetros de entrada; nunca concatene valores diretamente no SQL.
