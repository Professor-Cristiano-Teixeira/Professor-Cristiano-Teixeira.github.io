Capítulo 09 — POO em PHP: Classes, Objetos, Atributos e Métodos

Modele o domínio da lanchonete com classes e objetos (Item e Categoria), usando namespaces e um autoload simples. Prepare o terreno para a separação em camadas.

Bimestre 3 Carga: ~100 min Entrega (parcial): Modelos OOP + Demo integrando DAO
← Cap. 08 Cap. 10 → Índice

Ao final você será capaz de:

  • Explicar os conceitos de classe, objeto, atributo e método no PHP.
  • Criar classes de domínio (Categoria e Item) com construtor e getters/setters tipados.
  • Organizar o projeto com namespaces (App\Model) e autoload simples.
  • Integrar DAOs existentes para retornar objetos (e não só arrays) com métodos auxiliares fromArray/toArray.

Objetivos de aprendizagem

  • Conhecer a sintaxe de classes em PHP: class, visibilidade (public/private), __construct.
  • Aplicar tipagem em propriedades e parâmetros (ex.: int, string, float).
  • Usar namespaces e autoload para carregar classes automaticamente.
  • Representar Categoria e Item como objetos com regras simples (ex.: preço > 0).
  • Refatorar DAOs para hidratar objetos (hydration) a partir de linhas do banco.

Onde será aplicado: No catálogo e nos CRUDs, passando a manipular instâncias de Item e Categoria em vez de arrays “soltos”.

Conceitos fundamentais

1) Classe e Objeto

Uma classe descreve um tipo com atributos (dados) e métodos (comportamentos). Um objeto é uma instância dessa classe em execução (com valores reais).

2) Visibilidade e tipagem

Use private para proteger atributos (encapsulamento) e getters/setters para acesso controlado. Tipos em propriedades/métodos ajudam a evitar erros (ex.: float $preco).

3) Namespaces e Autoload

Namespaces organizam classes (ex.: App\Model\Item). O autoload carrega arquivos de classe automaticamente quando o nome é usado, evitando require repetidos.

Pesquisas complementares sugeridas

  • Convenção PSR-4 de autoload (estrutura de pastas e mapeamento de namespaces).
  • Métodos especiais em PHP: __construct, __toString, __get/__set (quando usar).
  • Vantagens do encapsulamento e do “Tell, Don’t Ask” (evitar expor estado sem necessidade).

1) Autoload simples — src/App/Autoload.php


<!-- src/App/Autoload.php -->
<?php
spl_autoload_register(function($fqcn){
  // Carrega apenas classes do namespace "App\"
  if($fqcn === null || strpos($fqcn, 'App\\') !== 0){ return; }
  $baseDir = __DIR__.'/../';        // aponta para "src/"
  $relPath = str_replace('App\\', '', $fqcn);
  $relPath = str_replace('\\', '/', $relPath);
  $file = $baseDir.$relPath.'.php';
  if(is_file($file)){ require_once $file; }
});

2) Classe Categoria — src/Model/Categoria.php


<!-- src/Model/Categoria.php -->
<?php
namespace App\Model;

class Categoria {
  private ?int $id;
  private string $nome;

  public function __construct(?int $id, string $nome){
    $this->setId($id);
    $this->setNome($nome);
  }

  public function getId(): ?int { return $this->id; }
  public function getNome(): string { return $this->nome; }

  public function setId(?int $id): void { $this->id = $id; }
  public function setNome(string $nome): void {
    $nome = trim($nome);
    if(mb_strlen($nome) < 3){ throw new \InvalidArgumentException('Nome da categoria muito curto'); }
    $this->nome = $nome;
  }

  public static function fromArray(array $row): self {
    return new self(
      isset($row['id']) ? (int)$row['id'] : null,
      (string)($row['nome'] ?? '')
    );
  }

  public function toArray(): array {
    return ['id'=>$this->id, 'nome'=>$this->nome];
  }
}

3) Classe Item — src/Model/Item.php


<!-- src/Model/Item.php -->
<?php
namespace App\Model;

class Item {
  private ?int $id;
  private string $nome;
  private float $preco;
  private bool $popular;
  private Categoria $categoria;

  public function __construct(?int $id, string $nome, float $preco, Categoria $categoria, bool $popular=false){
    $this->setId($id);
    $this->setNome($nome);
    $this->setPreco($preco);
    $this->setCategoria($categoria);
    $this->popular = $popular;
  }

  public function getId(): ?int { return $this->id; }
  public function getNome(): string { return $this->nome; }
  public function getPreco(): float { return $this->preco; }
  public function isPopular(): bool { return $this->popular; }
  public function getCategoria(): Categoria { return $this->categoria; }

  public function setId(?int $id): void { $this->id = $id; }
  public function setNome(string $nome): void {
    $nome = trim($nome);
    if(mb_strlen($nome) < 3){ throw new \InvalidArgumentException('Nome do item muito curto'); }
    $this->nome = $nome;
  }
  public function setPreco(float $preco): void {
    if($preco <= 0){ throw new \InvalidArgumentException('Preço deve ser > 0'); }
    $this->preco = $preco;
  }
  public function setCategoria(Categoria $c): void { $this->categoria = $c; }
  public function setPopular(bool $p): void { $this->popular = $p; }

  public static function fromArray(array $row): self {
    $cat = new Categoria(
      isset($row['categoria_id']) ? (int)$row['categoria_id'] : null,
      (string)($row['categoria'] ?? $row['nome_categoria'] ?? '(sem categoria)')
    );
    return new self(
      isset($row['id']) ? (int)$row['id'] : null,
      (string)($row['nome'] ?? ''),
      (float)($row['preco'] ?? 0),
      $cat,
      (bool)((int)($row['popular'] ?? 0))
    );
  }

  public function toArray(): array {
    return [
      'id'=>$this->id,
      'nome'=>$this->nome,
      'preco'=>$this->preco,
      'popular'=>($this->popular ? 1 : 0),
      'categoria_id'=>$this->categoria->getId()
    ];
  }
}

4) DAO que retorna objetos — src/DAO/ItemDAO_OO.php (opcional)


<!-- src/DAO/ItemDAO_OO.php -->
<?php
declare(strict_types=1);

use App\Model\Item;
use App\Model\Categoria;

class ItemDAO_OO {
  private PDO $pdo;
  public function __construct(PDO $pdo){ $this->pdo = $pdo; }

  private function hydrate(array $row): Item { return Item::fromArray($row); }

  public function listar(): array {
    $sql = "SELECT i.id,i.nome,i.preco,i.popular,i.categoria_id,c.nome AS categoria
             FROM item i JOIN categoria c ON c.id=i.categoria_id ORDER BY c.nome,i.nome";
    $rows = $this->pdo->query($sql)->fetchAll();
    $objs = [];
    foreach($rows as $r){ $objs[] = $this->hydrate($r); }
    return $objs;
  }

  public function buscarPorId(int $id): ?Item {
    $st = $this->pdo->prepare("SELECT i.id,i.nome,i.preco,i.popular,i.categoria_id,c.nome AS categoria
           FROM item i JOIN categoria c ON c.id=i.categoria_id WHERE i.id=:id");
    $st->execute([':id'=>$id]);
    $r = $st->fetch();
    return $r ? $this->hydrate($r) : null;
  }
}

Atividades práticas (para concluir na aula seguinte)

  1. Método de domínio: adicione em Item o método getPrecoFormatado() que retorna o preço já formatado (R$).
  2. Valor-objeto: crie uma classe simples Dinheiro (valor em float + método formatar()) e use-a dentro de Item.
  3. DAO OO: refatore o BebidaDAO do Cap. 06 para retornar Item (objetos) ao invés de arrays.

Dica: mantenha validações no construtor/setters (ex.: nome com tamanho mínimo, preço > 0).
