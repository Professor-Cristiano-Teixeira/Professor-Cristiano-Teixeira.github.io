Programação Web III • 2º ano • Desenvolvimento de Sistemas

Apostila Interativa — Laravel (MVC, CRUD, APIs, Segurança e Integrações)

Esta apostila foi organizada em 4 bimestres (total de 16 capítulos), considerando aulas semanais de 100 minutos. Em cada capítulo, você verá a teoria essencial (sem ficar superficial), um passo a passo no contexto do Sistema de Lanchonete, atividades práticas para você completar e questionários interativos.

📚 Ver Sumário ▶️ Começar pelo Capítulo 1
Ritmo por capítulo (padrão):
  • Semana A (100 min): conceitos + demonstração + iniciar o passo a passo.
  • Semana B (100 min): concluir o passo a passo + atividades correlatas + revisão.

1º Bimestre — Fundamentos de MVC (Laravel) e CRUD com Validação

Foco: Setup, MVC, Blade, Eloquent (CRUD), validação, paginação/busca e segurança básica.
B1
  1. Capítulo 1 — Visão Geral da Arquitetura Web e Setup do Projeto HTTP, requisição/resposta, stateless, MVC, artisan, Vite, migrations (visão), layout Blade.
  2. Capítulo 2 — Modelagem de Dados, Migrations, Seeders & Eloquent (CRUD Categoria) Modelagem leve, migrations/seeders, Eloquent básico e CRUD completo.
  3. Capítulo 3 — Blade, Formulários, Validação e Mensagens CSRF, Form Requests, mensagens amigáveis, components e UX básica.
  4. Capítulo 4 — Listagens, Paginação, Busca e Segurança Básica (CSRF/XSS) Paginação, filtros, query string, escaping no Blade, noções de SQLi.

2º Bimestre — Autenticação/Autorização, Relacionamentos e Integração AJAX & API Pública

Foco: Breeze, sessão/middlewares, relações Eloquent, fluxo de pedidos, AJAX/fetch e integração externa.
B2
  1. Capítulo 5 — Autenticação (Breeze), Sessão e Perfis Login/registro, middleware auth, perfis (Gerente/Atendente) e menus condicionais.
  2. Capítulo 6 — Relacionamentos Eloquent e Fluxo de Pedido 1:N, N:N, Pedido/ItemPedido e regras de negócio iniciais.
  3. Capítulo 7 — Requisições Assíncronas (AJAX) no Laravel/Blade fetch/JSON, rotas internas, status HTTP, atualização de UI sem recarregar.
  4. Capítulo 8 — Consumindo APIs Públicas + Postman Integração com ViaCEP, tratamento de erros, cache básico e coleção Postman.
Abrir Bimestre 2 (Cap. 05) Próximo bimestre ↓

3º Bimestre — Serviços para Web: REST/JSON, SOAP/WSDL/XML e Segurança de API

Foco: API REST stateless, API Resources, XML, SOAP/WSDL e proteção com tokens + rate limit.
B3
  1. Capítulo 9 — Expondo uma REST API (stateless) para o Sistema de Lanchonete REST, api.php, versionamento v1, API Resources, CORS e padrões de resposta.
  2. Capítulo 10 — Padrões de Transferência: JSON e XML JSON vs XML, content negotiation, Accept header e export/import simples.
  3. Capítulo 11 — SOAP/WSDL (com manutenção de estado) — Consumo e Exposição Mensagens SOAP, WSDL, SoapClient/SoapServer e comparação com REST.
  4. Capítulo 12 — Segurança de API e Observabilidade Sanctum (tokens), throttle, padrões de erro, logs com contexto e CORS por ambiente.
Abrir Bimestre 3 (Cap. 09) Próximo bimestre ↓

4º Bimestre — Internacionalização, Autorização Avançada, Qualidade/Desempenho e Empacotamento

Foco: i18n, policies/gates, segurança avançada, performance (N+1/cache) e deploy/empacotamento.
B4
  1. Capítulo 13 — Internacionalização (i18n) e Acessibilidade Básica resources/lang, locale, pluralização, formatos e noções de acessibilidade.
  2. Capítulo 14 — Autorização Fina (Policies/Gates) e Boas Práticas de Segurança Regras por negócio, defense-in-depth, mass assignment e segurança de upload.
  3. Capítulo 15 — Qualidade, Desempenho e Manutenção N+1, eager loading, cache simples, organização em serviços e comandos Artisan.
  4. Capítulo 16 — Empacotamento, Deploy e Fechamento (opcional PWA) Ambientes, build com Vite, .env.example, backup, Docker (opcional) e PWA leve.
