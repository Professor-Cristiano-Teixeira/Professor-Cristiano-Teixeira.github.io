3º Bimestre • Capítulo 11 (100 min/semana)

Painéis, Abas (TabControl) e Menus (MenuStrip/ToolStrip/StatusStrip)

Agora que você já tem telas mais organizadas (Cap. 09) e controles bem configurados (Cap. 10), vamos montar uma interface completa: menus com atalhos, barra de ferramentas, barra de status, abas para organizar módulos e painéis para mostrar/ocultar seções. O resultado é um “mini-sistema” com navegação profissional.

Roteiro Passo a passo Atividades

Objetivos de aprendizagem

  • Usar Panel, GroupBox e SplitContainer para organizar a tela.
  • Usar TabControl para separar módulos (Produtos/Vendas/Relatórios).
  • Criar navegação com MenuStrip e atalhos (Ctrl+N, Ctrl+F etc.).
  • Adicionar ToolStrip (atalhos visuais) e StatusStrip (feedback).
  • Implementar ContextMenuStrip no DataGridView (ações rápidas).
  • Aplicar isso no projeto mantendo MVC (Views → Controllers).

Pré-requisitos

  • Cap. 08 (MVC com Controllers) concluído
  • Cap. 09 (layout responsivo) aplicado
  • Cap. 10 (DataGridView/ComboBox) aplicado

Criar uma tela principal “Dashboard” com abas e menus, reduzindo quantidade de janelas abertas.

1) Parte teórica (organização de interfaces)

1.1 Por que usar abas e painéis?

Conforme um sistema cresce, abrir muitas janelas (Forms) deixa o usuário perdido. Uma solução clássica é ter uma tela principal com: Menu + Ações rápidas + Status + Conteúdo. O conteúdo pode ser organizado em abas (TabControl) ou em painéis que trocam de lugar.

1.2 MenuStrip, ToolStrip e StatusStrip

  • MenuStrip: navegação por categorias (Cadastros, Vendas, Relatórios, Ajuda).
  • ToolStrip: botões mais usados (Produtos, Venda, Atualizar, Sair).
  • StatusStrip: feedback (usuário, data/hora, mensagens “Pronto”).

1.3 ContextMenuStrip

Um menu de contexto (clique direito) dá produtividade. Exemplo: no DataGridView, abrir “Etiqueta”, “Copiar Nome”, “Remover”.

1.4 Abas com TabControl

TabControl é excelente quando os módulos são do mesmo “nível”. Ex.: Produtos, Venda e Relatórios. Cada aba pode conter um UserControl (ideal) ou um layout com controles.

Regra prática
Menu = navegação, ToolStrip = atalhos, StatusStrip = feedback. TabControl = módulos. Panel/SplitContainer = organização interna.

2) Passo a passo (Dashboard com abas + menus)

Vamos criar uma tela principal nova chamada FrmDashboard e integrar o sistema nela.

Antes de começar

  1. Execute o projeto e confirme que as telas abrem (Menu → Produtos, Venda, Relatórios).
  2. Faça backup/commit.

Passo 1 — Criar o FrmDashboard (Views)

  1. Crie um novo Form: Views/FrmDashboard.cs.
  2. No Designer, adicione: MenuStrip, ToolStrip, StatusStrip e um TabControl.
  3. Defina Dock do TabControl como Fill.
  4. Crie 3 abas: Produtos, Venda, Relatórios.
Estrutura recomendada
  • MenuStrip (Dock Top)
  • ToolStrip (Dock Top, logo abaixo do Menu)
  • StatusStrip (Dock Bottom)
  • TabControl (Dock Fill)

Passo 2 — Inserir as telas dentro das abas (forma simples)

Existem duas formas: A) Ideal: transformar telas em UserControls. B) Simples: abrir Forms dentro do painel da aba (TopLevel=false). Aqui vamos usar a forma simples para avançar rápido.

Arquivo: Views/FrmDashboard.cs (método para embutir um Form em uma TabPage)
using System;
using System.Windows.Forms;

namespace LanchoneteApp.Views
{
    public partial class FrmDashboard : Form
    {
        public FrmDashboard()
        {
            InitializeComponent();
            this.Text = "LanchoneteApp • Dashboard";
            this.WindowState = FormWindowState.Maximized;
        }

        private void AbrirFormNaAba(Form form, TabPage aba)
        {
            aba.Controls.Clear();
            form.TopLevel = false;
            form.FormBorderStyle = FormBorderStyle.None;
            form.Dock = DockStyle.Fill;
            aba.Controls.Add(form);
            form.Show();
        }
    }
}

Agora, no Load do Dashboard, abra as telas dentro das abas usando o mesmo Repository:

Arquivo: Views/FrmDashboard.cs (Load com repositório compartilhado)
using LanchoneteApp.Data;

private readonly ProdutoRepository _repo = new();

private void FrmDashboard_Load(object sender, EventArgs e)
{
    _repo.SeedBasico();

    AbrirFormNaAba(new FrmProdutos(_repo), tabProdutos);
    AbrirFormNaAba(new FrmVendaSimples(_repo), tabVenda);
    AbrirFormNaAba(new FrmEstoqueBaixo(_repo), tabRelatorios); // ou outro relatório
}
Importante
Como agora o Dashboard mantém o repositório, o Program.cs deve iniciar em FrmDashboard (e não mais em FrmMenu).

Passo 3 — Ajustar o Program.cs para iniciar no Dashboard

Arquivo: Program.cs (trecho)
using LanchoneteApp.Views;

ApplicationConfiguration.Initialize();
Application.Run(new FrmDashboard());

Passo 5 — ToolStrip: botões rápidos

No ToolStrip, crie botões: Produtos, Venda, Relatórios, Atualizar. Conecte os eventos para selecionar a aba e/ou atualizar.

Exemplo: botão Atualizar (força recarregar a aba atual)
private void btnAtualizar_Click(object sender, EventArgs e)
{
    // abordagem simples: reabrir o form na aba atual
    if (tabMain.SelectedTab == tabProdutos)
        AbrirFormNaAba(new FrmProdutos(_repo), tabProdutos);
    else if (tabMain.SelectedTab == tabVenda)
        AbrirFormNaAba(new FrmVendaSimples(_repo), tabVenda);
    else
        AbrirFormNaAba(new FrmEstoqueBaixo(_repo), tabRelatorios);

    SetStatus("Atualizado!");
}
Em projetos maiores, você atualiza via controller/binding. Aqui reabrir é aceitável para aprendizado.

Passo 6 — StatusStrip: mensagens e relógio

Adicione no StatusStrip: ToolStripStatusLabel (lblStatus) e um ToolStripStatusLabel (lblHora). Use um Timer (Interval = 1000) para atualizar a hora.

Arquivo: Views/FrmDashboard.cs (Status + Timer)
private void SetStatus(string msg)
{
    lblStatus.Text = msg;
}

private void timer1_Tick(object sender, EventArgs e)
{
    lblHora.Text = DateTime.Now.ToString("dd/MM/yyyy HH:mm:ss");
}

Passo 7 — ContextMenuStrip no DataGridView (Produtos)

No FrmProdutos adicione um ContextMenuStrip (cmsGrid) com itens: Etiqueta, Copiar Nome, Copiar ID. No evento CellMouseDown, selecione a linha ao clicar com botão direito.

Arquivo: Views/FrmProdutos.cs (selecionar linha no clique direito)
private void dgvProdutos_CellMouseDown(object sender, DataGridViewCellMouseEventArgs e)
{
    if (e.Button == MouseButtons.Right && e.RowIndex >= 0)
    {
        dgvProdutos.ClearSelection();
        dgvProdutos.Rows[e.RowIndex].Selected = true;
        dgvProdutos.CurrentCell = dgvProdutos.Rows[e.RowIndex].Cells[0];
    }
}
Exemplo: item “Copiar Nome”
private void copiarNomeToolStripMenuItem_Click(object sender, EventArgs e)
{
    if (dgvProdutos.CurrentRow?.DataBoundItem is dynamic row)
        Clipboard.SetText((string)row.Nome);
}
Exemplo: item “Etiqueta”
private void etiquetaToolStripMenuItem_Click(object sender, EventArgs e)
{
    if (dgvProdutos.CurrentRow?.DataBoundItem is dynamic row)
    {
        int id = (int)row.Id;
        MessageBox.Show(_controller.Etiqueta(id), "Etiqueta", MessageBoxButtons.OK, MessageBoxIcon.Information);
    }
}

3) Atividades práticas

Faça 2 atividades (ou todas). O foco é menus, abas e produtividade.

Atividade A — Abas dinâmicas
  • Crie um menu “Janela → Nova aba de Produtos”.
  • Ao clicar, crie uma nova TabPage “Produtos (2)” e carregue FrmProdutos nela.
  • Bônus: botão “Fechar aba atual”.
Atividade B — Barra de pesquisa no ToolStrip
  • Adicione um ToolStripTextBox “Buscar produto”.
  • Ao pressionar Enter, aplique filtro por nome na aba Produtos.
  • Dica: chame método do controller de filtro (Cap. 10).
Atividade C — Status avançado
  • Mostre no StatusStrip o total de produtos no repositório.
  • Atualize esse número ao cadastrar um novo produto.
  • Dica: exponha no controller um método Count().

Critérios rápidos

  • Menus com atalhos e eventos coerentes.
  • Abas organizando módulos sem abrir dezenas de janelas.
  • Context menu útil e funcionando.
  • StatusStrip informativo (não apenas decorativo).
