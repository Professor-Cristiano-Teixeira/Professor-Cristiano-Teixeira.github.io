2º Bimestre • Capítulo 05 (100 min/semana)

Herança e Sobrescrita de Métodos (override)

Vamos evoluir o sistema da lanchonete criando tipos diferentes de produto (ex.: Lanche e Bebida), reaproveitando código com herança e personalizando comportamentos com sobrescrita. Você vai preparar o terreno para polimorfismo (Cap. 06).

Roteiro Passo a passo Atividades

Objetivos de aprendizagem

  • Explicar herança (classe base e classe derivada).
  • Usar : para criar uma classe que herda de outra em C#.
  • Usar virtual e override para sobrescrever um método/propriedade.
  • Usar base para reaproveitar parte do comportamento da classe base.
  • Aplicar herança no projeto: Produto (base), Lanche e Bebida (derivadas).
  • Exibir no grid o tipo e detalhes do produto (sobrescrita).

Pré-requisitos

  • Estrutura por pastas/namespaces (Cap. 04)
  • Classe Produto encapsulada, Service/Repository funcionando
  • Windows Forms: DataGridView e eventos Click
Contexto do projeto
Agora “produto” terá variações: bebida e lanche, com informações diferentes — sem duplicar código.

1) Parte teórica (conceitos essenciais)

1.1 Herança (classe base e classe derivada)

Herança permite criar uma nova classe reaproveitando outra. A classe nova (derivada/filha) herda dados e comportamentos da classe existente (base/pai). Isso evita duplicação: se Produto já tem Nome, Preço e Estoque, não faz sentido reescrever tudo em Bebida e Lanche.

Pense na lanchonete: Lanche é um Produto e Bebida é um Produto. Ambos compartilham coisas em comum, mas também têm dados específicos (ex.: bebida tem volume, lanche tem tamanho).

1.2 Sobrescrita (override) — mudando um comportamento herdado

Sobrescrita é quando uma classe derivada altera (personaliza) um comportamento que vem da classe base. Para permitir sobrescrita em C#, o membro na classe base precisa ser virtual (ou abstract, que veremos no Cap. 07). Na classe derivada, usamos override.

Exemplo no nosso sistema: vamos criar uma propriedade Tipo e outra Detalhes na classe Produto. Para o Produto “genérico”, o tipo pode ser “Produto”. Já em Bebida o tipo vira “Bebida” e os detalhes mostram volume. Em Lanche, os detalhes mostram o tamanho.

1.3 base: reaproveitando parte do comportamento da classe pai

Às vezes você quer sobrescrever, mas ainda assim usar algo do pai. Para isso existe base. Por exemplo: a classe base pode ter uma Etiqueta() padrão com nome e preço. A classe filha pode acrescentar detalhes, chamando base.Etiqueta() e completando.

Regra prática
Use herança quando existir a relação “é um” (Bebida é um Produto). Use sobrescrita quando precisar personalizar a forma como algo é exibido/calculado.

2) Passo a passo (implementando herança no projeto)

Vamos criar as classes Lanche e Bebida em Models herdando de Produto. Em seguida, vamos adicionar membros virtual na classe base e sobrescrever nas classes derivadas. Depois, vamos ajustar o Seed do repositório e criar um botão na tela para exibir a etiqueta do item selecionado.

Antes de começar

  1. Abra a solução LanchoneteApp.
  2. Garanta que a estrutura de pastas/namespace do Cap. 04 está aplicada (Models, Data, Services, Views).
  3. Execute (F5) e confirme que abre o FrmMenu.

Passo 1 — Atualizar a classe base Produto para permitir sobrescrita

Vamos adicionar em Produto: (1) propriedades virtuais Tipo e Detalhes; (2) método virtual Etiqueta(). Assim, classes derivadas podem sobrescrever.

  1. Abra Models/Produto.cs.
  2. Adicione os membros abaixo ao final da classe (sem remover o que você já tem).
Arquivo: Models/Produto.cs (adicione estes membros dentro da classe)
// --- NOVO (Cap. 05): membros virtuais para sobrescrita ---

public virtual string Tipo => "Produto";

public virtual string Detalhes => "";

public virtual string Etiqueta()
{
    // Etiqueta padrão: pode ser reaproveitada com base.Etiqueta() nas classes filhas
    return $"[{Tipo}] {Nome} • Preço: {Preco:C} • Estoque: {Estoque}";
}
Dica
Coloque esses membros dentro da classe Produto, abaixo dos métodos existentes.

Passo 2 — Criar a classe derivada Bebida

  1. Crie Models/Bebida.cs.
  2. Use o código abaixo.
Arquivo: Models/Bebida.cs
using System;

namespace LanchoneteApp.Models
{
    // Bebida HERDA de Produto
    public class Bebida : Produto
    {
        public int VolumeMl { get; private set; }
        public bool Alcoolica { get; private set; }

        // Construtor chamando o construtor da base
        public Bebida(int id, string nome, decimal preco, int estoque, int volumeMl, bool alcoolica)
            : base(id, nome, preco, estoque)
        {
            if (volumeMl <= 0)
                throw new ArgumentException("Volume deve ser maior que zero.");

            VolumeMl = volumeMl;
            Alcoolica = alcoolica;
        }

        // Sobrecarga: ID automático (usa construtor da base que gera id)
        public Bebida(string nome, decimal preco, int estoque, int volumeMl, bool alcoolica)
            : base(nome, preco, estoque)
        {
            if (volumeMl <= 0)
                throw new ArgumentException("Volume deve ser maior que zero.");

            VolumeMl = volumeMl;
            Alcoolica = alcoolica;
        }

        // OVERRIDE (sobrescrita)
        public override string Tipo => "Bebida";

        public override string Detalhes => $"{VolumeMl}ml • {(Alcoolica ? "Alcoólica" : "Não alcoólica")}";

        public override string Etiqueta()
        {
            // Reaproveita etiqueta base e acrescenta detalhes
            return base.Etiqueta() + $" • {Detalhes}";
        }
    }
}

Passo 3 — Criar a classe derivada Lanche

  1. Crie Models/Lanche.cs.
  2. Use o código abaixo.
Arquivo: Models/Lanche.cs
using System;

namespace LanchoneteApp.Models
{
    // Lanche HERDA de Produto
    public class Lanche : Produto
    {
        public string Tamanho { get; private set; } // Ex.: Pequeno, Médio, Grande

        public Lanche(int id, string nome, decimal preco, int estoque, string tamanho)
            : base(id, nome, preco, estoque)
        {
            if (string.IsNullOrWhiteSpace(tamanho))
                throw new ArgumentException("Tamanho não pode ser vazio.");

            Tamanho = tamanho.Trim();
        }

        public Lanche(string nome, decimal preco, int estoque, string tamanho)
            : base(nome, preco, estoque)
        {
            if (string.IsNullOrWhiteSpace(tamanho))
                throw new ArgumentException("Tamanho não pode ser vazio.");

            Tamanho = tamanho.Trim();
        }

        public override string Tipo => "Lanche";

        public override string Detalhes => $"Tamanho: {Tamanho}";

        public override string Etiqueta()
        {
            return base.Etiqueta() + $" • {Detalhes}";
        }
    }
}

Passo 4 — Atualizar o repositório para carregar exemplos com herança

Agora o repositório vai armazenar uma lista de Produto, mas dentro dela pode haver Lanche e Bebida. Isso já é um gostinho de polimorfismo (Cap. 06).

  1. Abra Data/ProdutoRepository.cs.
  2. No método SeedBasico(), substitua os _dados.Add por estes:
Arquivo: Data/ProdutoRepository.cs (SeedBasico atualizado)
public void SeedBasico()
{
    if (_dados.Count > 0) return;

    _dados.Add(new Lanche(1, "X-Burger", 18.50m, 5, "Grande"));
    _dados.Add(new Lanche(2, "Batata Frita", 12.00m, 2, "Média"));
    _dados.Add(new Bebida(3, "Refrigerante Cola", 7.00m, 12, 350, false));
    _dados.Add(new Bebida(4, "Cerveja", 9.50m, 6, 350, true));
}
Se aparecer erro de classe não encontrada, confira os using do repositório: using LanchoneteApp.Models;.

Passo 6 — Botão “Etiqueta” usando método sobrescrito

Vamos criar um botão que pega o item selecionado e chama Etiqueta(). Como Etiqueta() é virtual na base e override nas filhas, a mensagem muda conforme o tipo.

  1. No FrmProdutos, adicione um botão btnEtiqueta (Text: Mostrar Etiqueta).
  2. Dê duplo clique para criar o evento e use o código abaixo.
Arquivo: Views/FrmProdutos.cs (evento do botão Etiqueta)
private void btnEtiqueta_Click(object sender, EventArgs e)
{
    try
    {
        if (dgvProdutos.CurrentRow?.DataBoundItem is Produto p)
        {
            MessageBox.Show(p.Etiqueta(), "Etiqueta", MessageBoxButtons.OK, MessageBoxIcon.Information);
            return;
        }
        throw new InvalidOperationException("Selecione um produto no grid.");
    }
    catch (Exception ex)
    {
        MessageBox.Show(ex.Message, "Atenção", MessageBoxButtons.OK, MessageBoxIcon.Warning);
    }
}
O que aconteceu aqui?
Você chamou Etiqueta() a partir de uma referência do tipo Produto. O método executado depende do tipo real (Lanche/Bebida). Isso prepara o polimorfismo (Cap. 06).
