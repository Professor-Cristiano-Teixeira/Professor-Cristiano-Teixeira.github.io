3º Bimestre • Capítulo 10 (100 min/semana)

Controles de Tela (WinForms): DataGridView, ComboBox, Máscaras e Diálogos

Neste capítulo você vai dominar os controles mais usados do Windows Forms. Vamos melhorar o FrmProdutos e o FrmVendaSimples com: DataGridView (colunas, formatação e eventos), ComboBox (binding e AutoComplete), MaskedTextBox/NumericUpDown (entradas seguras), e diálogos como OpenFileDialog e ColorDialog.

Roteiro Passo a passo Atividades

Objetivos de aprendizagem

  • Configurar DataGridView: colunas, formatação, seleção e eventos.
  • Usar BindingSource para atualizar grid/combos sem “gambiarras”.
  • Configurar ComboBox com ViewModel e AutoComplete.
  • Usar NumericUpDown e MaskedTextBox para entradas mais seguras.
  • Aplicar diálogos (OpenFileDialog, ColorDialog) para melhorar UX.
  • Implementar filtro por nome e destaque visual para estoque baixo no grid.

Pré-requisitos

  • Cap. 08 (MVC com Controllers e ViewModels) concluído
  • Cap. 09 (layout com Dock/Anchor/TableLayoutPanel) aplicado
  • Forms: FrmProdutos e FrmVendaSimples funcionando
Meta do capítulo
Telas mais rápidas de usar, com menos erro de digitação e grid “inteligente”.

1) Parte teórica (controles essenciais)

1.1 DataGridView: o “painel de dados”

O DataGridView exibe listas e tabelas. Ele funciona melhor quando você decide: (A) colunas automáticas (rápido, porém menos controle) ou (B) colunas manuais (mais trabalho, porém UI mais bonita). Para projetos escolares e profissionais, colunas manuais são recomendadas quando a tela é “final”.

1.2 BindingSource: atualizações sem dor

Em vez de ficar fazendo DataSource = null toda hora, você pode usar um BindingSource. Ele “segura” a lista para o grid/combos e você só faz ResetBindings(false) para atualizar.

1.3 ComboBox: escolha guiada

Um ComboBox com DisplayMember e ValueMember evita erro de digitação. Com AutoComplete, o usuário digita e o controle sugere.

1.4 Entradas seguras

  • NumericUpDown: quantidade sem “texto inválido”.
  • MaskedTextBox: aplica máscara (ex.: “0000” para ml, “00/00/0000” para data).
  • DateTimePicker: data/hora sem erro de formato.

1.5 Diálogos úteis

  • OpenFileDialog: abrir arquivo (ex.: imagem do produto).
  • ColorDialog: escolher cor (ex.: cor de destaque do sistema).
  • FontDialog: escolher fonte (opcional).
Regra prática
Use controles que impedem erro antes de acontecer (NumericUpDown/ComboBox) e deixe validação para regras de negócio no Service/Controller.

2) Passo a passo (aplicando no projeto)

Vamos melhorar FrmProdutos e FrmVendaSimples sem quebrar MVC.

Antes de começar

  1. Execute o projeto e confirme que Produtos e Venda Simples abrem (Cap. 08).
  2. Faça backup/commit.

Passo 1 — Criar colunas manuais no DataGridView (Produtos)

No Designer do FrmProdutos: (1) selecione o DataGridView, (2) defina AutoGenerateColumns = false, (3) clique em “Edit Columns...” e crie colunas com os seguintes DataPropertyName: Id, Nome, Preco, Estoque, Tipo, Detalhes.

Configuração recomendada
  • SelectionMode = FullRowSelect
  • MultiSelect = false
  • ReadOnly = true
  • AllowUserToAddRows = false
  • AutoSizeColumnsMode = Fill (ou DisplayedCells)
Opcional: ajustar formatação por código (moeda e alinhamento)
// após InitializeComponent()
dgvProdutos.Columns["Preco"].DefaultCellStyle.Format = "C";
dgvProdutos.Columns["Preco"].DefaultCellStyle.Alignment = DataGridViewContentAlignment.MiddleRight;
dgvProdutos.Columns["Estoque"].DefaultCellStyle.Alignment = DataGridViewContentAlignment.MiddleCenter;

Passo 2 — Usar BindingSource para atualizar o grid com eficiência

No FrmProdutos, crie um BindingSource e use ele como DataSource. Assim, quando atualizar, você troca a lista no BindingSource ou chama ResetBindings.

Arquivo: Views/FrmProdutos.cs (BindingSource)
private readonly BindingSource _bsProdutos = new BindingSource();

private void ConfigurarGrid()
{
    dgvProdutos.AutoGenerateColumns = false;
    dgvProdutos.DataSource = _bsProdutos;
}

private void AtualizarGrid()
{
    _bsProdutos.DataSource = _controller.ListarParaGrid();
    _bsProdutos.ResetBindings(false);
}
Dica: chame ConfigurarGrid() no construtor e depois AtualizarGrid().

Passo 3 — Destacar estoque baixo com CellFormatting

Vamos pintar linhas com estoque <= 3 (ex.: amarelo) e estoque 0 (vermelho). Isso melhora muito a leitura do grid.

Arquivo: Views/FrmProdutos.cs (evento CellFormatting)
private void dgvProdutos_CellFormatting(object sender, DataGridViewCellFormattingEventArgs e)
{
    if (dgvProdutos.Rows[e.RowIndex].DataBoundItem is dynamic row)
    {
        int estoque = (int)row.Estoque;
        var gridRow = dgvProdutos.Rows[e.RowIndex];

        if (estoque == 0)
        {
            gridRow.DefaultCellStyle.BackColor = Color.MistyRose;
            gridRow.DefaultCellStyle.ForeColor = Color.DarkRed;
        }
        else if (estoque <= 3)
        {
            gridRow.DefaultCellStyle.BackColor = Color.LemonChiffon;
            gridRow.DefaultCellStyle.ForeColor = Color.Black;
        }
        else
        {
            gridRow.DefaultCellStyle.BackColor = Color.White;
            gridRow.DefaultCellStyle.ForeColor = Color.Black;
        }
    }
}
Lembrete
Não esqueça de adicionar o using System.Drawing; no topo do arquivo.

Passo 4 — Filtro por nome (TextBox + botão “Filtrar”)

Vamos adicionar um TextBox txtFiltro e um botão btnFiltrar no topo do painel de formulário. A lógica de filtro deve ficar no Controller (ou no Form de forma mínima).

Adicionar no Controller: método de filtro simples
// em ProdutoController
public List<ProdutoListItemVM> FiltrarPorNome(string texto)
{
    texto = (texto ?? "").Trim().ToLower();
    var lista = ListarParaGrid();
    if (string.IsNullOrWhiteSpace(texto)) return lista;

    return lista.Where(p => p.Nome.ToLower().Contains(texto)).ToList();
}
No Form: usar filtro
private void btnFiltrar_Click(object sender, EventArgs e)
{
    _bsProdutos.DataSource = _controller.FiltrarPorNome(txtFiltro.Text);
    _bsProdutos.ResetBindings(false);
}

private void btnLimparFiltro_Click(object sender, EventArgs e)
{
    txtFiltro.Clear();
    AtualizarGrid();
}

Passo 5 — ComboBox com AutoComplete (Venda Simples)

No FrmVendaSimples, configure o ComboBox assim:

  • DropDownStyle = DropDown (para permitir digitar)
  • AutoCompleteMode = SuggestAppend
  • AutoCompleteSource = ListItems
Exemplo (no construtor, após carregar produtos)
cboProduto.DropDownStyle = ComboBoxStyle.DropDown;
cboProduto.AutoCompleteMode = AutoCompleteMode.SuggestAppend;
cboProduto.AutoCompleteSource = AutoCompleteSource.ListItems;

Passo 6 — Substituir TextBox de quantidade por NumericUpDown

Troque txtQtd por nudQtd (NumericUpDown) no Designer. Configure Minimum = 1, Maximum = 999, Value = 1. Depois, ajuste a chamada do controller.

Arquivo: Views/FrmVendaSimples.cs (chamar controller com nudQtd)
private void btnCalcular_Click(object sender, EventArgs e)
{
    try
    {
        int id = IdSelecionado();
        int qtd = (int)nudQtd.Value;
        decimal total = _vendaController.CalcularTotal(id, qtd.ToString(), txtDesconto.Text);
        lblResultado.Text = $"Total: {total:C}";
    }
    catch (Exception ex)
    {
        MessageBox.Show(ex.Message, "Atenção", MessageBoxButtons.OK, MessageBoxIcon.Warning);
    }
}
Você continua passando string para reaproveitar o método do Controller, mas agora a quantidade nunca será inválida.

Passo 7 — MaskedTextBox para volume (ml) e desconto (opcional)

Para reduzir erro de digitação, você pode usar MaskedTextBox no volume (4 dígitos) e desconto (3 dígitos). Exemplo de máscara:

  • Volume (ml): 0000
  • Desconto (%): 000
Exemplo de configuração (Designer ou código)
mskVolume.Mask = "0000";
mskDesconto.Mask = "000";

Passo 8 — OpenFileDialog + PictureBox (imagem do produto) (opcional)

Para dar um salto de UX, adicione um PictureBox e um botão “Carregar imagem”. Isso não muda o Model (por enquanto é só visual).

Exemplo: abrir imagem e exibir no PictureBox
private void btnImagem_Click(object sender, EventArgs e)
{
    using var dlg = new OpenFileDialog();
    dlg.Filter = "Imagens|*.png;*.jpg;*.jpeg;*.bmp";
    dlg.Title = "Escolha uma imagem";

    if (dlg.ShowDialog() == DialogResult.OK)
    {
        picProduto.SizeMode = PictureBoxSizeMode.Zoom;
        picProduto.Image = Image.FromFile(dlg.FileName);
    }
}
Cuidados
Em projetos reais, você salva caminho/bytes em banco. Aqui é apenas para demonstrar controle e diálogo.

Passo 9 — Testes obrigatórios

  • O grid mostra colunas corretas e preço formatado em moeda.
  • Linhas com estoque baixo ficam destacadas (<=3) e estoque 0 em vermelho.
  • Filtro por nome funciona e limpar filtro restaura lista.
  • Venda: ComboBox sugere itens ao digitar (AutoComplete).
  • Venda: quantidade não aceita valores inválidos (NumericUpDown).
Resultado esperado
Interface mais confiável: o usuário erra menos e acha as coisas mais rápido.

3) Atividades práticas

Faça 2 atividades (ou todas). O foco é dominar controles e eventos.

Atividade A — Duplo clique no grid
  • No evento CellDoubleClick, mostre a etiqueta do item selecionado.
  • Use o Controller para obter a etiqueta pelo Id.
  • Mostre em MessageBox (ou painel lateral).
Atividade B — Ordenação e busca rápida
  • Ative ordenação por clique no cabeçalho do grid.
  • Adicione busca rápida no TextBox: filtrar ao digitar (evento TextChanged).
  • Garanta que limpar o texto restaura lista.
Atividade C — ColorDialog (tema do grid)
  • Crie um botão “Cor do destaque”.
  • Use ColorDialog para escolher a cor de estoque baixo.
  • Guarde a cor em uma variável e aplique no CellFormatting.

Critérios rápidos

  • Uso correto de eventos de controles (CellFormatting, TextChanged, Click).
  • Menos validação manual (NumericUpDown/ComboBox/MaskedTextBox).
  • UI clara: feedback visual e comandos fáceis de encontrar.
