Preparação • Windows (casa)

Preparação do Ambiente: Visual Studio 2022 + XAMPP

Siga este passo a passo para deixar seu computador pronto para as atividades. Ao final, você conseguirá criar e rodar projetos no Visual Studio e subir o banco local com XAMPP.

Começar Ver checklist

Antes de instalar (5 minutos)

  1. Atualize o Windows (Configurações → Windows Update).
  2. Garanta pelo menos 20–30 GB livres no disco (ideal: SSD).
  3. Tenha uma conta Microsoft para entrar no Visual Studio (opcional, mas recomendado).
  4. Se tiver antivírus muito agressivo, evite bloquear instaladores (não desative permanentemente).
Importante
Instale com permissões de administrador quando solicitado (UAC).

Requisitos mínimos (referência)

  • Windows 10/11 64-bit
  • CPU 64-bit (1.8 GHz+), RAM 4 GB+ (recomendado 8–16 GB)
  • Internet para baixar instaladores

Se o PC for mais fraco, ainda dá para estudar, mas o Visual Studio pode ficar lento.

1) Passo a passo (instalações e configuração)

1.1 Instalar o Visual Studio Community 2022

O Visual Studio Community é a IDE usada para criar projetos em C# (Windows Forms). Baixe sempre do site oficial.

Download Visual Studio Community Página de Downloads Instalador VS 2022 (vs_community.exe)

Se a página do Visual Studio baixar uma versão mais nova, use o instalador acima (linha 17.x) para manter a versão 2022.

  1. Abra o link acima e clique em Download.
  2. Execute o instalador (ex.: vs_community.exe).
  3. Quando abrir o Visual Studio Installer, clique em Continuar.
  4. Na tela de workloads, marque:
    • .NET desktop development (obrigatório para WinForms).
    • (Opcional) Data storage and processing (ajuda com ferramentas de banco).
  5. Clique em Instalar e aguarde (pode demorar).
Teste rápido do Visual Studio
Abra o Visual Studio → Create a new project → procure por Windows Forms App (C#). Se aparecer, você instalou o workload correto.
(Opcional) Verificar versão do Windows (PowerShell)
winver
# ou
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsHardwareAbstractionLayer

1.2 Instalar o XAMPP (Apache + MariaDB)

O XAMPP fornece um servidor local e o banco (MariaDB), que é compatível com MySQL na maioria dos casos. Para a apostila, o importante é ter um banco local funcionando na porta 3306.

Download XAMPP (Apache Friends)
  1. Baixe o instalador XAMPP for Windows (64-bit).
  2. Execute o instalador e mantenha os componentes padrão (Apache + MySQL/MariaDB + phpMyAdmin).
  3. Escolha um caminho simples, por exemplo: C:\\xampp.
  4. Ao final, abra o XAMPP Control Panel.
  5. Clique em Start em:
    • Apache (para o localhost)
    • MySQL (MariaDB)
  6. Abra o navegador e teste:
    • http://localhost (deve abrir a página do XAMPP)
    • http://localhost/phpmyadmin (gerenciador do banco)
Portas e firewall
Se o Apache não iniciar, a porta 80 pode estar ocupada (IIS/Skype/Outro). Se necessário, use a porta 8080. Se o MySQL não iniciar, verifique se a porta 3306 está livre. Quando o Windows pedir, clique em Permitir acesso para o XAMPP.

1.3 Criar o banco do projeto (phpMyAdmin)

Agora vamos criar o banco e inserir dados iniciais (se você estiver seguindo os capítulos 13–16). No phpMyAdmin, clique em SQL e execute scripts.

Criar database e tabela (SQL)
CREATE DATABASE IF NOT EXISTS lanchonete_db
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE lanchonete_db;

CREATE TABLE IF NOT EXISTS produto (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(120) NOT NULL,
  preco DECIMAL(10,2) NOT NULL,
  estoque INT NOT NULL DEFAULT 0,
  tipo ENUM('Lanche','Bebida') NOT NULL,
  tamanho VARCHAR(20) NULL,
  volume_ml INT NULL,
  alcoolica TINYINT(1) NULL,
  criado_em TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
Inserir alguns produtos (seed)
USE lanchonete_db;

INSERT INTO produto (nome,preco,estoque,tipo,tamanho,volume_ml,alcoolica) VALUES
('X-Salada', 18.50, 10, 'Lanche', 'M', NULL, NULL),
('Refrigerante Lata', 6.00, 20, 'Bebida', NULL, 350, 0);

1.4 Configurar a conexão no projeto (App.config)

Para os capítulos com MySQL, você vai colocar a connection string no App.config. Se estiver usando XAMPP, o servidor costuma ser localhost e porta 3306.

Modelo (ajuste usuário/senha conforme seu XAMPP)
<configuration>
  <connectionStrings>
    <add name="LanchoneteDb"
         connectionString="Server=localhost;Port=3306;Database=lanchonete_db;Uid=root;Pwd=;SslMode=Preferred;" />
  </connectionStrings>
</configuration>
Recomendação
Defina uma senha para o usuário do banco e use um usuário específico do sistema (não admin) quando possível.

1.5 Instalações recomendadas (opcionais, mas ajudam)

  • Git: facilita backup/commit do projeto (Git já vem integrado ao Visual Studio).
  • MySQL Workbench (se você preferir ao phpMyAdmin): ajuda a executar scripts e visualizar tabelas.
  • 7-Zip: para compactar o projeto em .zip para as entregas.
Importante
Mesmo sem itens opcionais, você consegue fazer a apostila. Eles só melhoram o fluxo.
