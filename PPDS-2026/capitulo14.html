4º Bimestre • Capítulo 14 (100 min/semana)

DAO e CRUD (MySQL) — Persistindo Produtos

Neste capítulo você vai implementar o DAO (Data Access Object) e o CRUD (Create, Read, Update, Delete) usando MySQL. Você vai criar classes de acesso ao banco, mapear a tabela produto para Lanche e Bebida, e substituir o repositório em memória por um repositório baseado em banco. No Capítulo 15 vamos reforçar ainda mais segurança com parâmetros e prevenção de SQL Injection.

Roteiro Passo a passo Atividades

Objetivos de aprendizagem

  • Explicar o que é DAO e por que ele reduz acoplamento com o banco.
  • Implementar CRUD completo na tabela produto usando comandos parametrizados.

  • Criar um repositório MySQL para substituir o repositório em memória.
  • Integrar o DAO ao sistema (Controllers/Views) mantendo MVC.

1) Parte teórica (DAO e CRUD)

1.1 O que é DAO?

DAO (Data Access Object) é uma classe responsável por acessar o banco. Ela encapsula SQL e operações de leitura/escrita, evitando que a UI ou Controllers conheçam detalhes de SQL. Isso melhora manutenção: se amanhã mudar MySQL para outro banco, você troca o DAO.

1.2 CRUD

  • Create: inserir registros (INSERT)
  • Read: consultar registros (SELECT)
  • Update: atualizar registros (UPDATE)
  • Delete: remover registros (DELETE)

1.3 Mapeamento objeto-relacional (bem simples)

Sua tabela produto tem campos comuns e campos específicos. No código, vamos mapear assim:

  • tipo = 'Lanche' ⇒ cria new Lanche(..., tamanho)
  • tipo = 'Bebida' ⇒ cria new Bebida(..., volumeMl, alcoolica)
Segurança (já comece certo)
Use sempre parâmetros no SQL. Evite concatenar strings com dados do usuário. Cap. 15 aprofunda isso.

Passo 1 — Criar uma interface de repositório

Para não quebrar o MVC e permitir trocar a fonte dos dados (memória vs MySQL), crie uma interface IProdutoRepository.

Arquivo: Data/IProdutoRepository.cs
using System.Collections.Generic;
using LanchoneteApp.Models;

namespace LanchoneteApp.Data
{
    public interface IProdutoRepository
    {
        List<Produto> GetAll();
        Produto? FindById(int id);
        void Add(Produto p);
        void Update(Produto p);
        void Delete(int id);
    }
}
Seu repositório em memória pode implementar essa interface depois (opcional). Vamos focar no MySQL.

Passo 2 — Criar o DAO (ProdutoDaoMySql)

O DAO executa SQL e devolve objetos Produto. Ele usa a MySqlConnectionFactory.

Arquivo: Data/ProdutoDaoMySql.cs (CRUD)
using System;
using System.Collections.Generic;
using MySql.Data.MySqlClient;
using LanchoneteApp.Models;

namespace LanchoneteApp.Data
{
    public class ProdutoDaoMySql
    {
        private Produto Map(MySqlDataReader r)
        {
            int id = r.GetInt32("id");
            string nome = r.GetString("nome");
            decimal preco = r.GetDecimal("preco");
            int estoque = r.GetInt32("estoque");
            string tipo = r.GetString("tipo");

            if (tipo == "Lanche")
            {
                string tamanho = r["tamanho"] == DBNull.Value ? "" : r.GetString("tamanho");
                return new Lanche(id, nome, preco, estoque, tamanho);
            }
            else // Bebida
            {
                int volume = r["volume_ml"] == DBNull.Value ? 0 : r.GetInt32("volume_ml");
                bool alcoolica = r["alcoolica"] != DBNull.Value && r.GetInt32("alcoolica") == 1;
                return new Bebida(id, nome, preco, estoque, volume, alcoolica);
            }
        }

        public List<Produto> Listar()
        {
            var lista = new List<Produto>();
            using var conn = MySqlConnectionFactory.Create();
            conn.Open();

            using var cmd = new MySqlCommand(
                "SELECT id,nome,preco,estoque,tipo,tamanho,volume_ml,alcoolica FROM produto ORDER BY id DESC", conn);

            using var r = cmd.ExecuteReader();
            while (r.Read())
                lista.Add(Map(r));

            return lista;
        }

        public Produto? ObterPorId(int id)
        {
            using var conn = MySqlConnectionFactory.Create();
            conn.Open();

            using var cmd = new MySqlCommand(
                "SELECT id,nome,preco,estoque,tipo,tamanho,volume_ml,alcoolica FROM produto WHERE id=@id", conn);
            cmd.Parameters.AddWithValue("@id", id);

            using var r = cmd.ExecuteReader();
            return r.Read() ? Map(r) : null;
        }

        public int Inserir(Produto p)
        {
            using var conn = MySqlConnectionFactory.Create();
            conn.Open();

            string sql = @"INSERT INTO produto (nome,preco,estoque,tipo,tamanho,volume_ml,alcoolica)
                           VALUES (@nome,@preco,@estoque,@tipo,@tamanho,@volume,@alcoolica);
                           SELECT LAST_INSERT_ID();";

            using var cmd = new MySqlCommand(sql, conn);
            PreencherParametros(cmd, p);

            object? id = cmd.ExecuteScalar();
            return Convert.ToInt32(id);
        }

        public bool Atualizar(Produto p)
        {
            using var conn = MySqlConnectionFactory.Create();
            conn.Open();

            string sql = @"UPDATE produto
                           SET nome=@nome, preco=@preco, estoque=@estoque, tipo=@tipo,
                               tamanho=@tamanho, volume_ml=@volume, alcoolica=@alcoolica
                           WHERE id=@id";

            using var cmd = new MySqlCommand(sql, conn);
            cmd.Parameters.AddWithValue("@id", p.Id);
            PreencherParametros(cmd, p);

            int linhas = cmd.ExecuteNonQuery();
            return linhas > 0;
        }

        public bool Remover(int id)
        {
            using var conn = MySqlConnectionFactory.Create();
            conn.Open();

            using var cmd = new MySqlCommand("DELETE FROM produto WHERE id=@id", conn);
            cmd.Parameters.AddWithValue("@id", id);

            int linhas = cmd.ExecuteNonQuery();
            return linhas > 0;
        }

        private void PreencherParametros(MySqlCommand cmd, Produto p)
        {
            cmd.Parameters.AddWithValue("@nome", p.Nome);
            cmd.Parameters.AddWithValue("@preco", p.Preco);
            cmd.Parameters.AddWithValue("@estoque", p.Estoque);
            cmd.Parameters.AddWithValue("@tipo", p.Tipo);

            if (p is Lanche l)
            {
                cmd.Parameters.AddWithValue("@tamanho", l.Tamanho);
                cmd.Parameters.AddWithValue("@volume", DBNull.Value);
                cmd.Parameters.AddWithValue("@alcoolica", DBNull.Value);
            }
            else if (p is Bebida b)
            {
                cmd.Parameters.AddWithValue("@tamanho", DBNull.Value);
                cmd.Parameters.AddWithValue("@volume", b.VolumeMl);
                cmd.Parameters.AddWithValue("@alcoolica", b.Alcoolica ? 1 : 0);
            }
            else
            {
                // se surgir outro tipo no futuro
                cmd.Parameters.AddWithValue("@tamanho", DBNull.Value);
                cmd.Parameters.AddWithValue("@volume", DBNull.Value);
                cmd.Parameters.AddWithValue("@alcoolica", DBNull.Value);
            }
        }
    }
}
Atenção ao tipo
O campo tipo no banco usa valores Lanche e Bebida. Garanta que suas propriedades Tipo retornem exatamente esses textos.

Passo 3 — Criar o repositório MySQL (implementa IProdutoRepository)

O repositório será um adaptador: ele implementa a interface e chama o DAO. Assim, Controllers/Services não precisam saber SQL.

Arquivo: Data/ProdutoRepositoryMySql.cs
using System.Collections.Generic;
using LanchoneteApp.Models;

namespace LanchoneteApp.Data
{
    public class ProdutoRepositoryMySql : IProdutoRepository
    {
        private readonly ProdutoDaoMySql _dao = new();

        public List<Produto> GetAll() => _dao.Listar();
        public Produto? FindById(int id) => _dao.ObterPorId(id);

        public void Add(Produto p)
        {
            int id = _dao.Inserir(p);
            // opcional: se seu Model permitir setar Id, ajuste; se não, ignore
            // Em muitos projetos, Id é set privado. Nesse caso, apenas confie no banco.
        }

        public void Update(Produto p) => _dao.Atualizar(p);
        public void Delete(int id) => _dao.Remover(id);
    }
}
Nota sobre Id
Como o banco gera o Id, você não precisa aceitar Id manual no cadastro. No Cap. 14/15 você pode ocultar o campo Id na UI.

Passo 4 — Ajustar Controllers/Services para dependerem da interface

Refatore o ProdutoController para receber IProdutoRepository (em vez de ProdutoRepository). Faça o mesmo nos outros. Isso permite trocar de memória para MySQL sem alterar a lógica.

Exemplo: ProdutoController (construtor)
private readonly IProdutoRepository _repo;
private readonly ProdutoService _service;

public ProdutoController(IProdutoRepository repo)
{
    _repo = repo;
    _service = new ProdutoService(_repo); // ajuste ProdutoService para aceitar IProdutoRepository
}
Refatoração necessária
Se seu ProdutoService foi criado com ProdutoRepository concreto, altere-o para receber IProdutoRepository. Isso é DI manual.

Passo 5 — No Dashboard, trocar para repositório MySQL

Em vez de manter um repositório em memória no Dashboard, mantenha um IProdutoRepository e instancie a versão MySQL.

Arquivo: Views/FrmDashboard.cs (trecho)
using LanchoneteApp.Data;

private readonly IProdutoRepository _repo = new ProdutoRepositoryMySql();

private void FrmDashboard_Load(object sender, EventArgs e)
{
    AbrirFormNaAba(new FrmProdutos(_repo), tabProdutos);
    AbrirFormNaAba(new FrmVendaSimples(_repo), tabVenda);
    AbrirFormNaAba(new FrmRelatorios(_repo), tabRelatorios);
}
Você precisará ajustar os construtores dos Forms para receber IProdutoRepository em vez de ProdutoRepository.

Passo 6 — Ajustar os Forms (Views) para receber IProdutoRepository

Atualize os construtores de FrmProdutos, FrmVendaSimples e FrmRelatorios para receberem IProdutoRepository.

Exemplo: FrmProdutos (construtor)
private readonly ProdutoController _controller;

public FrmProdutos(IProdutoRepository repo)
{
    InitializeComponent();
    _controller = new ProdutoController(repo);
    ConfigurarGrid();
    AtualizarGrid();
}
Resultado
Agora sua UI não sabe se os dados vêm da memória ou do MySQL — ela só fala com Controllers.

  • Cadastre um Lanche e uma Bebida: feche e reabra o app — os itens continuam lá (persistência).

3) Atividades práticas

Faça 2 atividades (ou todas). O foco é consolidar CRUD + boas práticas.

Atividade A — Busca no banco
  • Crie no DAO um método BuscarPorNome(string texto).
  • Use LIKE com parâmetros (@texto).
  • Integre ao filtro do Cap. 10 (agora filtrando no banco).
Atividade B — Transação (bônus técnico)
  • Implemente uma transação para atualizar estoque e registrar uma venda (tabela nova opcional).
  • Use MySqlTransaction com commit/rollback.
  • Explique em 5 linhas por que transação evita inconsistência.
Atividade C — Logs e mensagens
  • Crie um método para registrar erros em logs.txt (data + mensagem).
  • Em falhas do DAO, mostre mensagem amigável ao usuário.
  • Evite exibir stack trace no MessageBox (mostre só no log).

Critérios rápidos

  • CRUD completo com comandos parametrizados.
  • Mapeamento correto para Lanche/Bebida.
  • Persistência real (fecha e abre e mantém dados).
  • Arquitetura preservada (View não faz SQL).
