POO em C#: Classe, Objeto e Instanciação

Neste capítulo você vai entender como a Programação Orientada a Objetos organiza um sistema e vai iniciar o projeto da Lanchonete criando a primeira classe (Produto) e instanciando objetos para exibir na tela.

Roteiro da aula Passo a passo Atividades

Objetivos de aprendizagem

  • Explicar os conceitos de classe, objeto e instância.
  • Criar uma classe em C# no Visual Studio e instanciar objetos com new.
  • Organizar o projeto inicial do sistema da lanchonete em pastas (ex.: Models).
  • Exibir dados de objetos em uma interface Windows Forms (DataGridView).

Pré-requisitos

  • Noções de lógica e variáveis
  • Conceito de tabela e registros (Banco de Dados 1/2)
  • Ambiente: Windows + Visual Studio 2022 + XAMPP (MySQL) (neste capítulo ainda sem banco)
Observação
Hoje o foco é POO e uma versão em memória. A conexão com MySQL será no 4º bimestre.

1) Parte teórica (conceitos essenciais)

1.1 O que é Programação Orientada a Objetos (POO)?

A POO é um jeito de programar em que organizamos o sistema como um conjunto de objetos que representam coisas do mundo real ou do problema (por exemplo: Produto, Venda, Operador). Cada objeto tem dados (o que ele “sabe”) e ações (o que ele “faz”). Isso ajuda a deixar o código mais organizado, mais fácil de manter e de evoluir.

No nosso sistema da lanchonete, pensar em objetos facilita separar responsabilidades: o Produto guarda informações do item vendido; a Venda registra data/itens/total; a tela (Windows Forms) mostra e coleta dados do usuário. Neste capítulo vamos começar pelo Produto.

1.2 Classe

Uma classe é como um molde ou uma receita. Ela define quais informações (campos/propriedades) e quais comportamentos (métodos) um tipo de objeto vai ter. A classe por si só não é um objeto, ela é a definição.

Exemplo: a classe Produto define que todo produto terá Id, Nome, Preco e Estoque. Quando criarmos um produto específico (por exemplo, “X-Burger”), isso será um objeto criado a partir da classe.

1.3 Objeto e Instância

Um objeto é uma “coisa” criada a partir de uma classe, com valores reais nos seus dados. Quando dizemos que um objeto é uma instância de uma classe, significa exatamente isso: ele é um “exemplar” daquele molde.

Exemplo prático: Produto (classe) → “X-Burger” (objeto/instância), “Batata Frita” (objeto/instância), “Refri Cola” (objeto/instância).

1.4 Instanciação (criando objetos com new)

Instanciar é o ato de criar um objeto a partir de uma classe. Em C#, normalmente fazemos isso com a palavra-chave new. O new reserva espaço na memória e chama um construtor (vamos ver construtores com mais detalhes no Capítulo 03).

No nosso passo a passo, vamos instanciar objetos Produto quando o usuário clicar no botão “Adicionar”. Em seguida, vamos colocar esses objetos em uma List<Produto> e exibi-los em um DataGridView.

Conexão com a prática
Perceba como cada conceito aparece no projeto: classe (Produto), objetos (itens cadastrados), instanciação (new Produto(...)) e uso na tela (lista exibida).

2) Passo a passo (Windows Forms + C#)

Vamos criar um primeiro módulo do sistema: Cadastro e listagem de produtos (em memória). Você fará isso no Visual Studio 2022 com Windows Forms.

Passo 1 — Criar a solução e o projeto

  1. Abra o Visual Studio 2022.
  2. Clique em Criar um novo projeto.
  3. Procure por Windows Forms App (C#) e selecione.
  4. Nome do projeto: LanchoneteApp
  5. Nome da solução: LanchoneteApp
  6. Framework: .NET (use o padrão disponível no laboratório, ex.: .NET 6/7/8).
  7. Confirme em Criar.
Dica: crie a pasta do projeto em um local sem espaços e com caminho curto (ex.: C:\Projetos\LanchoneteApp).

Passo 2 — Organizar pastas (Models)

  1. No Solution Explorer, clique com o botão direito no projeto LanchoneteApp.
  2. Selecione Add → New Folder e crie a pasta Models.
  3. Essa pasta vai guardar classes do “mundo do problema” (Produto, Venda, etc.).

Passo 3 — Criar a classe Produto (classe → molde)

  1. Clique com o botão direito na pasta Models → Add → Class...
  2. Nome: Produto.cs
  3. Substitua o conteúdo pelo código abaixo.
Arquivo: Models/Produto.cs
namespace LanchoneteApp.Models
{
    // Classe = molde (definição) de um produto
    public class Produto
    {
        // Propriedades (dados do objeto)
        public int Id { get; set; }
        public string Nome { get; set; }
        public decimal Preco { get; set; }
        public int Estoque { get; set; }

        // Construtor simples (vamos aprofundar no Cap. 03)
        public Produto(int id, string nome, decimal preco, int estoque)
        {
            Id = id;
            Nome = nome;
            Preco = preco;
            Estoque = estoque;
        }
    }
}
Onde este conceito aparece?
Aqui você definiu uma classe (Produto). Ainda não existe nenhum produto de verdade. Eles vão surgir quando você instanciar a classe com new Produto(...).

Passo 4 — Criar a tela de Produtos (Windows Forms)

  1. No projeto, clique com o botão direito → Add → Windows Form...
  2. Nome: FrmProdutos.cs
  3. Abra o designer e ajuste as propriedades do formulário:
  • Text: Produtos - Lanchonete
  • StartPosition: CenterScreen
  • FormBorderStyle: FixedDialog (opcional)

Agora adicione os controles (arraste da Toolbox):

  • 4 Labels: ID, Nome, Preço, Estoque
  • 4 TextBox: txtId, txtNome, txtPreco, txtEstoque
  • 1 Button: btnAdicionar (Text: Adicionar)
  • 1 DataGridView: dgvProdutos
Dica: deixe o DataGridView ocupando a parte inferior do formulário (Dock: Bottom), para visualizar a lista.

Passo 5 — Criar a lista em memória e instanciar objetos

Aqui vamos criar uma List<Produto> para guardar os produtos cadastrados. Quando clicarmos em Adicionar, vamos instanciar um Produto e colocar na lista.

  1. No arquivo FrmProdutos.cs, dê dois cliques no botão btnAdicionar para criar o evento Click.
  2. No topo do arquivo, adicione using LanchoneteApp.Models; e using System.Globalization;.
  3. Substitua/complete o código conforme abaixo.
Arquivo: FrmProdutos.cs (código principal do capítulo)
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Windows.Forms;
using LanchoneteApp.Models;

namespace LanchoneteApp
{
    public partial class FrmProdutos : Form
    {
        // Lista em memória (por enquanto). No 4º bimestre iremos persistir no MySQL.
        private readonly List<Produto> _produtos = new();

        public FrmProdutos()
        {
            InitializeComponent();

            // Ajuste visual simples do grid
            dgvProdutos.AutoGenerateColumns = true;
            dgvProdutos.ReadOnly = true;
            dgvProdutos.AllowUserToAddRows = false;

            // Carrega alguns produtos iniciais para testar (instanciação)
            _produtos.Add(new Produto(1, "X-Burger", 18.50m, 5));
            _produtos.Add(new Produto(2, "Batata Frita", 12.00m, 10));
            _produtos.Add(new Produto(3, "Refrigerante Cola", 7.00m, 12));

            AtualizarGrid();
        }

        private void btnAdicionar_Click(object sender, EventArgs e)
        {
            // 1) Ler dados da tela
            if (!int.TryParse(txtId.Text, out int id))
            {
                MessageBox.Show("ID inválido.");
                return;
            }

            string nome = txtNome.Text.Trim();
            if (string.IsNullOrWhiteSpace(nome))
            {
                MessageBox.Show("Informe o nome do produto.");
                return;
            }

            // Aceita vírgula ou ponto (pt-BR) ao converter
            var cultura = new CultureInfo("pt-BR");
            if (!decimal.TryParse(txtPreco.Text, System.Globalization.NumberStyles.Any, cultura, out decimal preco))
            {
                MessageBox.Show("Preço inválido. Ex.: 9,50");
                return;
            }

            if (!int.TryParse(txtEstoque.Text, out int estoque))
            {
                MessageBox.Show("Estoque inválido.");
                return;
            }

            // 2) Instanciar (criar objeto) a partir da classe Produto
            Produto novo = new Produto(id, nome, preco, estoque);

            // 3) Guardar na lista (em memória)
            _produtos.Add(novo);

            // 4) Atualizar a visualização
            AtualizarGrid();

            // 5) Limpar campos
            txtId.Clear();
            txtNome.Clear();
            txtPreco.Clear();
            txtEstoque.Clear();
            txtId.Focus();
        }

        private void AtualizarGrid()
        {
            // Rebind simples para atualizar a lista no grid
            dgvProdutos.DataSource = null;
            dgvProdutos.DataSource = _produtos;
        }
    }
}
Repare onde a POO acontece
A linha new Produto(id, nome, preco, estoque) é a instanciação. Cada clique cria um objeto diferente (uma instância) guardado na lista _produtos.

Passo 6 — Abrir o formulário FrmProdutos como tela inicial

  1. Abra o arquivo Program.cs.
  2. Substitua o formulário inicial para FrmProdutos.
Arquivo: Program.cs (trecho importante)
ApplicationConfiguration.Initialize();
Application.Run(new FrmProdutos());

Agora execute (F5) e teste cadastrando produtos.

Resultado esperado
Ao abrir a tela, você verá 3 produtos iniciais no grid. Ao preencher os campos e clicar em Adicionar, um novo produto (objeto) será criado e aparecerá na lista.
