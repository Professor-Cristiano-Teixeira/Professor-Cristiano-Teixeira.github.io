Programação Web II — 2º ano (Téc. Desenvolvimento de Sistemas)

Apostila Interativa • React + Next.js + Bootstrap

Esta apostila foi organizada em 4 bimestres (4 capítulos por bimestre), com aulas semanais de 100 minutos. Cada capítulo prevê uma aula conceitual + início do passo a passo e uma aula para concluir + praticar.

Ver Sumário Começar pelo Cap. 01

Competências em foco

  • Elaborar interfaces web (componentes, rotas, estado, CSS framework).
  • Aplicar práticas de desenvolvimento (testes, versionamento, build/release, contêineres).
  • Projeto-modelo contínuo: Sistema Web de Lanchonete (Admin).

Ferramentas e escolhas didáticas

Ir para o Sumário

Stack principal (fixa para toda a apostila)

  • React com Next.js (CSR/SSG/SSR + hidratação no mesmo framework)
  • Bootstrap 5 + Bootstrap Icons
  • Jest + React Testing Library
  • Git (GitHub opcional)
  • Docker (docker-compose opcional)
  • VS Code, Node.js (npm), Postman

Observação pedagógica

Usaremos Next.js como base única para SPA e renderização híbrida, evitando troca de ferramentas durante o curso. O Bootstrap será o padrão de layout e componentes. Testes e Git serão usados continuamente. Docker entra com foco no 4º bimestre.

Contexto do projeto-modelo: lanchonete com papel único (Administrador) para simplificar os casos de uso.

Como usar esta apostila

Aula 1 (100 min)

Conceitos + demonstração do professor + início do passo a passo guiado.

Aula 2 (100 min)

Continuação do passo a passo + prática individual + entrega curta (checkpoint).

Revisão e avaliação

Cada capítulo terá checklist interativo + questionário objetivo com feedback.

Sumário por bimestre

Cap. 01 Ambiente, Git, Next.js e Bootstrap (Setup do projeto)
Criar projeto, integrar Bootstrap, padronizar Git. Layout base (Navbar, Footer, Grid).
Abrir
Cap. 02 Componentes, Props, Estado e Eventos
JSX, composição, useState, comunicação pai-filho. Cards de bebidas e botão “Adicionar”.
Abrir
Cap. 03 Renderização de Listas/Condicional + Layout/Grade no Bootstrap
map/keys, condicionais, Grid/Cards/Badges. Catálogo com filtro por categoria.
Abrir
Cap. 04 Rotas e Navegação (SPA com Next.js)
App Router (/app), Link, layouts aninhados. Páginas Home/Cardápio/Favoritos.
Abrir
Mini-projeto (Entrega do 1º Bimestre)
Catálogo navegável com layout responsivo, filtros por categoria e favoritos (estado local). Repositório + README + screenshots.
Ver no Cap. 04

Cap. 05 Bootstrap avançado e Customização
Utilitários, Modal/Toast, temas. Modal para detalhes do item e cores da marca.
Abrir
Cap. 06 Formulários e Validação (sem libs extras)
Campos controlados, validação HTML5 + lógica simples, feedback Bootstrap. Cadastro de bebidas.
Abrir
Cap. 07 Consumo de API (fetch) e Estados Assíncronos
useEffect, loading/erro, Postman. API Routes (mock) + front consumindo.
Abrir
Cap. 08 Testes Unitários e de Interface (Jest + RTL)
Render, interação, mocks (fetch), boas práticas. Testes do Card, Form e filtro.
Abrir
Mini-projeto (Entrega do 2º Bimestre)
CRUD simples do cardápio consumindo API Routes, com testes de pelo menos 3 componentes críticos.
Ver no Cap. 08

Cap. 09 Conceitos de SSG, SSR e Hidratação (Next.js)
Diferenças, trade-offs, custos e UX. Home em SSG e pipeline de build.
Abrir
Cap. 10 Rotas Dinâmicas com SSG (Cardápio estático)
Páginas por item/categoria no build, params dinâmicos. Detalhe do produto SSG.
Abrir
Cap. 11 SSR para Dados Variáveis (Pedidos/Estoque “ao vivo”)
SSR para conteúdo que muda frequentemente. Dashboard admin com atualização simulada.
Abrir
Cap. 12 Hidratação e Interatividade no Cliente
Server vs Client Components, "use client", cuidados com estado. Carrinho interativo.
Abrir
Mini-projeto (Entrega do 3º Bimestre)
Vitrine híbrida: Cardápio SSG (detalhes/categorias), Dashboard SSR e carrinho cliente com hidratação.
Ver no Cap. 12

Cap. 13 Testes de Interface e Fluxos (RTL avançado)
Cenários do usuário, testes assíncronos, mocks de rotas/API, acessibilidade.
Abrir
Cap. 14 Builds e Releases (Next.js)
next build/start, .env, otimizações (imagem/fontes), checklist de performance.
Abrir
Cap. 15 Conteinerização com Docker
Imagem/contêiner, Dockerfile para Next.js, .dockerignore e variáveis de ambiente.
Abrir
Cap. 16 Projeto Final Integrador + Apresentação
Consolidação: SSG/SSR/CSR, CRUD, testes, build, Docker, Git e documentação.
Abrir
Entrega final (Projeto Integrador)
“Lanchonete Admin SPA+Híbrida” com vitrine SSG, dashboard SSR, carrinho cliente, CRUD validado, testes, build + Docker, Git e README.
