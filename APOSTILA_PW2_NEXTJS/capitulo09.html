🧠 Parte Teórica (explicação do conteúdo)

1) CSR, SSG, SSR: o que muda

  • CSR (Client-Side Rendering): o servidor envia um HTML “vazio” + JS; o navegador renderiza tudo via React. Ótimo para páginas altamente interativas e dados do usuário, mas TTFB e SEO podem sofrer.
  • SSG (Static Site Generation): o HTML é gerado no build e servido como estático. Ideal para conteúdo estável (home institucional, páginas “sobre”, catálogo que muda pouco). Barato e rápido.
  • SSR (Server-Side Rendering): o HTML é gerado a cada requisição no servidor (ou edge). Bom para dados que mudam com frequência (ex.: pedidos do dia). Custa mais CPU/latência.

2) Hidratação

  • O HTML (SSG/SSR) chega pronto, mas ainda “morto”; o React baixa o JS e hidrata os componentes para ativar a interação (cliques, estado, etc.).
  • Server Components (sem use client) não precisam hidratação; Client Components (com 'use client') precisam.

3) Cache e revalidate (ISR)

  • Em App Router, páginas server podem ser estáticas por padrão quando não usam dados dinâmicos não cacheáveis.
  • ISR (Incremental Static Regeneration) com export const revalidate = <segundos> faz o Next regenerar a página de tempos em tempos, mantendo o HTML estático entre regenerações.
  • Forçar SSG: export const dynamic = 'force-static'.
  • Forçar SSR: export const dynamic = 'force-dynamic' ou fetch(..., { cache: 'no-store' }).

4) Como escolher?

  • SSG: conteúdo institucional, catálogo “curado”, páginas que mudam raro ou previsivelmente.
  • SSR: dashboards de dados ao vivo, relatórios “do dia”, páginas personalizadas por sessão.
  • CSR: experiências fortemente interativas no cliente (ex.: carrinho, UI de filtros, drag/drop).

🛠️ Passo a Passo — Transformar a Home em SSG com ISR (revalidate)

Objetivo: Tornar a Home uma página estática com destaques do cardápio gerados no build (e revalidados periodicamente).

0) Preparação

  • Projeto até o Cap. 8 rodando.
  • Home atual (app/page.jsx) é server component por padrão (sem 'use client').
  • Vamos extrair “destaques” do dataset local data/itens.js.

1) Criar uma fonte de “destaques” (server-safe)

Em server components, importar arquivos locais é SSG-friendly (não depende de rede).

Crie/edite data/destaques.js (opcional) — ou use diretamente data/itens.js.

// data/destaques.js
import { itens } from './itens';

export function getDestaques(limit = 3) {
  const ds = itens.filter((it) => it.destaque && it.disponivel);
  // Ordena por categoria/nome para estabilidade
  ds.sort((a, b) => a.categoria.localeCompare(b.categoria) || a.nome.localeCompare(b.nome, 'pt-BR'));
  return ds.slice(0, limit);
}

2) Converter a Home para SSG com ISR

Edite app/page.jsx:

// app/page.jsx (server component por padrão; sem 'use client')
import Link from 'next/link';
import { getDestaques } from '@/data/destaques';

export const metadata = {
  title: 'Lanchonete — Home',
  description: 'Vitrine estática com destaques do cardápio',
};

// ---- Opções de renderização (descomente conforme o caso) ----
// Força o modo estático, mesmo se surgirem fetches cacheáveis:
// export const dynamic = 'force-static';

// Intervalo de revalidação (ISR): reconstroi HTML a cada N segundos
export const revalidate = 60 * 60; // 1 hora

export default function Home() {
  // Como é server, isso roda no build, gerando HTML estático (SSG + ISR)
  const destaques = getDestaques(3);

  return (
    <>
      <section className="py-5 text-center bg-light rounded-3 border">
        <div className="container">
          <h1 className="display-6 fw-bold d-flex justify-content-center align-items-center gap-2">
            <i className="bi bi-emoji-smile"></i>
            Bem-vindo(a) à Lanchonete
          </h1>
          <p className="lead text-secondary">
            Vitrine estática com destaques; cardápio completo e pedidos em outras páginas.
          </p>
          <div className="d-flex justify-content-center gap-2">
            /cardapio
              <i className="bi bi-basket me-1"></i> Ver Cardápio
            </Link>
            /admin
              <i className="bi bi-speedometer2 me-1"></i> Administração
            </Link>
          </div>
        </div>
      </section>

      <section className="my-5">
        <div className="d-flex justify-content-between align-items-center mb-3">
          <h2 className="h4 mb-0">Destaques</h2>
          /cardapio
            Ver tudo
          </Link>
        </div>

        <div className="row g-4">
          {destaques.map((item) => (
            <div className="col-12 col-sm-6 col-lg-4" key={item.id}>
              <div className="card h-100 shadow-sm">
                <div className="card-body d-flex flex-column">
                  <div className="d-flex justify-content-between">
                    <h5 className="card-title mb-2 d-flex align-items-center gap-2">
                      <i className={`bi ${item.icone}`}></i> {item.nome}
                    </h5>
                    <span className="badge text-bg-warning text-dark">destaque</span>
                  </div>
                  {item.volume && <p className="text-muted mb-1">{item.volume}</p>}
                  {item.descricao && <p className="text-muted mb-1">{item.descricao}</p>}
                  <p className="fw-semibold mb-3">R$ {item.preco.toFixed(2)}</p>
                  <div className="mt-auto">
                    <Link href={`/cardapio/${item.id}`} className="btn btn-outline-secondary btn-sm me-2">
                      <i className="bi bi-info-circle me-1"></i> Detalhes
                    </Link>
                    /cardapio
                      <i className="bi bi-cart-plus me-1"></i> Adicionar
                    </Link>
                  </div>
                </div>
              </div>
            </div>
          ))}

          {destaques.length === 0 && (
            <div className="col-12">
              <div className="alert alert-secondary">Sem destaques no momento.</div>
            </div>
          )}
        </div>
      </section>
    </>
  );
}

Por que isso é SSG?

  • Home é server component sem use client.
  • Importa dados locais (getDestaques) — não depende de rede.
  • Com revalidate = 3600, temos ISR: HTML estático regenerado a cada 1h.

3) (Opcional) Forçar SSG/SSR para estudo

  • Forçar SSG: export const dynamic = 'force-static';
  • Forçar SSR: export const dynamic = 'force-dynamic'; ou fetch(url, { cache: 'no-store' }).

Use apenas para fins didáticos; no projeto real, escolha a estratégia adequada por página.

4) Build e Inspeção do HTML estático

No terminal:

npm run build
npm run start

Verifique:

  • Pasta .next/server/app: procure subpastas como page.js e arquivos HTML renderizados (conforme versão/estrutura), indicando conteúdo pré-renderizado.
  • No navegador: abra http://localhost:3000/ → DevTools → Network (Disable cache) e recarregue.
  • Observe o TTFB e o conteúdo do HTML (guia Response), que já vem com os cards de destaques.
  • Compare com uma página dinâmica (ex.: um dashboard SSR no Cap. 11) para notar diferença de TTFB.

Commits sugeridos

  • feat(home): tornar Home SSG com destaques e ISR (revalidate=3600)
  • docs: instruções de build e inspeção do HTML estático
