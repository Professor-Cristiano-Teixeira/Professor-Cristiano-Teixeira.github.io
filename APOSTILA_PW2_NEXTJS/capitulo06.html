Capítulo 6 — Formulários e Validação (sem libs extras)

Carga: 2 aulas × 140 min

Projeto-base: Sistema da Lanchonete (Admin) (Cap. 1–5)

Stack fixa: Next.js (App Router) + React, Bootstrap 5 + Bootstrap Icons, Git

Resultados de aprendizagem deste capítulo:

  • Construir formulários controlados em React (useState), com HTML5 validation e feedback visual Bootstrap.
  • Usar input groups, select, switch e mensagens de erro (invalid-feedback).
  • Aplicar regras de negócio simples (ex.: campos condicionais por categoria).
  • Persistir temporariamente o cadastro no localStorage (sem backend) e mostrar Toast de sucesso.

🎯 Competências e Habilidades trabalhadas

  • Competências: (1) Elaborar interfaces web; (2) Aplicar práticas de desenvolvimento de sistemas.
  • Habilidades: 1.1 (SPAs com framework frontend), 1.2 (Framework CSS), 4 (práticas de desenvolvimento: organização, versionamento).

📆 Plano de Aula (Capítulo 6)

Aula 1 (140 min) — Teoria + Formulários Controlados + UI/UX de Form

Teoria (35–45 min): Inputs controlados, onChange, validação nativa HTML5, invalid-feedback, switches, selects, input groups; boas práticas de acessibilidade.

Prática (85–95 min): Criar a página /admin/itens/novo (cadastro de Bebidas por padrão) com validações e feedback do Bootstrap.

Aula 2 (140 min) — Regras de Negócio + Persistência Local + Toast

Teoria (20–30 min): Regras condicionais (campos por categoria), localStorage (persistência local), UX de sucesso/erro (Toast).

Prática (100–110 min): Salvar no localStorage, limpar formulário, exibir Toast de sucesso; opcional: listar itens em /admin/itens mesclando dataset base + extras.

Entrega rápida (10 min): Print do formulário com erros visíveis + print do Toast após cadastro.

  • • Vantagens: validações em tempo real, máscaras simples, envio confiável.

2) Validação nativa HTML5 + feedback Bootstrap

  • • Atributos de HTML5: required, min, max, step, pattern, type="number".
  • • Bootstrap usa classes:
    • o is-invalid / is-valid nos inputs;
    • o .invalid-feedback / .valid-feedback como mensagens.
  • • Você pode usar form.checkValidity() e aplicar was-validated no <form> ao tentar enviar.

3) Campos condicionais por categoria

  • • Mostrar Volume só quando a categoria for Bebida; Descrição quando for Lanche/Sobremesa.
  • • Isso melhora a experiência e evita ruído no cadastro.

4) Acessibilidade em formulários

  • • label associado a id do input.
  • • Descrições adicionais com aria-describedby.
  • • Indicar erro com aria-invalid="true" quando necessário.

5) Persistência local

  • • Não há backend ainda: guardaremos novos itens em localStorage (chave adminItensExtra).
  • • No 2º bimestre faremos API Routes e consumo via fetch (Cap. 7).

1) Utilitário simples de persistência local

Crie lib/localdb.js (usado apenas em componentes cliente):

JSX

// lib/localdb.js
export const EXTRA_KEY = 'adminItensExtra';

export function readExtras() {
try {
const raw = localStorage.getItem(EXTRA_KEY);
return raw ? JSON.parse(raw) : [];
} catch {
return [];
}
}

export function addExtra(item) {
const all = readExtras();
all.push(item);
try {
localStorage.setItem(EXTRA_KEY, JSON.stringify(all));
return true;
} catch {
return false;
}
}

2) Página /admin/itens/novo (formulário controlado)

Crie app/admin/itens/novo/page.jsx:

JSX

// app/admin/itens/novo/page.jsx
'use client';

import { useMemo, useState } from 'react';
import { addExtra } from '@/lib/localdb';
import ToastContainer from '@/components/ToastContainer';

const CATEGORIAS = [
{ value: 'bebida', label: 'Bebida', icon: 'bi-cup-straw' },
{ value: 'lanche', label: 'Lanche', icon: 'bi-egg-fried' },
{ value: 'sobremesa', label: 'Sobremesa', icon: 'bi-ice-cream' },
];

function slugify(texto) {
return texto
.toLowerCase()
.normalize('NFD').replace(/[\u0300-\u036f]/g, '')
.replace(/[^a-z0-9]+/g, '-')
.replace(/(^-|-$)/g, '');
}

export default function NovoItemPage() {
// estado do formulário
const [categoria, setCategoria] = useState('bebida');
const [nome, setNome] = useState('');
const [preco, setPreco] = useState(''); // string p/ controlar input
const [disponivel, setDisponivel] = useState(true);
const [destaque, setDestaque] = useState(false);
const [volume, setVolume] = useState(''); // só p/ bebida
const [descricao, setDescricao] = useState(''); // p/ demais

// controle de UI
const [touched, setTouched] = useState({});
const [toast, setToast] = useState({ show: false, message: '' });

const icone = useMemo(() => {
const cat = CATEGORIAS.find((c) => c.value === categoria);
return cat?.icon ?? 'bi-list';
}, [categoria]);

const isBebida = categoria === 'bebida';

// validações simples
const erros = {
nome: nome.trim().length < 3 ? 'Informe ao menos 3 caracteres.' : '',
preco:
preco === '' ? 'Informe um preço.' :
Number.isNaN(Number(preco)) ? 'Preço inválido.' :
Number(preco) < 0 ? 'Preço não pode ser negativo.' : '',
volume: isBebida && volume.trim() === '' ? 'Informe o volume (ex.: 350 ml).' : '',
descricao: !isBebida && descricao.trim().length < 5 ? 'Descreva o item (mín. 5 caracteres).' : '',
};

const invalido = Boolean(erros.nome || erros.preco || erros.volume || erros.descricao);

function handleBlur(field) {
setTouched((t) => ({ ...t, [field]: true }));
}

function limparFormulario() {
setNome('');
setPreco('');
setDisponivel(true);
setDestaque(false);
setVolume('');
setDescricao('');
setTouched({});
}

function handleSubmit(e) {
e.preventDefault();

// marca todos como tocados para exibir feedback
setTouched({ nome: true, preco: true, volume: true, descricao: true });

if (invalido) return;

const idBase = slugify(nome);
const id = `${idBase}-${Math.random().toString(36).slice(2, 6)}`;

const item = {
id,
nome: nome.trim(),
preco: Number(Number(preco).toFixed(2)),
categoria,
volume: isBebida ? volume.trim() : undefined,
descricao: !isBebida ? descricao.trim() : undefined,
disponivel,
destaque,
icone,
};

const ok = addExtra(item);
if (ok) {
setToast({ show: true, message: `${item.nome} cadastrado com sucesso!` });
limparFormulario();
} else {
setToast({ show: true, message: 'Falha ao salvar. Verifique o armazenamento local.' });
}
}

// normaliza preço ao sair do campo
function normalizePreco() {
if (preco === '') return;
const num = Number(preco);
if (!Number.isNaN(num)) setPreco(num.toFixed(2));
}

return (
<>
<header className="mb-3">
<h1 className="h4 d-flex align-items-center gap-2">
<i className="bi bi-plus-circle"></i> Novo Item do Cardápio
</h1>
<p className="text-muted">Preencha os campos e salve para adicionar ao cardápio (local).</p>
</header>

<form noValidate onSubmit={handleSubmit} className="needs-validation">
<div className="row g-3">
{/* Categoria */}
<div className="col-12 col-md-4">
<label htmlFor="categoria" className="form-label">Categoria</label>
<select
id="categoria"
className="form-select"
value={categoria}
onChange={(e) => setCategoria(e.target.value)}
>
{CATEGORIAS.map((c) => (
<option key={c.value} value={c.value}>{c.label}</option>
))}
</select>
</div>

{/* Nome */}
<div className="col-12 col-md-8">
<label htmlFor="nome" className="form-label">Nome *</label>
<input
id="nome"
type="text"
className={`form-control ${touched.nome && erros.nome ? 'is-invalid' : ''}`}
placeholder="Ex.: Refrigerante Cola"
value={nome}
onChange={(e) => setNome(e.target.value)}
onBlur={() => handleBlur('nome')}
required
minLength={3}
aria-invalid={touched.nome && !!erros.nome}
aria-describedby="nomeHelp nomeError"
/>
<div id="nomeHelp" className="form-text">Mínimo 3 caracteres.</div>
{touched.nome && erros.nome && (
<div id="nomeError" className="invalid-feedback">{erros.nome}</div>
)}
</div>

{/* Preço */}
<div className="col-12 col-md-4">
<label htmlFor="preco" className="form-label">Preço *</label>
<div className="input-group">
<span className="input-group-text">R{{responseHTML}}lt;/span>
<input
id="preco"
type="number"
step="0.01"
min="0"
className={`form-control ${touched.preco && erros.preco ? 'is-invalid' : ''}`}
placeholder="0,00"
value={preco}
onChange={(e) => setPreco(e.target.value)}
onBlur={() => {
handleBlur('preco');
normalizePreco();
}}
required
aria-invalid={touched.preco && !!erros.preco}
aria-describedby="precoError"
/>
{touched.preco && erros.preco && (
<div id="precoError" className="invalid-feedback d-block">{erros.preco}</div>
)}
</div>
</div>

{/* Disponível & Destaque (switches) */}
<div className="col-6 col-md-4 d-flex align-items-end">
<div className="form-check form-switch">
<input
className="form-check-input"
type="checkbox"
id="disponivel"
checked={disponivel}
onChange={(e) => setDisponivel(e.target.checked)}
/>
<label className="form-check-label" htmlFor="disponivel">Disponível</label>
</div>
</div>

<div className="col-6 col-md-4 d-flex align-items-end">
<div className="form-check form-switch">
<input
className="form-check-input"
type="checkbox"
id="destaque"
checked={destaque}
onChange={(e) => setDestaque(e.target.checked)}
/>
<label className="form-check-label" htmlFor="destaque">Destaque</label>
</div>
</div>

{/* Campo condicional */}
{isBebida ? (
<div className="col-12 col-md-6">
<label htmlFor="volume" className="form-label">Volume *</label>
<input
id="volume"
type="text"
className={`form-control ${touched.volume && erros.volume ? 'is-invalid' : ''}`}
placeholder="Ex.: 350 ml"
value={volume}
onChange={(e) => setVolume(e.target.value)}
onBlur={() => handleBlur('volume')}
required={isBebida}
aria-invalid={touched.volume && !!erros.volume}
aria-describedby="volumeError"
/>
{touched.volume && erros.volume && (
<div id="volumeError" className="invalid-feedback">{erros.volume}</div>
)}
</div>
) : (
<div className="col-12">
<label htmlFor="descricao" className="form-label">Descrição *</label>
<textarea
id="descricao"
rows={3}
className={`form-control ${touched.descricao && erros.descricao ? 'is-invalid' : ''}`}
placeholder="Ex.: Pão, hambúrguer, queijo e molho da casa."
value={descricao}
onChange={(e) => setDescricao(e.target.value)}
onBlur={() => handleBlur('descricao')}
required={!isBebida}
aria-invalid={touched.descricao && !!erros.descricao}
aria-describedby="descricaoError"
/>
{touched.descricao && erros.descricao && (
<div id="descricaoError" className="invalid-feedback">{erros.descricao}</div>
)}
</div>
)}

{/* Ações */}
<div className="col-12 d-flex gap-2 mt-2">
<button type="submit" className="btn btn-primary">
<i className="bi bi-save me-1"></i> Salvar
</button>
<button
type="button"
className="btn btn-outline-secondary"
onClick={limparFormulario}
>
Limpar
</button>
</div>
</div>
</form>

<ToastContainer
show={toast.show}
message={toast.message}
onHide={() => setToast({ show: false, message: '' })}
/>
</>
);
}

JSX

// app/admin/itens/page.jsx
'use client';

import { useEffect, useState } from 'react';
import { itens as base } from '@/data/itens';
import { readExtras } from '@/lib/localdb';
import ProductCard from '@/components/ProductCard';

export default function AdminItens() {
const [lista, setLista] = useState(base);

useEffect(() => {
const extras = readExtras();
setLista([...base, ...extras]);
}, []);

return (
<>
<h1 className="h4 mb-3">Admin — Itens do Cardápio</h1>
<p className="text-muted">Itens base + novos cadastrados localmente.</p>
<div className="row g-4">
{lista.map((item) => (
<div className="col-12 col-sm-6 col-lg-4" key={item.id}>
<ProductCard item={item} onAdd={() => {}} />
</div>
))}
</div>
</>
);
}

🧪 Atividades Práticas (para desenvolver por conta própria)

  1. Cadastro de Lanches e Sobremesas
    • Use a mesma página (/admin/itens/novo) mudando a categoria no topo e preenchendo Descrição (em vez de Volume).
    • Cadastre ao menos 2 lanches e 2 sobremesas.
  2. Máscara simples de preço (onChange)
    • Ao digitar, normalize o valor para apenas números e vírgula/ponto, e no onBlur formate com 2 casas decimais (toFixed(2)).
    • Bônus: formatação locale pt-BR (apenas UI; mantenha o número em formato padrão para salvar).
  3. Validação de nome único
    • No handleSubmit, verifique se já existe item com o mesmo nome na lista base + extras; se existir, bloqueie e exiba erro no campo.
  4. Edição e exclusão
    • Em /admin/itens, adicione botões para editar (carregar dados da edição em /admin/itens/editar/[id]) e excluir (remover do localStorage).
  5. Pré-visualização (preview) do Card
    • À direita do formulário, exiba um ProductCard com os valores digitados (em tempo real), ajudando o aluno a visualizar o resultado.
