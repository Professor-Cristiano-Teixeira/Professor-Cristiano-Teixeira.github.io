Programação Web III (PW3) • 2º Ano • Técnico em Desenvolvimento de Sistemas

Apostila PW3 — Laravel (NOVA)

Esta apostila organiza o aprendizado em 4 bimestres (16 capítulos), com aulas semanais de 100 minutos, combinando teoria essencial e prática guiada. O projeto integrador será um Sistema Web para uma Lanchonete.

Semana A: conceitos + iniciar passo a passo Semana B: concluir + atividades + revisão Git + VS Code + Linux MySQL + Migrations/Seeds Postman + APIs
Ver Sumário Ir para o Capítulo 01
Visão Geral Didática
  • Competências: MVC, frameworks, serviços Web, integração mobile.
  • Bases: CRUD, validação, auth, i18n, segurança, REST/JSON, SOAP/XML.
  • Entregas: 1 por bimestre + entrega final completa.
  • Ferramentas: Laravel, Composer, Node/Vite, Docker (opcional), Postman.

Os capítulos terão: teoria objetiva, passo a passo, atividades propostas, pesquisas e questionário interativo.

Competências e Habilidades (ao longo do curso)

Desenvolvimento de sistemas multicamadas com framework MVC, construção de serviços Web e integração com recursos de dispositivos (quando aplicável).

  • MVC: Models, Views (Blade) e Controllers.
  • ORM (Eloquent): mapeamento objeto-relacional e relacionamentos.
  • Roteamento: URLs, rotas web e API.
  • Templates: layout, partials, componentes Blade.
  • Scaffolding: Artisan, geração de estruturas, produtividade.
  • Validação e Formulários: Form Requests, UX e mensagens.
  • Auth / Autorização: Breeze, middleware, policies e gates.
  • Integrações: AJAX, consumo de API pública, Postman.
  • Serviços: REST/JSON, XML e SOAP/WSDL.
  • Segurança: CSRF/XSS, tokens, rate limit, upload seguro.
  • i18n: internacionalização e acessibilidade básica.
Projeto Integrador: Sistema de Lanchonete

O projeto evolui durante o ano: catálogo → pedidos → APIs → segurança/qualidade.

Catálogo
Categorias e produtos (CRUD, validação, imagens, busca/paginação).
Pedidos
Fluxo de pedido e itens (relacionamentos, status, total, regras).
Integrações e Serviços
AJAX, consumo de API pública (ex.: ViaCEP), REST/JSON, XML, SOAP.
Segurança e Qualidade
Sanctum, policies, rate limit, logs, i18n, performance e deploy.

Sumário (Planejamento em 4 Bimestres)

Começar

01
Visão Geral da Arquitetura Web e Setup do Projeto

HTTP, request/response, estado vs stateless, MVC, setup Laravel + MySQL, layout base com Blade.

02
Modelagem, Migrations, Seeders & Eloquent (CRUD Categoria)

Entidades, migrations/seeders, Eloquent básico, relacionamento (visão) e primeiro CRUD completo.

03
Blade, Formulários, Validação e Mensagens

CSRF, Form Requests, mensagens amigáveis, UX básica e preservação de dados (old()).

04
Listagens, Paginação, Busca e Segurança Básica

Paginação, filtros, busca, escaping no Blade, CSRF/XSS e noções de SQLi.

Entrega Bimestral (B1)
Catálogo da Lanchonete com CRUDs de Categoria/Produto, validação, imagem, paginação/busca e README.

05
Autenticação (Breeze), Sessão e Perfis

Login/registro, middleware auth, sessão e roles (Gerente/Atendente).

06
Relacionamentos Eloquent e Fluxo de Pedido

1:N e N:N, pedidos e itens, regras iniciais e persistência completa.

07
Requisições Assíncronas (AJAX) no Laravel/Blade

fetch/Axios, respostas JSON, atualização sem recarregar, códigos de status.

08
Consumindo APIs Públicas + Postman

Integração com API pública (ex.: ViaCEP), tratamento de erros e coleção no Postman.

Entrega Bimestral (B2)
Fluxo de pedidos com AJAX + integração com API pública + coleção Postman com exemplos.

09
Expondo uma REST API (stateless) para a Lanchonete

REST, rotas api.php, API Resources, versionamento e CORS.

10
Padrões de Transferência: JSON e XML

JSON vs XML, content negotiation (Accept), serialização e exportações.

11
SOAP/WSDL — Consumo e Exposição (com estado)

SOAP, WSDL, SoapClient/SoapServer, diferenças para REST e sessão.

12
Segurança de API e Observabilidade

Sanctum (tokens), rate limiting, padrão de erros e logs com contexto.

Entrega Bimestral (B3)
API v1 segura com tokens, rate limit, logs e documentação (coleção Postman atualizada).

13
Internacionalização (i18n) e Acessibilidade Básica

resources/lang, locale, pluralização, boas práticas e acessibilidade essencial.

14
Autorização Fina (Policies/Gates) e Segurança

Policies, gates, defesa em camadas, mass assignment e upload seguro.

15
Qualidade, Desempenho e Manutenção

N+1, eager loading, cache simples, organização em serviços e comandos Artisan.

16
Empacotamento, Deploy e Fechamento (opcional PWA)

.env, build Vite, scripts de migração/seed, Docker (opcional), backup e PWA leve.

Entrega Final do Curso
Sistema completo da Lanchonete com catálogo, pedidos, autorização, API v1 (JSON/XML) segura, i18n e documentação (README + Postman + manual do usuário).
