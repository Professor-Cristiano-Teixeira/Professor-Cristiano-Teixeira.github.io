Capítulo 09 — Estruturas Condicionais (Seleção) em Python

Carga: —

Projeto-base: Sistema simples de controle de acesso por faixa etária e categoria

Stack fixa: Python 3.x, Thonny IDE

  • Identificar situações que exigem tomada de decisão no algoritmo.
  • Aplicar if, elif e else para controlar o fluxo do programa.
  • Combinar operadores relacionais e lógicos em condições compostas.
  • Tratar casos-limite e entradas inválidas em decisões.
  • Escrever expressões condicionais (operador ternário) de forma legível.

  • Modelagem de regras de negócio com condições simples e compostas.
  • Validação de entrada e tratamento de casos-limite.
  • Leitura e depuração de fluxos condicionais no Thonny.

Parte Teórica (explicação do conteúdo)

1) Por que usar estruturas condicionais?

Programas reais precisam tomar decisões: seguir por um caminho quando uma condição é verdadeira e por outro quando é falsa. As estruturas condicionais permitem que seu algoritmo reaja aos dados de entrada, às validações e às regras de negócio.

Onde vou aplicar isso: no controle de acesso por faixa etária, para decidir se a pessoa pode entrar, se precisa de responsável ou se não pode; e também para aplicar preços/categorias.

2) Sintaxe do if, elif e else

Em Python, a seleção é definida por cabeçalhos terminados em “:” e blocos delimitados por indentação. O if testa a primeira condição; elif (opcional e repetível) testa condições adicionais; else (opcional) captura todos os outros casos.

idade = 16

if idade >= 18:
    print("Maior de idade")
elif idade >= 16:
    print("Pode entrar acompanhado")
else:
    print("Não pode entrar")

Onde vou aplicar isso: no passo a passo, para ramificar o comportamento do programa conforme idade e categoria de ingresso.

3) Operadores relacionais e lógicos em condições

Condições comparam valores (==, !=, <, <=, >, >=) e podem ser combinadas com operadores lógicos (and, or, not). “and” exige que todas as subcondições sejam verdadeiras; “or” exige ao menos uma; “not” inverte o resultado.

ingresso = "meia"
idade = 15

if (ingresso == "meia" and idade < 18) or (ingresso == "cortesia"):
    print("Desconto aplicado")
else:
    print("Sem desconto")

Onde vou aplicar isso: para combinar regras como “menor de idade com meia” ou “cortesia sempre válida”.

4) Truthiness: valores considerados verdadeiros/falsos

Em Python, além de True/False, alguns valores são “falsy”: 0, 0.0, "", [], {}, None. Qualquer outro valor tende a ser “truthy”. Isso influencia checagens como if nome:, que é verdadeiro quando a string não está vazia.

nome = input("Digite seu nome: ").strip()
if nome:
    print("Bem-vindo,", nome)
else:
    print("Nome não informado.")

Onde vou aplicar isso: para validar entradas vazias antes de prosseguir com a lógica de decisão.

5) Aninhamento de condicionais

É possível ter if dentro de if. Contudo, muito aninhamento reduz legibilidade. Prefira combinar condições ou usar retornos antecipados quando fizer sentido.

idade = 17
tem_responsavel = True

if idade < 18:
    if tem_responsavel:
        print("Entrada permitida com responsável")
    else:
        print("Entrada negada")
else:
    print("Entrada permitida")

Onde vou aplicar isso: ao tratar casos como “menor de idade” e, dentro dele, verificar se está acompanhado.

6) Expressão condicional (operador ternário)

Para atribuições simples e decisões curtas, Python oferece a expressão condicional: X if condição else Y. Use com moderação e legibilidade.

idade = 20
situacao = "adulto" if idade >= 18 else "menor"
print(situacao)

Onde vou aplicar isso: para criar rótulos como “adulto/menor” de forma compacta em saídas.

7) Casos-limite e ordem de avaliação

Cuide da ordem: condições mais específicas tendem a vir antes das mais gerais. Trate valores nas “bordas” (ex.: idade 0, 17, 18, 120) e entradas inválidas. Isso evita erros lógicos.

idade = 18
if idade < 0:
    print("Idade inválida")
elif idade < 18:
    print("Menor de idade")
else:
    print("Maior de idade")

Onde vou aplicar isso: validando a idade antes de decidir a política de acesso/preços.

Passo a Passo — Controle de Acesso por Faixa Etária e Categoria

Objetivo desta etapa:

Construir um programa interativo que, com base na idade do usuário e na categoria do ingresso, decide o tipo de acesso permitido e o valor a pagar, validando entradas e tratando casos-limite.


Passo 1 — Preparar o arquivo e ler entradas

Abra o Thonny e crie um novo arquivo chamado controle_acesso.py. Vamos ler idade (inteiro) e categoria do ingresso (string entre “inteira”, “meia”, “cortesia”).

# controle_acesso.py

print("=== Sistema de Controle de Acesso ===")
idade_str = input("Informe sua idade: ").strip()
categoria = input("Categoria do ingresso (inteira/meia/cortesia): ").strip().lower()

# Validação básica da idade (vazia ou não numérica)
if not idade_str.isdigit():
    print("Erro: idade deve ser um número inteiro não negativo.")
    exit()

idade = int(idade_str)

Passo 2 — Validar casos-limite da idade

Antes de qualquer regra de negócio, rejeite idades impossíveis ou improváveis. Em seguida, valide a categoria.

# Casos-limite
if idade < 0 or idade > 120:
    print("Erro: idade fora de faixa plausível (0 a 120).")
    exit()

# Validar categoria
categorias_validas = {"inteira", "meia", "cortesia"}
if categoria not in categorias_validas:
    print("Erro: categoria inválida. Use: inteira, meia ou cortesia.")
    exit()

Passo 3 — Definir regras de acesso (if/elif/else)

Exemplo de política:

  • Menores de 12: acesso negado.
  • De 12 a 17: acesso permitido apenas acompanhado de responsável.
  • 18 ou mais: acesso permitido.
acesso = ""
if idade < 12:
    acesso = "negado"
elif idade < 18:
    acesso = "acompanhado"
else:
    acesso = "liberado"

Passo 4 — Combinar condições com operadores lógicos

Vamos calcular o valor a pagar considerando uma base de R$ 40,00:

  • cortesia: R$ 0,00 sempre.
  • meia: R$ 20,00 se idade < 18, caso contrário R$ 40,00 (ex.: meia apenas para estudantes/menores, ajuste conforme a regra da instituição).
  • inteira: R$ 40,00.
valor_base = 40.0

if categoria == "cortesia":
    valor = 0.0
elif categoria == "meia" and idade < 18:
    valor = valor_base / 2
elif categoria == "meia" and idade >= 18:
    # regra alternativa: meia não aplicável para maiores (exemplo simples)
    valor = valor_base
else:
    valor = valor_base

Passo 5 — Expressão condicional (ternário) para rótulos

Podemos criar um rótulo de faixa etária de forma compacta e legível.

faixa = "adulto" if idade >= 18 else ("adolescente" if idade >= 12 else "criança")

Passo 6 — Exibir resultado final formatado

Imprima um resumo claro, com moeda formatada e explicando o tipo de acesso.

print("\n=== Resultado ===")
print(f"Idade: {idade} ({faixa})")
print(f"Categoria: {categoria}")

if acesso == "negado":
    print("Acesso: NEGADO (menores de 12 anos)")
elif acesso == "acompanhado":
    print("Acesso: PERMITIDO SOMENTE ACOMPANHADO")
else:
    print("Acesso: LIBERADO")

print(f"Valor a pagar: R$ {valor:,.2f}".replace(",", "X").replace(".", ",").replace("X", "."))

Passo 7 — Teste de mesa e casos-limite

Execute o programa testando pelo menos estes cenários:

  • idade = 11, categoria = “inteira” → acesso negado, valor R$ 40,00 (regra de preço ainda se aplicaria, mas sem acesso).
  • idade = 15, categoria = “meia” → acesso acompanhado, valor R$ 20,00.
  • idade = 18, categoria = “meia” → acesso liberado, valor R$ 40,00 (no exemplo acima, meia não aplicável para maiores).
  • idade = 30, categoria = “cortesia” → acesso liberado, valor R$ 0,00.
  • idade inválida (ex.: “abc” ou 130) → mensagem de erro e saída.
Entrada: idade=15, categoria=meia
Fluxo:
- idade_str.isdigit() == True → ok
- idade = 15 → 0..120 → ok
- categoria "meia" ∈ válidas → ok
- acesso: idade < 12? não; idade < 18? sim → "acompanhado"
- valor: categoria == "cortesia"? não; categoria == "meia" and idade < 18? sim → 20.00
Saída coerente.
Dica: se o bloco de regras crescer, considere extrair partes em funções no Capítulo 14. Por enquanto, foque na clareza das condições e nos testes.
