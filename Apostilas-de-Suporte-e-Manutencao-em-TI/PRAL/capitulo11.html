Parte Teórica (explicação do conteúdo)

1) Estrutura for em Python

O laço for percorre uma sequência de valores, executando um bloco de código para cada elemento. Em Python, é comum iterar diretamente sobre sequências (como listas e strings) ou sobre a sequência gerada pela função range(). Diferentemente de outras linguagens, não usamos índices inteiros necessariamente; podemos iterar diretamente sobre os próprios elementos.

O padrão geral é: for elemento in sequência:. A cada iteração, elemento recebe um item da sequência e o bloco indentado é executado.

Onde vou aplicar isso no passo a passo? Usaremos for para percorrer cada caractere de uma frase e contar quantas vogais aparecem.

2) Função range(início, fim, passo)

range() gera uma sequência de números que pode ser usada para contagem. A forma mais comum é range(fim), que vai de 0 até fim-1. Também é possível especificar início e passo: range(início, fim, passo). O fim não é incluído (intervalo semiaberto).

O passo pode ser negativo, permitindo contagens regressivas. Essa função não cria uma lista na memória, mas um iterável eficiente.

Onde vou aplicar isso no passo a passo? Vamos usar range para imprimir contagens, índices e criar tabelas simples (por exemplo, tabuada).

3) Iteração sobre strings

Strings são sequências de caracteres, então podem ser percorridas com for, caractere por caractere. Também é possível acessar um caractere específico por índice (str[i]) e percorrer por posição usando range(len(str)).

Ao iterar sobre strings, podemos combinar transformações como lower() e upper() para padronizar a análise (por exemplo, ignorar diferenças entre maiúsculas e minúsculas).

Onde vou aplicar isso no passo a passo? Iteraremos sobre cada caractere para contar vogais, espaços e produzir um relatório de frequências.

4) Slicing (fatiamento) de strings

Fatiar é extrair uma subsequência usando a notação s[início:fim:passo]. Quando início é omitido, assume 0; quando fim é omitido, vai até o final; quando passo é omitido, assume 1. Passos negativos invertem a direção, permitindo, por exemplo, reverter a string com s[::-1].

O slicing não altera a string original (strings são imutáveis), mas cria uma nova string com o trecho especificado.

Onde vou aplicar isso no passo a passo? Vamos extrair trechos de texto, inverter a frase e amostrar caracteres com saltos para explorar padrões.

5) for vs while: quando usar cada um

Use for quando você conhece a quantidade de repetições (percurso contado) ou quando quer iterar sobre uma sequência de forma direta. Use while quando a repetição depende de uma condição que é verificada a cada ciclo e não há número fixo de iterações previamente determinado.

Em Python, for tende a ser mais legível para percorrer sequências. while é mais flexível para loops dirigidos por condição (por exemplo, ler entradas até que o usuário digite “sair”).

Onde vou aplicar isso no passo a passo? O contador de vogais é naturalmente resolvido com for (percurso por caracteres). Em atividades extras, veremos como reimplementar com while para comparar legibilidade.

6) Boas práticas com laços

- Prefira nomes de variáveis claros (car, indice, contagem_vogais).

- Evite trabalho desnecessário dentro do loop; compute fora o que for fixo. Padronizar a frase com lower() antes de iterar economiza chamadas repetidas.

- Valide entradas e trate casos extremos: string vazia, apenas espaços, acentuação.

Onde vou aplicar isso no passo a passo? Padronizaremos a frase antes de contar e validaremos entradas vazias.

Passo a Passo — Contador de Vogais e Estatísticas de Texto

Objetivo desta etapa:

Construir, testar e explicar um programa em Python que percorre uma frase com for, conta vogais e exibe estatísticas (total, por vogal e percentuais), explorando range e slicing.


Passo 1 — Preparar o ambiente e criar o arquivo

Abra o Thonny IDE. Crie um novo arquivo e salve como contador_vogais.py em uma pasta de exercícios organizada (por exemplo, PRAL/cap11/).

# sugestão de organização de pastas (no sistema de arquivos)
PRAL/

    └── contador_vogais.py

Passo 2 — Ler a entrada do usuário com validação simples

Solicite uma frase. Se o usuário informar vazio ou apenas espaços, peça novamente. Padronize para minúsculas para facilitar a contagem.

frase = input("Digite uma frase: ").strip()
while frase == "":
    print("Entrada vazia. Tente novamente.")
    frase = input("Digite uma frase: ").strip()

frase_proc = frase.lower()  # padroniza para contagem
print(f"Frase recebida: {frase!r}")

Passo 3 — Contar vogais com for iterando sobre a string

Inicialize contadores e percorra caractere por caractere. Ao encontrar uma vogal, incremente o respectivo contador.

vogais = "aeiou"
cont_total = 0
cont_por_vogal = {"a": 0, "e": 0, "i": 0, "o": 0, "u": 0}

for car in frase_proc:
    if car in vogais:
        cont_total += 1
        cont_por_vogal[car] += 1

print(f"Total de vogais: {cont_total}")
for v in vogais:
    print(f"{v}: {cont_por_vogal[v]}")
Dica: strings são iteráveis; por isso, for car in frase_proc percorre direto cada caractere.

Passo 4 — Calcular percentuais e mostrar relatório formatado

Use o tamanho da frase (sem espaços, se desejar) como base. Aqui, vamos considerar todos os caracteres para o percentual de vogais.

tam = len(frase_proc)
perc = (cont_total / tam * 100) if tam > 0 else 0.0

print("-" * 30)
print(f"Tamanho da frase: {tam} caractere(s)")
print(f"Vogais: {cont_total} ({perc:.2f}%)")
print("-" * 30)

Passo 5 — Explorar range para percursos contados e índices

Gerar uma tabela simples e percorrer por índice pode ser útil. Exemplo: exibir os primeiros 10 números e suas potências; e iterar a frase por posição.

# Tabela simples: n e n**2 usando range(inicio, fim, passo)
print("n  n**2")
for n in range(1, 11):  # 1 a 10
    print(f"{n:2} {n**2:4}")

# Percorrer a frase por índice
for i in range(0, len(frase_proc), 2):  # de 2 em 2
    print(f"Índice {i} -> caractere {frase_proc[i]!r}")
Lembre: range(fim) vai até fim-1. Para passos negativos, use range(inicio, fim, -1).

Passo 6 — Slicing (fatiamento) na prática

Extraia trechos e inverta a frase com slicing. Isso não altera a string original; cria cópias fatiadas.

# Três exemplos de slicing
print("Três primeiros:", frase_proc[:3])
print("Do 3 ao 7:", frase_proc[3:8])
print("De 2 em 2:", frase_proc[::2])

# Inverter a string
invertida = frase_proc[::-1]
print("Invertida:", invertida)

Passo 7 — Comparar com while (opcional, didático)

Reimplemente a contagem de vogais com while para comparar legibilidade. Note como for é mais direto para percorrer sequências.

i = 0
cont_total_w = 0
cont_por_vogal_w = {"a": 0, "e": 0, "i": 0, "o": 0, "u": 0}

while i < len(frase_proc):
    car = frase_proc[i]
    if car in vogais:
        cont_total_w += 1
        cont_por_vogal_w[car] += 1
    i += 1

print("Total (while):", cont_total_w)

Passo 8 — Consolidação: programa completo com saída organizada

Una tudo em um script único, com validação, contagens, percentuais e relatórios. Teste com frases curtas, vazias e com acentos.

# contador_vogais.py
def main():
    frase = input("Digite uma frase: ").strip()
    while frase == "":
        print("Entrada vazia. Tente novamente.")
        frase = input("Digite uma frase: ").strip()

    base = frase.lower()
    vogais = "aeiou"
    cont_total = 0
    cont_por_vogal = {v: 0 for v in vogais}

    for car in base:
        if car in vogais:
            cont_total += 1
            cont_por_vogal[car] += 1

    tam = len(base)
    perc = (cont_total / tam * 100) if tam > 0 else 0.0

    print("\n=== Relatório ===")
    print(f"Frase: {frase!r}")
    print(f"Tamanho: {tam}")
    print(f"Total de vogais: {cont_total} ({perc:.2f}%)")
    print("Por vogal:")
    for v in vogais:
        print(f"  {v}: {cont_por_vogal[v]}")

    print("\nExploração de slicing:")
    print("  Invertida:", base[::-1])
    print("  Amostra de 2 em 2:", base[::2])

    print("\nÍndices pares (range):")
    for i in range(0, len(base), 2):
        print(f"  {i} -> {base[i]!r}")

if __name__ == "__main__":
    main()
Teste rápido: “Programar em Python é divertido!” — verifique totais, percentuais e cortes por slicing.
