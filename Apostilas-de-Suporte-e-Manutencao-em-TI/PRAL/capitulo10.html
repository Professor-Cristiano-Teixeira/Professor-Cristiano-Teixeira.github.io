Capítulo 10 — Repetição com while e Controle de Fluxo

Carga: 2–4 aulas (flexível conforme prática)

Projeto-base: Menu interativo em loop com três operações e opção de sair

Stack fixa: Python 3.x e Thonny IDE

Resultados de aprendizagem deste capítulo:

  • Utilizar break e continue para ajustar o fluxo dentro do loop.
  • Implementar contadores e acumuladores de forma correta e segura.
  • Identificar e evitar loops infinitos por meio de condições e atualizações adequadas.
  • Construir um menu interativo com repetição até escolha de saída.

Parte Teórica (explicação do conteúdo)

1) O que é um laço while

O while executa um bloco de instruções enquanto uma condição booleana permanecer verdadeira. É ideal quando não sabemos previamente quantas repetições serão necessárias, mas temos um critério de parada.

No Python, avaliamos a condição antes de cada iteração. Se for False, o laço termina. Se for True, o bloco é executado e a condição é reavaliada.

Onde vou aplicar: será o núcleo do “menu interativo”, que permanece em execução até o usuário escolher sair.

2) Condição de permanência e atualização de estado

Para um while terminar corretamente, a condição precisa, em algum momento, tornar-se False. Isso normalmente ocorre por meio de uma variável de controle atualizada a cada iteração (por exemplo, leitura de opção do usuário).

Erros comuns: esquecer de atualizar a variável de controle; usar condição que nunca muda; comparar tipos incompatíveis.

Onde vou aplicar: no menu, a cada ciclo leremos a opção; quando for “sair”, a condição se tornará False.

3) Contadores e Acumuladores

Contador é uma variável que incrementa ou decrementa de forma previsível (ex.: i = i + 1). Acumulador soma valores ao longo de iterações (ex.: total = total + valor).

Boas práticas: inicializar antes do loop; escolher nomes significativos; atualizar dentro do loop; usar tipos corretos (int/float).

Onde vou aplicar: contabilizar quantas operações o usuário executou e somar resultados quando fizer sentido.

4) break e continue

break interrompe o laço imediatamente, independentemente da condição. continue pula para a próxima iteração, sem executar o restante do bloco atual.

Use break com critério claro (ex.: opção “0” para sair) e continue para ignorar casos específicos (ex.: entrada inválida) mantendo o loop.

Onde vou aplicar: sair do menu com break e pular processamento quando a opção for inválida com continue.

5) Loop infinito: detecção e prevenção

Loop infinito ocorre quando a condição de permanência nunca se torna False. Sintomas: programa “trava” e não prossegue. Em IDE, é possível interromper a execução.

Prevenção: revisar a lógica; garantir atualização das variáveis de controle; testar com dados-limite; usar contadores de segurança em casos críticos.

Onde vou aplicar: ao construir o menu, validaremos a condição e as atualizações para impedir travamentos.

6) Teste de mesa com while

Antes de codificar, simule manualmente 2–3 iterações: liste variáveis e seus valores, a condição e o fluxo escolhido (normal, continue ou break). Isso aumenta a confiança na correção.

Onde vou aplicar: faremos teste de mesa do nosso menu para confirmar a lógica de repetição e contadores.

Passo a Passo — Menu interativo com while, break, continue, contadores e acumuladores

Objetivo desta etapa:

Construir, testar e depurar um programa de menu em loop que oferece três operações simples e uma opção de saída, aplicando while, break, continue, contadores e acumuladores.


Etapa 0 — Preparação do ambiente

  1. Abrir o Thonny IDE.
  2. Criar um novo arquivo e salvar como menu_while.py em uma pasta organizada do curso.

Estrutura base do arquivo

# menu_while.py
# Capítulo 10 — Repetição com while e controle de fluxo
# Objetivo: menu interativo em loop

def mostrar_menu():
    print("\n=== MENU ===")
    print("1) Somar dois números")
    print("2) Contar de 1 até N")
    print("3) Acumular total de compras")
    print("0) Sair")

def ler_opcao():
    try:
        return int(input("Escolha uma opção: "))
    except ValueError:
        return -1  # inválida

def main():
    print("Bem-vindo(a) ao Menu com while!")
    # contadores/estatísticas gerais
    total_operacoes = 0
    while True:
        mostrar_menu()
        opcao = ler_opcao()

        if opcao == 0:
            print("Encerrando... obrigado por usar!")
            break  # saída do loop

        if opcao not in (1, 2, 3):
            print("Opção inválida. Tente novamente.")
            continue  # volta ao topo do loop

        # se chegou aqui, é uma operação válida
        total_operacoes += 1

        if opcao == 1:
            # Somar dois números
            try:
                a = float(input("Digite o primeiro número: "))
                b = float(input("Digite o segundo número: "))
                print(f"Resultado: {a + b}")
            except ValueError:
                print("Entrada inválida para números.")
        elif opcao == 2:
            # Contar de 1 até N
            try:
                n = int(input("Contar até: "))
                i = 1
                while i <= n:
                    print(i, end=" ")
                    i += 1
                print()
            except ValueError:
                print("Entrada inválida para inteiro.")
        elif opcao == 3:
            # Acumular total de compras (encerra com valor 0)
            total = 0.0
            while True:
                try:
                    v = float(input("Valor do item (0 para encerrar): "))
                except ValueError:
                    print("Valor inválido. Tente novamente.")
                    continue
                if v == 0:
                    break
                if v < 0:
                    print("Ignorando valor negativo.")
                    continue
                total += v
                print(f"Parcial: R$ {total:.2f}")
            print(f"Total da compra: R$ {total:.2f}")

    print(f"Você executou {total_operacoes} operações válidas.")

if __name__ == "__main__":
    main()

Etapa 1 — Entendendo o while principal

O while True cria um loop infinito controlado por break. Isso simplifica o menu: exibimos, lemos opção e decidimos continuar ou sair com base na entrada.

Onde aplicar: no corpo do programa, até o usuário digitar 0.

while True:
    mostrar_menu()
    opcao = ler_opcao()
    if opcao == 0:
        break
    # ... demais caminhos

Etapa 2 — Opções inválidas com continue

Se a opção não estiver na lista, informamos e usamos continue para ir direto à próxima iteração, evitando processamentos indevidos.

if opcao not in (1, 2, 3):
    print("Opção inválida. Tente novamente.")
    continue

Etapa 3 — Operação 1: Somar dois números

Exemplo simples com leitura, conversão para float e soma. Tratamos ValueError para entradas não numéricas.

try:
    a = float(input("Digite o primeiro número: "))
    b = float(input("Digite o segundo número: "))
    print(f"Resultado: {a + b}")
except ValueError:
    print("Entrada inválida para números.")

Etapa 4 — Operação 2: Contar de 1 até N (contador)

Contador i começa em 1 e incrementa até N. Este é um while clássico controlado por condição e atualização de estado.

n = int(input("Contar até: "))
i = 1
while i <= n:
    print(i, end=" ")
    i += 1
print()

Etapa 5 — Operação 3: Acumulador com sentinela

Use 0 como valor sentinela para encerrar a entrada de itens. Valores negativos são ignorados com continue. O total é um acumulador.

total = 0.0
while True:
    v = float(input("Valor do item (0 para encerrar): "))
    if v == 0:
        break
    if v < 0:
        print("Ignorando valor negativo.")
        continue
    total += v
    print(f"Parcial: R$ {total:.2f}")
print(f"Total da compra: R$ {total:.2f}")

Etapa 6 — Teste de mesa (trecho do acumulador)

Simule entradas: 10, 5.5, -3, 0. Esperado: parcial 10.00; depois 15.50; ignora -3; encerra em 0; total 15.50.

Iter 1: v=10   → total=10.00
Iter 2: v=5.5  → total=15.50
Iter 3: v=-3   → continue (ignora)
Iter 4: v=0    → break (finaliza)

Etapa 7 — Depuração no Thonny

  1. Marque breakpoint na linha do while principal.
  2. Execute passo a passo e observe as variáveis opcao, total_operacoes e contadores.
  3. Teste entradas inválidas para acionar o continue e ver a repetição.

Etapa 8 — Boas práticas e finalização

  • Mensagens claras ao usuário.
  • Tratamento de exceções de conversão.
  • Variáveis com nomes significativos.
  • Comentários curtos explicando decisões (break/continue).
