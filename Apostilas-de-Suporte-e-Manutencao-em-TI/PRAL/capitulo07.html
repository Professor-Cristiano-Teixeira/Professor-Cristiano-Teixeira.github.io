Parte Teórica (explicação do conteúdo)

1) Operadores aritméticos e precedência

Os operadores aritméticos em Python são: + (adição), - (subtração), * (multiplicação), / (divisão real), // (divisão inteira), % (módulo ou resto) e ** (exponenciação). A precedência determina a ordem de avaliação: por padrão, ** é avaliado antes de *, /, // e %, que por sua vez vêm antes de + e -. Parênteses podem (e devem) ser usados para tornar a intenção clara e evitar erros de interpretação.

Alguns detalhes importantes: a divisão real (/) sempre produz float; a divisão inteira (//) descarta a parte fracionária, respeitando o sinal; o operador % retorna o resto da divisão e é útil para checar paridade (n % 2), ciclos, relógios etc. Exponenciação (**) pode crescer rapidamente, devendo-se tomar cuidado com números grandes.

Onde vou aplicar isso? No passo a passo, você usará todos esses operadores na “Mini calculadora”, controlando a precedência com parênteses ao combinar operações.

# exemplos rápidos
print(7 + 3 * 2)      # 13 (multiplicação antes da adição)
print((7 + 3) * 2)    # 20 (parênteses alteram a ordem)
print(10 / 4)         # 2.5 (divisão real)
print(10 // 4)        # 2   (divisão inteira)
print(10 % 4)         # 2   (resto da divisão)
print(2 ** 3)         # 8   (exponenciação)

2) Operadores relacionais (comparação)

Comparações retornam valores booleanos (True/False) e são usadas para tomar decisões: == (igual), != (diferente), < (menor), <= (menor ou igual), > (maior), >= (maior ou igual). Em Python, é possível encadear comparações, como 1 < x < 10, o que melhora a legibilidade.

Comparar tipos diferentes exige atenção: números e strings se comportam de forma distinta, e conversões explícitas podem ser necessárias. Evite comparar floats por igualdade direta quando houver operações com ponto flutuante; prefira tolerâncias.

Onde vou aplicar isso? No passo a passo, você implementará uma seção de “comparações” para verificar igualdade, maior/menor e faixas numéricas.

x = 7
print(x == 7)   # True
print(x != 3)   # True
print(x > 5)    # True
print(1 < x < 10)  # True (encadeamento)

3) Operadores lógicos: and, or, not

Operadores lógicos combinam expressões booleanas: and (verdadeiro se ambas são verdadeiras), or (verdadeiro se ao menos uma é verdadeira) e not (negação). Em Python, and e or têm avaliação de curto-circuito: se o resultado já é determinado na primeira parte, a segunda pode nem ser avaliada.

Use parênteses para deixar clara a associação entre condições, especialmente quando misturar relacionais e lógicos. Lembre-se: not tem alta precedência; depois vêm and e, por fim, or. Em expressões longas, priorize legibilidade.

Onde vou aplicar isso? Na mini calculadora, você criará verificações compostas, como “divisão válida” (denominador diferente de zero) e “número dentro de um intervalo OU com permissão especial”.

idade = 16
responsavel = True
autorizado = (idade >= 18) or (responsavel and idade >= 16)
print(autorizado)  # True

4) Precedência e associatividade em expressões mistas

Quando combinamos aritméticos, relacionais e lógicos, a ordem geral é: primeiro aritméticos, depois relacionais e, por fim, lógicos (respeitando as ordens internas de cada grupo). A associatividade define como operadores da mesma precedência agrupam: por exemplo, ** é associativo à direita (2 ** 3 ** 2 = 2 ** (3 ** 2)).

Apesar das regras, o uso de parênteses torna a leitura mais fácil e ajuda a evitar bugs. Sempre que a expressão ficar longa, divida em variáveis intermediárias com nomes explicativos.

Onde vou aplicar isso? No passo a passo, você refatorará expressões complexas usando variáveis auxiliares e parênteses para garantir clareza e correção.

a, b, c = 2, 3, 4
expr = (a + b) * c >= 10 and not (c % 2 != 0)
print(expr)  # True

5) Expressões com strings e conversões

Embora este capítulo foque em números e booleanos, é comum precisar converter entradas (strings vindas de input()) para int ou float. Evite somar strings com números sem conversão explícita. Para saídas, use f-strings para formatar resultados com clareza.

Ao dividir, prefira converter para float quando necessário para obter valores decimais. Ao formatar porcentagens, arredondamentos e casas decimais, use formatação apropriada.

Onde vou aplicar isso? No passo a passo, as entradas do usuário serão convertidas e os resultados exibidos com f-strings e formatação consistente.

texto = "5"
n = int(texto)         # conversão explícita
media = (n + 7) / 2
print(f"Média: {media:.2f}")

Ler entradas e converter tipos

Leia dois números do usuário. Converta para float para permitir valores decimais. Em seguida, leia um “divisor” para testar a divisão (incluindo tratamento de zero).

a = float(input("Digite o primeiro número (a): "))
b = float(input("Digite o segundo número (b): "))
divisor = float(input("Digite um divisor para testar divisão: "))

Operações aritméticas básicas

Calcule soma, subtração, multiplicação, divisão real, divisão inteira, resto e exponenciação. Observe a diferença entre / e // e o uso do %.

soma = a + b
subtr = a - b
mult = a * b
div_real = a / b  if b != 0 else None
div_int  = a // b if b != 0 else None
resto    = a % b  if b != 0 else None
potencia = a ** b

print("\n=== Operações Aritméticas ===")
print(f"Soma: {soma}")
print(f"Subtração: {subtr}")
print(f"Multiplicação: {mult}")
print("Divisão real: " + (f"{div_real}" if div_real is not None else "inválida (b=0)"))
print("Divisão inteira: " + (f"{div_int}" if div_int is not None else "inválida (b=0)"))
print("Resto: " + (f"{resto}" if resto is not None else "inválido (b=0)"))
print(f"Exponenciação (a**b): {potencia}")

Precedência e parênteses

Construa uma expressão que demonstre precedência. Depois, reescreva com parênteses para deixar a intenção explícita.

expr_padrao = a + b * 2 - 3 ** 2
expr_parent = (a + (b * 2)) - (3 ** 2)
print("\n=== Precedência ===")
print(f"Sem parênteses explícitos: {expr_padrao}")
print(f"Com parênteses:            {expr_parent}")

Comparações (relacionais)

Faça verificações de igualdade, diferença e relações de ordem. Encadeie comparações para checar faixas.

print("\n=== Comparações ===")
print(f"a == b ? {a == b}")
print(f"a != b ? {a != b}")
print(f"a > b  ? {a > b}")
print(f"1 <= a <= 10 ? {1 <= a <= 10}")

Lógica booleana: and, or, not

Combine condições para criar regras úteis. Exemplo: só dividir se o divisor for diferente de zero e o valor absoluto de a for menor que 1.000.

print("\n=== Lógica Booleana ===")
cond_divisao_valida = (divisor != 0)
cond_a_limitado = (abs(a) < 1000)
pode_dividir = cond_divisao_valida and cond_a_limitado
print(f"Divisão válida? {cond_divisao_valida}")
print(f"|a| < 1000 ? {cond_a_limitado}")
print(f"Pode dividir (ambas verdadeiras)? {pode_dividir}")
print(f"Nega a condição anterior (not): {not pode_dividir}")

# Exemplo com or (cenário alternativo)
bonus = float(input("\nSe houver bônus, digite um valor (ou 0): "))
meta_atingida = soma >= 100
tem_permissao_extra = bonus > 0
resultado = meta_atingida or tem_permissao_extra
print(f"Meta atingida OU possui permissão extra? {resultado}")

Formatar saída e documentar

Use f-strings para formatar decimais e deixe comentários esclarecendo expressões mais complexas.

print("\n=== Formatação ===")
media = (a + b) / 2
print(f"Média de a e b: {media:.2f}")  # duas casas decimais

# Dica: quebre expressões em passos nomeados
numerador = (a + b)
denominador = (divisor if divisor != 0 else 1)
fracao = numerador / denominador
print(f"Fração (a+b)/divisor: {fracao:.3f} (ajustada se divisor = 0)")
