Parte Teórica (explicação do conteúdo)

Tuplas: definição, imutabilidade e empacotamento

Tuplas são sequências ordenadas e imutáveis. Após criadas, seus elementos não podem ser alterados, inseridos ou removidos. Em Python, são delimitadas por parênteses e os itens são separados por vírgula.

Imutabilidade traz vantagens: segurança contra alterações acidentais, possibilidade de uso como chaves de dicionário (quando todos os elementos também são imutáveis) e melhor performance em alguns cenários.

Onde vou aplicar isso? No projeto do capítulo, usaremos tuplas para representar dados que não devem ser alterados, como um “snapshot” de um produto (código, nome), enquanto o preço pode ser mantido no dicionário, que é mutável.

# criação de tuplas
t1 = (10, 20, 30)
t2 = ('A', 'B', 'C')
t_mista = (1, 'produto', 9.99)

# empacotamento/ desempacotamento
dados = ('P001', 'Caneta Azul', 2.50)
codigo, nome, preco = dados  # desempacota em três variáveis

print(nome)  # Caneta Azul

# imutabilidade: a linha abaixo causaria erro se descomentada
# dados[0] = 'P002'  # TypeError: 'tuple' object does not support item assignment

Dicionários: pares chave-valor

Dicionários (dict) armazenam mapeamentos entre chaves e valores. A busca e atualização por chave são diretas e eficientes. Chaves devem ser únicas e, em geral, imutáveis (strings, números, tuplas imutáveis).

Use dicionários quando você precisa recuperar dados por uma chave significativa (ex.: código do produto, CPF, matrícula).

Onde vou aplicar isso? No catálogo, o código do produto será a chave, e o valor será outro dicionário com nome e preço.

# criação e acesso
produtos = {
    'P001': {'nome': 'Caneta Azul', 'preco': 2.50},
    'P002': {'nome': 'Caderno 200fl', 'preco': 18.90}
}

print(produtos['P001']['nome'])   # Caneta Azul
produtos['P001']['preco'] = 2.75  # atualização de valor

# inserção
produtos['P003'] = {'nome': 'Lápis HB', 'preco': 1.80}

# verificação de existência
if 'P004' in produtos:
    print('Existe P004')
else:
    print('P004 não cadastrado')

Percorrendo dicionários: keys, values e items

Em dicionários, você pode iterar sobre chaves, valores ou pares (chave, valor). O método items() é útil quando você precisa das duas coisas no laço.

Onde vou aplicar isso? Para listar todos os produtos do catálogo com seus dados formatados.

produtos = {
    'P001': {'nome': 'Caneta Azul', 'preco': 2.75},
    'P002': {'nome': 'Caderno 200fl', 'preco': 18.90},
    'P003': {'nome': 'Lápis HB', 'preco': 1.80}
}

# somente chaves
for cod in produtos.keys():
    print('Código:', cod)

# somente valores
for info in produtos.values():
    print('Produto:', info['nome'], ' - R$ ', info['preco'])

# chaves e valores
for cod, info in produtos.items():
    print(f'{cod} — {info["nome"]} — R$ {info["preco"]:.2f}')

Métodos úteis de dicionário e boas práticas

Alguns métodos e padrões aumentam a robustez do código: get() evita KeyError e permite valor padrão; update() mescla conteúdos; pop() remove itens com retorno; setdefault() inicializa chaves.

Boas práticas: nomear chaves de forma clara, validar entrada antes de atualizar, evitar aninhamentos muito profundos sem necessidade.

Onde vou aplicar isso? Na consulta segura por código e na atualização de preço com validação do valor.

produtos = {'P001': {'nome': 'Caneta', 'preco': 2.75}}

# consulta segura
info = produtos.get('P999')
if info is None:
    print('Produto não encontrado.')
else:
    print(info)

# atualização múltipla
produtos.update({
    'P002': {'nome': 'Caderno', 'preco': 18.90},
    'P003': {'nome': 'Lápis', 'preco': 1.80}
})

# remoção com retorno
removido = produtos.pop('P003', None)  # não quebra se não existir
print('Removido:', removido)

Combinação com E/S: lendo do usuário e formatando saída

Integração com input() e print() permite construir menus simples. Valide entradas (vazias, tipo numérico) e formate valores monetários com duas casas decimais.

Onde vou aplicar isso? Em todo o passo a passo do catálogo: cadastrar, consultar, atualizar e listar produtos.

# exemplo de leitura e formatação
codigo = input('Código do produto: ').strip().upper()
nome = input('Nome do produto: ').strip()
preco_str = input('Preço (ex.: 12.50): ').replace(',', '.').strip()

if not preco_str:
    print('Preço inválido.')
else:
    try:
        preco = float(preco_str)
        print(f'Preço formatado: R$ {preco:.2f}')
    except ValueError:
        print('Digite um número válido para o preço.')

Passo a Passo — Catálogo de Produtos com Tuplas e Dicionários

Objetivo desta etapa:

Construir um programa de console que mantém um catálogo simples: cadastrar produtos, consultar por código, atualizar preços e listar todos, usando tuplas (para registros imutáveis quando cabível) e dicionários (chave-valor).


1) Estrutura base do programa e menu

Crie um novo arquivo no Thonny chamado catalogo_produtos.py. Vamos montar um menu principal com opções para cadastrar, consultar, atualizar, listar e sair.

# catalogo_produtos.py

def mostrar_menu():

            pass
        elif opc == '2':
            # consultar
            pass
        elif opc == '3':
            # atualizar preço
            pass
        elif opc == '4':
            # listar
            pass
        elif opc == '5':
            # remover
            pass

2) Cadastro de produto (tupla para dados de entrada e dict para armazenamento)

Ao cadastrar, leia código, nome e preço. Use uma tupla para “empacotar” temporariamente os dados lidos e depois armazene no dicionário principal, usando o código como chave.

def cadastrar_produto(produtos: dict):
    codigo = input('Código (ex.: P001): ').strip().upper()
    if not codigo:
        print('Código não pode ser vazio.')
        return

    if codigo in produtos:
        print('Já existe produto com esse código.')
        return

    nome = input('Nome: ').strip()
    preco_str = input('Preço (ex.: 12.50): ').replace(',', '.').strip()

    if not nome or not preco_str:
        print('Nome e preço são obrigatórios.')
        return

    try:
        preco = float(preco_str)
        if preco < 0:
            print('Preço precisa ser não negativo.')
            return
    except ValueError:
        print('Preço inválido, use números.')
        return

    entrada = (codigo, nome, preco)  # tupla imutável como “pacote de entrada”
    # armazenar no dict (mutável)
    produtos[codigo] = {'nome': entrada[1], 'preco': entrada[2]}
    print(f'Produto {codigo} cadastrado com sucesso.')

Integre essa função ao menu principal, chamando-a quando a opção for “1”.

# dentro do while do main():
if opc == '1':
    cadastrar_produto(produtos)

4) Atualização de preço com validação

Leia o novo preço, valide e atualize o valor no dicionário.

def atualizar_preco(produtos: dict):
    codigo = input('Código para atualizar: ').strip().upper()
    info = produtos.get(codigo)
    if info is None:
        print('Produto não encontrado.')
        return

    preco_str = input('Novo preço: ').replace(',', '.').strip()
    try:
        novo_preco = float(preco_str)
        if novo_preco < 0:
            print('Preço precisa ser não negativo.')
            return
    except ValueError:
        print('Preço inválido.')
        return

    info['preco'] = novo_preco
    print('Preço atualizado com sucesso.')
# no menu:
elif opc == '3':
    atualizar_preco(produtos)

def listar_todos(produtos: dict):
