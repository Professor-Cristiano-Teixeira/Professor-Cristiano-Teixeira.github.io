Parte Teórica (explicação do conteúdo)

1) O que é uma lista em Python?

Lista é uma estrutura de dados ordenada e mutável que armazena uma sequência de elementos. Em Python, listas são delimitadas por colchetes e os elementos são separados por vírgulas. Uma mesma lista pode conter valores de tipos diferentes, embora, na prática, seja comum usar listas homogêneas para facilitar o processamento.

Como é mutável, você pode alterar, inserir e remover elementos após a criação. Isso as torna ideais para coleções que evoluem ao longo da execução do programa.

Onde vou aplicar isso: você usará listas para manter itens de uma "Lista de Tarefas", armazenando textos das tarefas e manipulando-os ao longo do passo a passo.

2) Criação, indexação e fatiamento (slicing)

Criação básica: use colchetes com valores. A indexação começa em 0. Índices negativos contam a partir do final (-1 é o último). O fatiamento permite pegar subpartes com a notação [início:fim:passo], onde fim é exclusivo.

# criação
nums = [10, 20, 30]
misturada = [1, "dois", 3.0, True]

# indexação
primeiro = nums[0]     # 10
ultimo = nums[-1]      # 30

# fatiamento
sub = nums[0:2]        # [10, 20]
salto = list(range(1, 10))  # [1..9]
pares = salto[1::2]    # elementos de índice ímpar: [2, 4, 6, 8]

Cuidado com IndexError ao acessar índices fora do alcance e lembre que slicing fora dos limites não lança erro, apenas retorna o recorte possível.

Onde vou aplicar isso: para mostrar tarefas específicas pelo índice e para listar subconjuntos (ex.: primeiras N tarefas).

3) Operações e funções úteis

Algumas funções e operadores trabalham bem com listas: len(lista) retorna o tamanho; operador in verifica presença; enumerate(lista) gera pares (índice, valor), útil para percorrer com índice.

frutas = ["maçã", "banana", "uva"]
tamanho = len(frutas)         # 3
tem_banana = "banana" in frutas  # True

for i, fruta in enumerate(frutas):
    print(i, fruta)

Onde vou aplicar isso: para numerar tarefas ao listar e validar se um item existe antes de removê-lo.

4) Métodos de lista mais usados

Python oferece métodos prontos para manipular listas:

  • append(x): adiciona ao final.
  • insert(i, x): insere em uma posição.
  • remove(x): remove a primeira ocorrência de x (ValueError se não existir).
  • pop([i]): remove e retorna o elemento do índice i (ou o último se i omitido).
  • sort(reverse=False): ordena in-place.
  • reverse(): inverte a lista in-place.
  • clear(): remove todos os elementos.
numeros = [3, 1, 2]
numeros.append(5)     # [3,1,2,5]
numeros.insert(1, 9)  # [3,9,1,2,5]
numeros.remove(1)     # [3,9,2,5]
removido = numeros.pop(2)  # remove índice 2 -> [3,9,5]; removido=2
numeros.sort()        # [3,5,9]
numeros.reverse()     # [9,5,3]
numeros.clear()       # []

Onde vou aplicar isso: para adicionar e remover tarefas, além de ordenar alfabeticamente se desejado.

5) Percurso e busca linear

Percorrer (iterar) uma lista é essencial. A busca linear verifica elemento a elemento até encontrar o valor desejado. É simples e funciona bem para listas pequenas ou médias.

tarefas = ["estudar", "treinar", "ler"]
# percurso simples
for t in tarefas:
    print("- ", t)

# busca linear (retorna índice ou -1)
def buscar_indice(lista, alvo):
    for i, valor in enumerate(lista):
        if valor == alvo:
            return i
    return -1

print(buscar_indice(tarefas, "ler"))   # 2
print(buscar_indice(tarefas, "dormir"))# -1

Onde vou aplicar isso: para localizar rapidamente a posição de uma tarefa digitada pelo usuário e validar remoções.

6) Casos-limite e boas práticas

Sempre considere lista vazia, índices inválidos e entradas em branco. Faça checagens antes de remover/mostrar. Use nomes claros, mensagens úteis ao usuário e mantenha as operações encapsuladas quando possível (mesmo sem funções, separe bem os blocos).

Onde vou aplicar isso: no menu da Lista de Tarefas, garantindo que operações não quebrem o programa em situações imprevistas.

Etapa 4 — Remover por índice (pop) com validação

Peça o índice ao usuário e valide se está no intervalo da lista. Use pop para remover e obter o item removido.

elif opcao == "3":
    if not tarefas:
        print("Lista vazia. Nada a remover.")
    else:
        try:
            idx = int(input("Índice para remover: ").strip())
            if 0 <= idx < len(tarefas):
                removida = tarefas.pop(idx)
                print(f"Removida: '{removida['titulo']}'")
