Parte Teórica (explicação do conteúdo)

Tipos de dados primitivos: int, float, str e bool

Todo programa manipula dados. Em Python, os tipos primitivos mais usados no início são: int (inteiros como 0, 7, -42), float (números com ponto decimal, como 1.75, -3.0), str (cadeias de caracteres, como "Olá", "2024"), e bool (valores lógicos True/False). Escolher o tipo correto ajuda a evitar erros e permite que as operações sejam coerentes (por exemplo, somar números versus concatenar textos).

Valores lidos com input() chegam como str e, quando necessário, devem ser convertidos para int ou float. Bools costumam resultar de comparações (por exemplo, idade >= 18) e são muito utilizados em decisões (capítulos seguintes).

Onde vou aplicar isso: no passo a passo, você definirá variáveis que guardam nome (str), idade (int) e altura (float) para o “Resumo de Perfil”.

# exemplos de literais em Python
idade = 17               # int
altura = 1.72            # float
nome = "Ana"             # str
maior_de_idade = idade >= 18  # bool (resultado de uma comparação)
print(type(idade), type(altura), type(nome), type(maior_de_idade))

Variáveis e convenções para constantes

Variáveis são “caixas” nomeadas que armazenam valores. O nome deve ser significativo e seguir convenções de legibilidade, como snake_case: data_nascimento, nota_final. Em Python, não há palavra-chave para declarar constantes, mas por convenção usamos nomes em MAIÚSCULAS para indicar valores que não deveriam mudar (ex.: PI = 3.14159).

Evite nomes genéricos (x, y, z) quando possível. Bons nomes documentam a intenção do código e facilitam manutenção e correção de erros.

Onde vou aplicar isso: você criará variáveis nome, idade, altura e, opcionalmente, uma constante para CASA_DECIMAIS na formatação da altura.

# convenções de nomes
CASA_DECIMAIS = 2
nome_completo = "João da Silva"
saldo_atual = 150.0
print(nome_completo, saldo_atual, f"{saldo_atual:.{CASA_DECIMAIS}f}")

Conversão de tipos (casting) e validação básica

Como input() retorna str, precisamos converter para números quando formos calcular. Para inteiros, use int("42"); para decimais, use float("1.75"). Se a string não representar um número válido, ocorrerá erro. Por isso, é boa prática validar antes (cap. 08 aprofunda). Um caminho inicial é ler como str e tentar converter, exibindo mensagem amigável caso haja falha.

Ao converter, tenha atenção ao separador decimal: Python usa ponto (.) para floats. Se o usuário digitar vírgula, podemos substituir por ponto antes de converter.

Onde vou aplicar isso: no passo a passo, converteremos idade para int e altura para float, com tratamento simples de vírgula.

entrada_idade = input("Idade: ")
entrada_altura = input("Altura (use ponto ou vírgula): ")

# tentativa de conversão simples e segura
try:
    idade = int(entrada_idade)
    altura = float(entrada_altura.replace(",", "."))
except ValueError:
    print("Dados inválidos. Tente novamente.")
    idade = 0
    altura = 0.0

Entrada com input() e saída com print()

A função input(prompt) exibe uma mensagem e aguarda que o usuário digite algo, retornando uma string. A função print() exibe valores no console. Você pode imprimir vários itens separados por vírgulas e alterar o separador (sep) e o terminador (end) para controlar a formatação.

Além disso, use f-strings para formatar saídas de maneira clara, interpolando variáveis em strings e ajustando casas decimais ou alinhamento.

Onde vou aplicar isso: você exibirá um resumo formatado, controlando casas decimais da altura e a quebra de linha final.

nome = input("Seu nome: ")
print("Olá,", nome, "! Seja bem-vindo(a).", sep=" ", end="\n")

# f-strings e formatação numérica
nota = 8.756
print(f"Nota formatada com 2 casas: {nota:.2f}")

Formatação de saída: f-strings, sep e end

F-strings (f"...") permitem inserir expressões entre chaves, por exemplo f"Altura: {altura:.2f} m". O parâmetro sep de print() define o separador entre argumentos (padrão é espaço), e end define como a linha termina (padrão é "\n"). Ajustar esses parâmetros melhora a apresentação dos resultados.

Use formatação adequada para números monetários, percentuais, e medidas com casas decimais. Uma saída bem apresentada torna o programa mais amigável.

Onde vou aplicar isso: ao compor o “Resumo de Perfil”, usaremos f-strings para idade e altura, controlando casas decimais e frases.

idade = 20
altura = 1.7345
print("Idade:", idade, "anos", sep=" ")
print(f"Altura: {altura:.2f} m")  # 2 casas decimais

Passo a Passo — Resumo de Perfil (E/S e formatação)

Objetivo desta etapa:

Ler nome, idade e altura do usuário, converter tipos com segurança e imprimir um resumo formatado usando f-strings, sep e end.


1) Preparar o arquivo no Thonny

  1. Abra o Thonny. No menu Arquivo, clique em “Novo”.
  2. Salve como resumo_perfil.py em uma pasta do curso (ex.: PRAL/cap06/).
  3. Verifique se o interpretador é Python 3 e o console está visível.

2) Ler dados como string com input()

Comece pedindo os três dados. Lembre: input() retorna str. Vamos armazenar em variáveis com nomes claros.

# resumo_perfil.py — leitura inicial (str)
print("=== Resumo de Perfil ===")
nome_str = input("Digite seu nome: ")
idade_str = input("Digite sua idade (inteiro): ")
altura_str = input("Digite sua altura em metros (ponto ou vírgula): ")

3) Converter idade para int e altura para float

Converta com tratamento simples para vírgula no decimal. Use try/except para evitar que o programa quebre em caso de erro.

# conversão de tipos
try:
    idade = int(idade_str)
    altura = float(altura_str.replace(",", "."))
except ValueError:
    print("Entrada inválida! Idade deve ser inteiro e altura número decimal.")
    # valores padrão para continuar a execução (didático)
    idade = 0
    altura = 0.0

4) Exibir um resumo com print() e f-strings

Use f-strings para produzir saída clara. Formate altura com duas casas decimais. Ajuste sep e end quando necessário.

# saída formatada
print()  # linha em branco
print("---- Resumo ----")
print("Nome:", nome_str)
print(f"Idade: {idade} anos")
print(f"Altura: {altura:.2f} m")

# Exemplo do uso de sep e end
print("Obrigado por usar", "o sistema!", sep=" ", end="\n")

5) Testar cenários e refinar

  • Teste casos: idade “18”, altura “1.80”; depois “1,80”.
  • Digite valores inválidos para observar o try/except.
  • Opcional: defina uma constante para as casas decimais.
# refinamento opcional
CASAS = 2
print(f"Altura com {CASAS} casas: {altura:.{CASAS}f} m")

Código final sugerido

# resumo_perfil.py — Cap. 06 (PRAL)
CASAS = 2

print("=== Resumo de Perfil ===")
nome = input("Digite seu nome: ")
idade_str = input("Digite sua idade (inteiro): ")
altura_str = input("Digite sua altura em metros (ponto ou vírgula): ")

try:
    idade = int(idade_str)
    altura = float(altura_str.replace(",", "."))
except ValueError:
    print("Entrada inválida! Usando valores padrão para continuar.")
    idade = 0
    altura = 0.0

print("\n---- Resumo ----")
print(f"Nome: {nome}")
print(f"Idade: {idade} anos")
print(f"Altura: {altura:.{CASAS}f} m")
print("Obrigado por usar", "o sistema!", sep=" ")
