Capítulo 05 — Ambiente de Programação: Python e Thonny; “Hello, World!”

Carga: 2 a 4 horas (prática em laboratório)

Projeto-base: Setup do ambiente + primeiro script “hello_world.py”

Stack fixa: Python 3.x + Thonny IDE (Windows/Linux), terminal do SO

Resultados de aprendizagem deste capítulo:

  • Instalar e configurar o Thonny IDE com Python 3 funcional.
  • Diferenciar Editor e Console do Thonny e usar cada um adequadamente.
  • Criar, salvar, abrir e executar arquivos .py a partir do editor.
  • Escrever saídas com print() e documentar o código com comentários.
  • Resolver problemas simples de execução (erros comuns de instalação e caminho de arquivo).

  • Instalar e configurar ferramentas de desenvolvimento.

  • Executar e validar programas simples, registrando observações.
  • Aplicar organização de arquivos/projetos e boas práticas iniciais.

Parte Teórica (explicação do conteúdo)

1) Instalação e tour pelo Thonny IDE

O Thonny é uma IDE simples e ideal para iniciantes em Python. Ele integra editor, console interativo e ferramentas de execução e depuração. Ao instalar o Thonny, você obtém um ambiente pronto para digitar, salvar e executar scripts Python, reduzindo a complexidade inicial.

Principais áreas: Editor (onde você escreve e salva o código), Console/Shell (onde o Python mostra resultados e permite testes interativos), e a barra de ferramentas com botões de Run, parar execução, e menus como Tools e View. Entender cada área evita confusões ao iniciar.

Onde vou aplicar isso: você usará o Thonny para criar o arquivo hello_world.py, executar o programa e visualizar as saídas no Console.

2) Arquivos .py, salvar/executar, Console vs. Editor

Arquivos com extensão .py contêm código-fonte Python. No Editor, você escreve e salva esses arquivos; no Console, o interpretador executa o que foi salvo e exibe saídas e erros. Executar diretamente no Editor garante que o código do arquivo é que está sendo testado, evitando dependência de comandos digitados manualmente.

Use “Run” (F5) para executar o arquivo aberto; nomes de arquivos devem ser simples (sem espaços ou acentos) e a pasta do projeto deve estar organizada. O Console também permite testes rápidos (por exemplo, digitar print("Oi") e pressionar Enter), mas isso não substitui o arquivo salvo.

Onde vou aplicar isso: você criará uma pasta de projeto, salvará hello_world.py e executará pelo botão Run, observando a saída no Console.

3) Primeiro script: print() e comentários

A função print() envia texto para a saída padrão (Console). É o ponto de partida para verificar se o ambiente está funcionando. Comentários começam com # e servem para documentar o código, explicando a intenção do programador sem afetar a execução.

Comentários são importantes para a manutenção e para lembrar por que certas escolhas foram feitas. Textos entre aspas (simples ou duplas) representam strings; cuidado com aspas desencontradas para evitar erros de sintaxe.

Onde vou aplicar isso: você escreverá um “Hello, World!” com duas linhas de print e usará comentários para descrever o que cada parte faz.

4) Boas práticas iniciais de organização

Crie uma pasta por capítulo/projeto e use nomes descritivos, por exemplo, cap05_hello. Nomeie arquivos sem espaços, com minúsculas e underscores: hello_world.py. Essa organização simples evita erros de caminho e facilita encontrar seus trabalhos.

Acostume-se a salvar frequentemente (Ctrl+S) antes de executar. Verifique a aba “Files” no Thonny para garantir que está abrindo/executando o arquivo correto.

Onde vou aplicar isso: ao estruturar a pasta do capítulo, salvar corretamente o script e validar que o Thonny está executando o arquivo certo.

Passo a Passo — Preparar o Thonny e criar o “Hello, World!”

Objetivo desta etapa:

Instalar o Thonny, configurar o interpretador Python, criar o arquivo hello_world.py, escrever prints e comentários, executar e validar a saída no Console.


Instalar o Thonny (Windows/Linux)

Baixe o instalador no site oficial e siga o assistente padrão. Em laboratórios Linux, o Thonny pode estar disponível pelo gerenciador de pacotes.

Windows (site oficial)

# Acesse: https://thonny.org
# Baixe o instalador para Windows (inclui Python)
# Execute o .exe e avance com as opções padrão

Linux (Debian/Ubuntu)

# Opcional (verifique com o administrador do laboratório)
sudo apt update
sudo apt install thonny
Validação rápida: abra o Thonny. No Console, digite print("ok") e pressione Enter. Se aparecer ok, o interpretador está funcionando.

Conhecer a interface do Thonny

  • Editor: painel principal onde você escreve e salva arquivos .py.
  • Console (Shell): painel inferior onde aparecem saídas e você pode testar comandos isolados.
  • Botões: Run (F5) executa o arquivo atual; Stop interrompe execução travada.
  • Menu View: permite mostrar/ocultar painéis, e o menu Tools oferece configurações.

Criar pasta do projeto e arquivo hello_world.py

  1. No seu sistema, crie a pasta cap05_hello em Documentos.
  2. Abra o Thonny e vá em File → New para criar um novo arquivo.
  3. Salve como hello_world.py dentro da pasta cap05_hello (File → Save As).

Escrever e executar o primeiro script

Python

Digite o código abaixo no Editor e salve (Ctrl+S). Em seguida, clique em Run (F5). Observe a saída no Console.

# hello_world.py
# Objetivo: testar ambiente Python + Thonny

print("Hello, World!")
print("Ambiente configurado com sucesso!")
O que observar: duas linhas devem aparecer no Console. Se surgir erro de sintaxe, confira as aspas e parênteses.

Comentários e variações de print()

Python

Adicione comentários e experimente diferentes prints para entender a saída.

# Demonstrando comentários (não executam)
# Dica: use comentários para explicar a intenção do código

print("Linha 1")
print("Linha 2")  # Comentário ao lado
print("Olá", "mundo", sep=" - ")  # separador customizado
print("Quebra de linha automática")  # por padrão, print adiciona \n

# Evitando a quebra de linha no final:
print("Sem quebra", end="... ")
print("continua na mesma linha!")

Resolver problemas comuns

  • “NameError: name 'print' is not defined”: verifique se não há erro de digitação (por exemplo, prnit).
  • Sem saída no Console: confirme se você executou o arquivo correto (olhe o nome no topo do Editor) e salvou antes de rodar.
  • Arquivo em pasta errada: use File → Save As para salvar dentro de cap05_hello.
  • Caracteres estranhos na saída: garanta que o arquivo está em UTF-8 (padrão do Thonny) e use aspas normais.

Dica: quando corrigir algo, execute novamente para validar a correção.

Executar via terminal (opcional)

Além do Thonny, você pode executar o script pelo terminal para treinar caminhos de arquivo.

# No Windows (PowerShell) — ajuste o caminho conforme sua pasta
cd "$HOME\Documents\cap05_hello"
python hello_world.py

# No Linux
cd ~/Documentos/cap05_hello
python3 hello_world.py
