Capítulo 07 — DML Básico: Inserção e Consulta

Carga: 4 a 6 horas (laboratório com prática guiada)

Projeto-base: Caso de Vendas (Clientes, Produtos, Pedidos e Itens)

Stack fixa: MySQL + MySQL Workbench; SQL padrão; Terminal/Workbench

Resultados de aprendizagem deste capítulo:

  • Inserir dados em tabelas existentes usando INSERT nas variações de colunas e múltiplas linhas.
  • Consultar registros com SELECT, aplicando filtros com WHERE e operadores básicos.
  • Ordenar e limitar resultados com ORDER BY e LIMIT.
  • Aplicar funções simples em colunas (UCASE/LOWER/CONCAT/ROUND/DATE_FORMAT) sem alterar dados originais.
  • Popular o esquema de vendas criado no capítulo anterior e responder perguntas do negócio com consultas simples.

Competências e Habilidades

  • Aplicar comandos DML fundamentais para manipulação segura de dados.
  • Interpretar requisitos do negócio e traduzi-los em filtros e ordenações SQL.
  • Organizar scripts SQL reexecutáveis e documentados.
  • Validar resultados, conferindo consistência entre dados inseridos e consultas realizadas.

Plano de Aula (Capítulo 07)

  1. Revisão inicial (10–15 min): recapitular o esquema do caso de vendas criado no capítulo 06 (clientes, produtos, pedidos, itens_pedido) e verificar se todos têm o banco disponível.
  2. Exposição guiada (20–30 min): introduzir DML básico: INSERT, SELECT, WHERE, ORDER BY, LIMIT e funções simples. Mostrar sintaxe geral, boas práticas e exemplos pequenos.
  3. Prática passo a passo (60–80 min): popular tabelas com INSERTs (múltiplas linhas), em seguida construir consultas com filtros típicos do negócio. Validar resultados com conferências.
  4. Exercícios autônomos (20–30 min): propor variações de filtros e ordenações; registrar respostas esperadas.
  5. Fechamento (10 min): checklist do que foi aprendido, quiz rápido e explicação do próximo capítulo (agregações).

Parte Teórica (explicação do conteúdo)

Visão geral de DML (Data Manipulation Language)

DML é o conjunto de comandos SQL usados para manipular dados nas tabelas. No nível básico, você usará principalmente INSERT para inserir registros e SELECT para consultar. Em capítulos futuros, ampliaremos para UPDATE e DELETE, além de transações.

Como regra de ouro, escreva scripts reexecutáveis, com comentários, e sempre valide a quantidade e o conteúdo dos registros inseridos e consultados.

Onde vou aplicar isso? Ao popular o banco do caso de vendas e ao construir consultas que respondem perguntas do negócio (por exemplo, “quais produtos custam mais de R$50,00?”).

INSERT: inserindo dados

O comando INSERT adiciona novas linhas a uma tabela. Use sempre a lista de colunas para evitar erros caso a tabela mude. Você pode inserir uma linha por vez ou várias linhas em um único comando.

-- Forma recomendada, especificando colunas
INSERT INTO clientes (nome, email, telefone)
VALUES ('Ana Silva', 'ana.silva@example.com', '(11) 90000-1111');

-- Inserção de múltiplas linhas
INSERT INTO produtos (nome, preco, categoria)
VALUES 
  ('Teclado Mecânico', 299.90, 'Periféricos'),
  ('Mouse Óptico', 79.50, 'Periféricos'),
  ('Monitor 24"', 899.00, 'Monitores');

Onde vou aplicar isso? Para popular as tabelas clientes, produtos e demais do caso de vendas rapidamente, criando um conjunto de dados de teste consistente.

SELECT: consultando dados

SELECT recupera dados de uma ou mais tabelas. Com ele, você define quais colunas ver, em que ordem e quantas linhas retornar. Você pode usar alias para deixar o resultado mais legível.

-- Seleciona colunas específicas
SELECT id, nome, email 
FROM clientes;

-- Alias de coluna e tabela
SELECT p.id AS codigo, p.nome AS produto, p.preco
FROM produtos AS p;

Onde vou aplicar isso? Para listar clientes cadastrados, verificar preços de produtos e explorar os dados que você inseriu com INSERT.

WHERE: filtrando resultados

WHERE restringe as linhas retornadas com base em condições. Combine operadores relacionais (=, <, >, <=, >=, <>) e lógicos (AND, OR, NOT). Para textos, use LIKE com curingas % e _.

-- Produtos com preço maior que 100
SELECT nome, preco
FROM produtos
WHERE preco > 100;

-- Clientes cujo email termina com "example.com"
SELECT nome, email
FROM clientes
WHERE email LIKE '%@example.com';

-- Filtros combinados
SELECT nome, preco, categoria
FROM produtos
WHERE categoria = 'Periféricos' AND preco BETWEEN 50 AND 300;

Onde vou aplicar isso? Para responder perguntas específicas do negócio, como localizar produtos em uma faixa de preço ou clientes por domínio de e-mail.

ORDER BY e LIMIT: ordenando e limitando

ORDER BY define a ordenação do resultado em ordem crescente (ASC) ou decrescente (DESC). LIMIT restringe a quantidade de linhas retornadas, útil para prévias e listagens.

-- Top 5 produtos mais caros
SELECT nome, preco
FROM produtos
ORDER BY preco DESC
LIMIT 5;

-- Clientes por ordem alfabética
SELECT id, nome
FROM clientes
ORDER BY nome ASC;

Onde vou aplicar isso? Para construir listagens amigáveis (por preço, nome, data) e mostrar apenas uma amostra de dados (Top N).

Funções básicas úteis no SELECT

Funções de string e numéricas ajudam a formatar a saída sem alterar os dados. Exemplos: UCASE/UPPER, LCASE/LOWER, CONCAT, ROUND, DATE_FORMAT, NOW. Use-as no SELECT para melhorar a apresentação.

-- Formatações comuns
SELECT 
  UPPER(nome) AS nome_maiusculo,
  CONCAT('R$ ', FORMAT(preco, 2, 'pt_BR')) AS preco_fmt
FROM produtos;

-- Data/hora atual e formatação (MySQL)
SELECT 
  NOW() AS agora, 
  DATE_FORMAT(NOW(), '%d/%m/%Y %H:%i') AS agora_fmt;

Onde vou aplicar isso? Ao montar relatórios simples, rotular colunas, padronizar caixa de texto e exibir valores monetários amigáveis.

Boas práticas e validação

Mantenha scripts versionados, com comentários e em ordem lógica (ex.: primeiro clientes e produtos, depois pedidos e itens). Após cada bloco de INSERT, faça um SELECT de conferência (com COUNT e amostras por LIMIT).

-- Conferência após inserções
SELECT COUNT(*) AS total_clientes FROM clientes;
SELECT COUNT(*) AS total_produtos FROM produtos;
SELECT * FROM clientes ORDER BY id DESC LIMIT 5;

Onde vou aplicar isso? Em todo ciclo de prática deste capítulo, garantindo que os dados de teste estão consistentes para os próximos capítulos (agregações e joins).

Passo a Passo — Inserção e Consulta no Caso de Vendas

Objetivo desta etapa:

Popular o banco de dados de vendas criado no capítulo 06 com dados de exemplo e praticar consultas básicas usando SELECT, WHERE, ORDER BY e LIMIT, além de funções simples.


1) Preparar o ambiente

Abra o MySQL Workbench e conecte-se ao servidor local. Se você seguiu o capítulo 06, já deve ter um schema criado (por exemplo, vendas_db) com as tabelas clientes, produtos, pedidos e itens_pedido.

-- Se necessário, selecione o seu schema
USE vendas_db;

-- Verifique se as tabelas existem
SHOW TABLES;
Dica: se não lembrar a estrutura das tabelas, use DESCRIBE nome_tabela; para ver colunas e tipos.

2) Inserir clientes

Insira um conjunto inicial de clientes. Use sempre a lista de colunas e agrupe múltiplas linhas quando fizer sentido.

INSERT INTO clientes (nome, email, telefone)
VALUES 
  ('Ana Silva', 'ana.silva@example.com', '(11) 90000-1111'),
  ('Bruno Costa', 'bruno.costa@example.com', '(21) 98888-2222'),
  ('Carla Nunes', 'carla.nunes@example.com', '(31) 97777-3333'),
  ('Diego Ramos', 'diego.ramos@empresa.com.br', '(41) 96666-4444'),
  ('Eva Martins', 'eva.martins@empresa.com.br', '(51) 95555-5555');
-- Conferência
SELECT COUNT(*) AS total_clientes FROM clientes;
SELECT id, nome, email FROM clientes ORDER BY id ASC LIMIT 5;

3) Inserir produtos

Popule a tabela de produtos com diferentes categorias e preços para permitir consultas variadas.

INSERT INTO produtos (nome, preco, categoria)
VALUES
  ('Teclado Mecânico', 299.90, 'Periféricos'),
  ('Mouse Óptico', 79.50, 'Periféricos'),
  ('Monitor 24"', 899.00, 'Monitores'),
  ('Cabo HDMI 2m', 39.90, 'Acessórios'),
  ('Headset Gamer', 349.00, 'Periféricos'),
  ('Notebook 14"', 3899.00, 'Computadores'),
  ('Webcam HD', 159.00, 'Periféricos');
-- Conferência
SELECT COUNT(*) AS total_produtos FROM produtos;
SELECT id, nome, preco, categoria 
FROM produtos 
ORDER BY preco DESC 
LIMIT 5;

4) Inserir pedidos e itens (amostra)

Crie alguns pedidos vinculados a clientes já inseridos. Em seguida, adicione itens para cada pedido com referências a produtos. Ajuste os IDs conforme estiverem no seu banco (consulte com SELECT).

-- Pedidos (supondo que a tabela possua colunas: id, cliente_id, data_pedido)
INSERT INTO pedidos (cliente_id, data_pedido)
VALUES
  (1, '2024-03-10'),
  (2, '2024-03-11'),
  (1, '2024-03-15');

-- Itens dos pedidos (supondo colunas: id, pedido_id, produto_id, quantidade, preco_unit)
-- Pedido 1
INSERT INTO itens_pedido (pedido_id, produto_id, quantidade, preco_unit)
VALUES
  (1, 1, 1, 299.90),   -- Teclado Mecânico
  (1, 4, 2, 39.90);    -- Cabo HDMI 2m (2 unidades)

-- Pedido 2
INSERT INTO itens_pedido (pedido_id, produto_id, quantidade, preco_unit)
VALUES
  (2, 2, 1, 79.50),    -- Mouse Óptico
  (2, 7, 1, 159.00);   -- Webcam HD

-- Pedido 3
INSERT INTO itens_pedido (pedido_id, produto_id, quantidade, preco_unit)
VALUES
  (3, 3, 1, 899.00);   -- Monitor 24"
-- Conferência rápida
SELECT COUNT(*) AS total_pedidos FROM pedidos;
SELECT COUNT(*) AS total_itens FROM itens_pedido;
SELECT * FROM pedidos ORDER BY id DESC LIMIT 5;
SELECT * FROM itens_pedido ORDER BY pedido_id ASC;
Se ocorrer erro de chave estrangeira, verifique se os IDs de clientes e produtos existem. Ajuste os valores conforme o seu banco.

5) Consultas básicas com WHERE

Pratique filtros comuns do negócio: por preço, categoria, domínio de e-mail e faixas.

-- Produtos acima de R$300, ordenados do mais caro
SELECT nome, preco
FROM produtos
WHERE preco > 300
ORDER BY preco DESC;

-- Periféricos até R$200
SELECT nome, preco
FROM produtos
WHERE categoria = 'Periféricos' AND preco <= 200
ORDER BY preco ASC;

-- Clientes com e-mail corporativo (termina com empresa.com.br)
SELECT nome, email
FROM clientes
WHERE email LIKE '%@empresa.com.br'
ORDER BY nome ASC;

6) Limitar resultados e criar “Top N”

Use LIMIT para obter amostras e “Top N” por ordenação. Isso ajuda a navegar por dados maiores.

-- 3 produtos mais baratos
SELECT nome, preco
FROM produtos
ORDER BY preco ASC
LIMIT 3;

-- Clientes mais recentes (assumindo ID autoincrement)
SELECT id, nome
FROM clientes
ORDER BY id DESC
LIMIT 3;

7) Funções simples para formatar saída

Melhore a legibilidade com funções de string, número e data. Não altera dados na tabela, apenas a visualização.

-- Formatar dinheiro e caixa do texto
SELECT 
  UPPER(nome) AS produto,
  CONCAT('R$ ', FORMAT(preco, 2, 'pt_BR')) AS preco_formatado
FROM produtos
ORDER BY preco DESC
LIMIT 5;

-- Data formatada dos pedidos
SELECT 
  id,
  DATE_FORMAT(data_pedido, '%d/%m/%Y') AS data_br
FROM pedidos
ORDER BY data_pedido DESC;

8) Checklist de conferência

Antes de seguir, valide:

  • Contagens de linhas em cada tabela batem com o esperado (clientes, produtos, pedidos, itens_pedido).
  • Consultas com WHERE retornam resultados condizentes com os filtros.
  • ORDER BY e LIMIT estão aplicando a ordenação e os recortes corretos.
  • Funções de formatação não geram erros e tornam a leitura mais clara.

Atividades Práticas para o(a) aluno(a) (desenvolver por conta própria)

Objetivo: Consolidar o uso de INSERT e SELECT com filtros, ordenações, limites e funções simples, aplicados ao caso de vendas.

Atividade 1 — Ampliação do conjunto de dados

Insira pelo menos 5 novos clientes e 5 novos produtos, variando categorias e preços. Em seguida, crie 3 novos pedidos e seus itens.

  • Registre as consultas de conferência (COUNT e amostras com LIMIT).
  • Garanta que todos os itens referenciem IDs válidos.

Atividade 2 — Catálogo filtrado

Monte uma listagem de produtos “catálogo” com as colunas: produto (em UPPER), categoria, preço formatado (R$ 0.000,00). Mostre apenas os 10 mais caros.

Atividade 3 — Segmentação de clientes

Liste clientes com e-mail corporativo (domínio empresa.com.br), ordenados por nome. Depois, liste os demais (não corporativos). Compare a quantidade de cada grupo.

Critérios de avaliação (formativa)

  • Corretude dos comandos INSERT e consistência entre chaves (FKs) e dados.
  • Aplicação adequada de WHERE, ORDER BY e LIMIT para responder perguntas.
  • Uso consciente de funções simples para melhorar a leitura dos resultados.
  • Organização e clareza do script SQL (comentários, seções, reexecutabilidade).
  • Validações por meio de consultas de conferência (COUNT, amostras).

Pesquisas complementares (sugestões)

  • Documentação MySQL sobre SELECT, WHERE, ORDER BY e LIMIT.
  • Funções de string e data no MySQL: UPPER/LOWER, CONCAT, FORMAT, DATE_FORMAT.
  • Boas práticas para scripts SQL versionados e reexecutáveis.
  • Diferenças de sintaxe entre MySQL e SQL padrão para funções básicas.

Entregáveis ao final do Capítulo 07

  • Script SQL contendo inserções (INSERT) para clientes, produtos, pedidos e itens, com comentários.
  • Script SQL de consultas (SELECT) demonstrando filtros (WHERE), ordenações (ORDER BY), limites (LIMIT) e funções.
  • Breve relatório (5–10 linhas) descrevendo como você validou os dados e exemplos de perguntas respondidas.
