Parte Teórica (explicação do conteúdo)

1) Bibliotecas de conexão Python–MySQL

Para que um programa Python interaja com o MySQL, usamos um “driver” (também chamado de conector). Um dos mais utilizados é o pacote mysql-connector-python, mantido pela Oracle. Existem alternativas como PyMySQL e mysqlclient, mas neste capítulo adotaremos o mysql-connector-python por ser completo, multiplataforma e simples de instalar.

O driver implementa a PEP 249 (DB-API 2.0), um padrão de como módulos de banco expõem objetos de conexão e cursor, métodos de execução de comandos e leitura de resultados. Entender essa interface ajuda a migrar para outros SGBDs no futuro (ex.: PostgreSQL) com poucas mudanças.

Onde vou aplicar isso no passo a passo: você instalará o pacote via pip, importará o módulo mysql.connector e criará a primeira conexão testando um SELECT 1.

2) Parâmetros de conexão e boas práticas

Para conectar, você precisa de host (endereço do servidor), porta (padrão 3306), usuário, senha e nome do banco (database). Em laboratório, é comum usar localhost, usuário de desenvolvimento e uma base específica do projeto.

Evite colocar senhas diretamente no código. Prefira variáveis de ambiente ou arquivos de configuração ignorados pelo controle de versão. Também é boa prática validar a conexão e tratar exceções para informar claramente erros como “acesso negado” ou “banco inexistente”.

Onde vou aplicar isso no passo a passo: você criará um módulo de configuração simples e fará try/except na abertura da conexão, exibindo mensagens amigáveis.

3) Cursores, execução de SQL e commits

Após abrir a conexão, criamos um cursor para executar comandos SQL. Comandos de escrita (INSERT, UPDATE, DELETE) precisam de commit para persistir as alterações; do contrário, podem ser revertidos quando a conexão encerrar. Já consultas (SELECT) retornam linhas que podem ser lidas com fetchone/fetchall.

Há cursores que retornam tuplas (padrão) e, em alguns drivers, cursores que retornam dicionários, facilitando acessar colunas por nome. Trabalhar conscientemente com o tipo de cursor simplifica o restante do código.

Onde vou aplicar isso no passo a passo: você criará cursores, executará INSERT/SELECT e usará commit no momento correto.

4) Consultas parametrizadas e prevenção de SQL Injection

Parametrizar consultas significa não concatenar strings de usuário diretamente no SQL. Em vez disso, usamos marcadores de posição e passamos os valores em uma tupla. O driver faz a sanitização adequada, prevenindo ataques de SQL Injection.

Em mysql-connector-python, os marcadores são %s (independente do tipo). Evite formatar SQL com f-strings, .format ou concatenação para dados dinâmicos. Essa prática é essencial em qualquer aplicação conectada a banco.

Onde vou aplicar isso no passo a passo: ao inserir e consultar clientes, você utilizará placeholders e parâmetros seguros.

5) Leitura de resultados: fetchone, fetchall e iteração

Depois de executar um SELECT, usamos fetchone para obter uma linha por vez ou fetchall para trazer todas as linhas. Em conjuntos grandes, prefira iterar sobre o cursor (streaming) para economizar memória. Entenda o formato retornado (tuplas) e mapeie para dicionários ou objetos quando necessário.

Também é útil verificar cursor.rowcount para saber quantas linhas foram afetadas ou retornadas (com ressalvas dependendo do driver e do tipo de operação).

Onde vou aplicar isso no passo a passo: você listará clientes em diferentes formatos e imprimirá os resultados formatados.

6) Estrutura de projeto e mensagens de log

Separar conexão, operações e a aplicação principal torna o código mais limpo e testável. Além disso, mensagens de log ajudam a diagnosticar problemas de credenciais, SQL inválido ou falhas de rede. Para este capítulo, usaremos prints claros; em projetos maiores, use o módulo logging.

Onde vou aplicar isso no passo a passo: você criará um arquivo db.py para cuidar da conexão e um app.py para as operações e testes.

Passo a Passo — Conectar Python ao MySQL e executar SQL com segurança

Objetivo desta etapa:

Instalar o conector, configurar a conexão, executar comandos parametrizados e ler resultados para um mini-CRUD de clientes (inserção e consulta).


Preparar o ambiente

Garanta que o MySQL Server está em execução e que você possui um usuário com permissão para criar/usar um banco de desenvolvimento. No MySQL Workbench, crie um schema de teste, por exemplo bd_vendas.

-- No MySQL Workbench
CREATE DATABASE IF NOT EXISTS bd_vendas
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_general_ci;

USE bd_vendas;

-- Tabela de clientes para o exemplo
CREATE TABLE IF NOT EXISTS clientes (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nome VARCHAR(100) NOT NULL,
  email VARCHAR(120) NOT NULL UNIQUE,
  criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Instale o conector Python no terminal do sistema ou no terminal integrado do Thonny.

pip install mysql-connector-python

Criar o módulo de conexão (db.py)

Centralize a lógica de conexão para reutilizar no seu projeto. Use try/except para mensagens claras e retorno seguro.

# db.py
import os
import mysql.connector
from mysql.connector import Error

def get_conn():
    """
    Abre e retorna uma conexão com o MySQL usando variáveis de ambiente
    ou valores padrão de desenvolvimento. Ajuste conforme seu laboratório.
    """
    host = os.getenv("DB_HOST", "localhost")
    port = int(os.getenv("DB_PORT", "3306"))
    user = os.getenv("DB_USER", "root")
    password = os.getenv("DB_PASS", "root")
    database = os.getenv("DB_NAME", "bd_vendas")

    try:
        conn = mysql.connector.connect(
            host=host, port=port,
            user=user, password=password,
            database=database
        )
        if conn.is_connected():
            return conn
    except Error as e:
        print(f"[ERRO] Falha ao conectar: {e}")
    return None

Dica: defina variáveis de ambiente DB_HOST, DB_USER etc. conforme necessário. Se não puder, ajuste valores padrão acima.

Testar a conexão e um SELECT simples (app.py)

Crie um arquivo app.py para validar a conexão, criar um cursor e executar um teste.

# app.py
from db import get_conn

def teste_conexao():
    conn = get_conn()
    if not conn:
        print("[ERRO] Não foi possível conectar ao banco. Verifique credenciais e servidor.")
        return
    try:
        cur = conn.cursor()
        cur.execute("SELECT 1")
        print("[OK] Conexão válida. Resultado:", cur.fetchone())
    finally:
        cur.close()
        conn.close()

if __name__ == "__main__":
    teste_conexao()

Execute e confirme o resultado (deve imprimir uma tupla contendo 1).

python app.py

Inserção segura com parâmetros

Evite concatenar strings. Use placeholders %s e passe os valores em uma tupla ao executar.

# app.py (adicione estas funções)
from db import get_conn

def inserir_cliente(nome: str, email: str) -> int | None:
    sql = "INSERT INTO clientes (nome, email) VALUES (%s, %s)"
    conn = get_conn()
    if not conn:
        print("[ERRO] Sem conexão.")
        return None
    try:
        cur = conn.cursor()
        cur.execute(sql, (nome, email))
        conn.commit()
        novo_id = cur.lastrowid
        print(f"[OK] Cliente inserido com id={novo_id}")
        return novo_id
    except Exception as e:
        print(f"[ERRO] Falha ao inserir: {e}")
        conn.rollback()
        return None
    finally:
        cur.close()
        conn.close()

if __name__ == "__main__":
    # Teste rápido de inserção
    inserir_cliente("Alice Silva", "alice.silva@example.com")

Se tentar inserir um email repetido, a UNIQUE vai falhar. Observe a mensagem e o rollback.

Consulta com filtros parametrizados

Use parâmetros também em SELECTs. Abaixo, duas funções: listar todos e buscar por parte do nome (LIKE).

# app.py (adicione)
def listar_clientes():
    sql = "SELECT id, nome, email, criado_em FROM clientes ORDER BY id"
    conn = get_conn()
    if not conn:
        print("[ERRO] Sem conexão.")
        return []
    try:
        cur = conn.cursor()
        cur.execute(sql)
        rows = cur.fetchall()
        for r in rows:
            print(f"id={r[0]} | nome={r[1]} | email={r[2]} | criado_em={r[3]}")
        return rows
    except Exception as e:
        print(f"[ERRO] Falha na consulta: {e}")
        return []
    finally:
        cur.close()
        conn.close()

def buscar_clientes_por_nome(fragmento: str):
    sql = "SELECT id, nome, email FROM clientes WHERE nome LIKE %s ORDER BY nome"
    conn = get_conn()
    if not conn:
        print("[ERRO] Sem conexão.")
        return []
    try:
        cur = conn.cursor()
        cur.execute(sql, (f"%{fragmento}%",))
        rows = cur.fetchall()
        for r in rows:
            print(f"- {r[1]} <{r[2]}> (id={r[0]})")
        return rows
    except Exception as e:
        print(f"[ERRO] Falha na busca: {e}")
        return []
    finally:
        cur.close()
        conn.close()

if __name__ == "__main__":
    listar_clientes()
    buscar_clientes_por_nome("Ali")

Cursor com dicionário (opcional)

Para acessar colunas por nome, crie o cursor com dictionary=True.

# Exemplo rápido
from db import get_conn

def listar_com_dict():
    conn = get_conn()
    if not conn:
        print("[ERRO] Sem conexão.")
        return
    try:
        cur = conn.cursor(dictionary=True)
        cur.execute("SELECT id, nome, email FROM clientes")
        for row in cur:
            print(row["id"], row["nome"], row["email"])
    finally:
        cur.close()
        conn.close()
