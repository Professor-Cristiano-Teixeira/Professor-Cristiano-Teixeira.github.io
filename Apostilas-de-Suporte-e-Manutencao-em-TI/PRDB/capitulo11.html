Parte Teórica (explicação do conteúdo)

Listas, Tuplas e Dicionários

Listas são coleções ordenadas e mutáveis, ideais para armazenar sequências de elementos que podem variar ao longo do processamento. Tuplas são semelhantes, porém imutáveis, oferecendo segurança quando você precisa garantir que os dados não mudem (por exemplo, um par fixo de coordenadas ou uma estrutura de campos). Dicionários armazenam pares chave-valor, sendo a base para representar registros com rótulos claros (por exemplo, {"nome": "Ana", "idade": 17}).

Em pipelines de dados, listas geralmente representam conjuntos de registros, dicionários representam cada registro (campos nomeados), e tuplas podem ser usadas para chaves compostas ou estruturas fixas temporárias. Entender quando usar cada uma economiza memória e simplifica as transformações.

Onde vou aplicar isso: você usará listas para armazenar linhas lidas do CSV, dicionários para mapear nomes de colunas a valores, e tuplas para chaves ou constantes imutáveis quando necessário.

# Exemplos rápidos
alunos = ["Ana", "Bruno", "Carla"]              # lista
coordenadas = (23.5, -46.6)                     # tupla
registro = {"nome": "Ana", "idade": 17}         # dicionário

# Acesso e mutação
alunos.append("Diego")
idade = registro.get("idade", None)

Comprehensions (list e dict)

Comprehensions permitem criar listas e dicionários de maneira concisa e eficiente. São úteis para filtrar, transformar e mapear dados em uma única expressão, melhorando legibilidade e desempenho para coleções pequenas e médias.

Uma list comprehension segue a forma [expressao for item in iteravel if condicao]. Para dict comprehension, usa-se {chave: valor for item in iteravel}. Evite expressões complexas demais; se ficar difícil de ler, prefira um laço explícito com funções.

Onde vou aplicar isso: no passo a passo, você utilizará comprehensions para limpar espaços, normalizar campos e filtrar linhas inválidas do CSV antes de gerar o JSON final.

# List comprehension: transformar e filtrar
idades = [17, 18, 16, 20]
maiores = [i for i in idades if i >= 18]

# Dict comprehension: normalizar nomes de colunas
colunas = [" Nome ", " Idade ", " Email "]
mapa = {c.strip().lower(): c.strip() for c in colunas}

Manipulação de Strings

Strings precisam de limpeza e padronização em dados reais: remoção de espaços, ajuste de capitalização, substituição de caracteres e validação de formatos (e-mail, datas, números). Funções como strip(), lower(), replace() e split() são essenciais. Para validações, combine métodos de string com conversões seguras (int(), float()) dentro de try/except.

Onde vou aplicar isso: ao ler o CSV, você padronizará campos (por exemplo, nome em título, e-mail em minúsculas) e tratará números e datas com conversões seguras.

nome = "  maria das dores  ".strip().title()  # "Maria Das Dores"
email = "USUARIO@EXEMPLO.COM".lower()
telefone = "(11) 99999-0000".replace("(", "").replace(")", "").replace("-", "").replace(" ", "")

CSV e JSON no Python (módulos csv e json)

CSV é um formato tabular simples, usual para importações/exportações. O módulo csv oferece DictReader e DictWriter, facilitando o trabalho por nomes de colunas. JSON é o formato mais comum para APIs e integração entre sistemas; o módulo json permite serializar (dump/dumps) e desserializar (load/loads) dados Python.

Ao converter CSV para JSON, garanta: nomes de campos padronizados, tipos corretos (números como números, datas como strings ISO até que sejam parseadas) e remoção de registros inconsistentes quando necessário.

Onde vou aplicar isso: no passo a passo, você lerá um arquivo CSV com DictReader e gravará um JSON final com json.dump, após validações.

import csv, json

with open("dados.csv", newline="", encoding="utf-8") as f:
    leitor = csv.DictReader(f)
    linhas = list(leitor)

with open("saida.json", "w", encoding="utf-8") as f:
    json.dump(linhas, f, ensure_ascii=False, indent=2)

Tratamento de Exceções (try/except)

Exceções representam erros em tempo de execução. Use blocos try/except para capturá-las e reagir adequadamente (mensagens, correções, descarte de registros). É fundamental capturar exceções específicas (ValueError, FileNotFoundError, KeyError) quando possível, mantendo o script robusto.

Evite except genérico sem log; se precisar capturar Exception, registre e continue de forma segura. Sempre que manipular arquivos, use with para garantir fechamento.

Onde vou aplicar isso: você envolverá parsing de números e abertura de arquivos em try/except, registrando erros e pulando linhas inválidas.

try:
    idade = int("18")
except ValueError as e:
    print("Idade inválida:", e)

Logging básico (módulo logging)

Logging registra eventos do programa com níveis (DEBUG, INFO, WARNING, ERROR, CRITICAL). Diferente de prints, logs podem ser direcionados a arquivos, padronizados e filtrados por nível. Em pipelines de dados, registre quantidades processadas, erros por linha e decisões de limpeza.

Defina um formato claro e um nível inicial (por exemplo, INFO). Para depuração, use DEBUG. Evite registrar dados sensíveis.

Onde vou aplicar isso: o script registrará início/fim do processo, contagem de linhas válidas/descartadas e erros específicos encontrados.

import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s",
    filename="pipeline.log",
    encoding="utf-8"
)

logging.info("Iniciando pipeline CSV->JSON")

2) Estrutura base do script e configuração de logging

Crie o arquivo main.py com configuração de logging, leitura de parâmetros simples (nomes fixos de arquivos) e função principal.

import csv
import json
import logging
from pathlib import Path

ARQ_CSV = "dados.csv"
ARQ_JSON = "saida.json"
ARQ_LOG = "pipeline.log"

def configurar_logging():
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s %(levelname)s %(message)s",
        filename=ARQ_LOG,
        encoding="utf-8"
    )

def main():
    configurar_logging()
    logging.info("Início do pipeline CSV->JSON")
    if not Path(ARQ_CSV).exists():
        logging.error(f"Arquivo CSV não encontrado: {ARQ_CSV}")
        print(f"Erro: {ARQ_CSV} não encontrado.")
        return

    # As próximas etapas serão implementadas nos passos seguintes
    logging.info("Pipeline finalizado")

if __name__ == "__main__":
    main()

3) Leitura segura do CSV com DictReader

Use DictReader para trabalhar por nomes de colunas. Registre a contagem de linhas lidas.

def ler_csv(caminho_csv: str) -> list[dict]:
    linhas = []
    try:
        with open(caminho_csv, newline="", encoding="utf-8") as f:
            leitor = csv.DictReader(f)
            for row in leitor:
                linhas.append(row)
        logging.info(f"Lidas {len(linhas)} linhas do CSV.")
    except FileNotFoundError:
        logging.error(f"Arquivo inexistente: {caminho_csv}")
        raise
    except Exception as e:
        logging.exception(f"Erro inesperado ao ler CSV: {e}")
        raise
    return linhas

# Dentro de main(), após verificar existência:
linhas = ler_csv(ARQ_CSV)

4) Funções de limpeza e validação de campos

Padronize nome (title case), e-mail (minúsculas sem espaços), idade (inteiro >= 0) e cidade (title case). Registre e descarte linhas inválidas, preservando somente as válidas.

def limpar_nome(valor: str) -> str:
    return (valor or "").strip().title()

def limpar_email(valor: str) -> str:
    return (valor or "").strip().lower().replace(" ", "")

def limpar_cidade(valor: str) -> str:
    return (valor or "").strip().title()

def validar_idade(valor: str) -> int | None:
    try:
        idade = int(str(valor).strip())
        return idade if idade >= 0 else None
    except ValueError:
        return None

def limpar_validar_linha(row: dict) -> dict | None:
    nome = limpar_nome(row.get("nome"))
    email = limpar_email(row.get("email"))
    cidade = limpar_cidade(row.get("cidade"))
    idade = validar_idade(row.get("idade"))

    erros = []
    if not nome:
        erros.append("nome vazio")
    if not email or "@" not in email or "." not in email:
        erros.append("email inválido")
    if idade is None:
        erros.append("idade inválida")

    if erros:
        logging.warning(f"Linha descartada: {row} | Motivos: {', '.join(erros)}")
        return None

    return {
        "nome": nome,
        "email": email,
        "idade": idade,
        "cidade": cidade
    }

5) Aplicar limpeza/validação com comprehension

Utilize uma list comprehension para aplicar a validação a todas as linhas e filtrar as inválidas. Registre estatísticas.

def processar_linhas(linhas: list[dict]) -> list[dict]:
    processadas = [limpar_validar_linha(r) for r in linhas]
    validas = [r for r in processadas if r is not None]
    logging.info(f"Registros válidos: {len(validas)} | Descartados: {len(linhas) - len(validas)}")
    return validas

# No main():

7) Arquivo completo (referência)

Conferir o script completo abaixo. Execute e observe o log gerado com avisos de linhas descartadas.

import csv
import json
import logging
from pathlib import Path

ARQ_CSV = "dados.csv"
ARQ_JSON = "saida.json"
ARQ_LOG = "pipeline.log"

def configurar_logging():
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s %(levelname)s %(message)s",
        filename=ARQ_LOG,
        encoding="utf-8"
    )

def ler_csv(caminho_csv: str) -> list[dict]:
    linhas = []
    with open(caminho_csv, newline="", encoding="utf-8") as f:
        leitor = csv.DictReader(f)
        for row in leitor:
            linhas.append(row)
    logging.info(f"Lidas {len(linhas)} linhas do CSV.")
    return linhas

def limpar_nome(valor: str) -> str:
    return (valor or "").strip().title()

def limpar_email(valor: str) -> str:
    return (valor or "").strip().lower().replace(" ", "")

def limpar_cidade(valor: str) -> str:
    return (valor or "").strip().title()

def validar_idade(valor: str) -> int | None:
    try:
        idade = int(str(valor).strip())
        return idade if idade >= 0 else None
    except ValueError:
        return None

def limpar_validar_linha(row: dict) -> dict | None:
    nome = limpar_nome(row.get("nome"))
    email = limpar_email(row.get("email"))
    cidade = limpar_cidade(row.get("cidade"))
    idade = validar_idade(row.get("idade"))

    erros = []
    if not nome:
        erros.append("nome vazio")
    if not email or "@" not in email or "." not in email:
        erros.append("email inválido")
    if idade is None:
        erros.append("idade inválida")

    if erros:
        logging.warning(f"Linha descartada: {row} | Motivos: {', '.join(erros)}")
        return None

    return {"nome": nome, "email": email, "idade": idade, "cidade": cidade}

def processar_linhas(linhas: list[dict]) -> list[dict]:
    processadas = [limpar_validar_linha(r) for r in linhas]
    validas = [r for r in processadas if r is not None]
    logging.info(f"Registros válidos: {len(validas)} | Descartados: {len(linhas) - len(validas)}")
    return validas

def salvar_json(caminho_json: str, dados: list[dict]) -> None:
    with open(caminho_json, "w", encoding="utf-8") as f:
        json.dump(dados, f, ensure_ascii=False, indent=2)
    logging.info(f"JSON gerado: {caminho_json} | Registros: {len(dados)}")

def main():
    configurar_logging()
    logging.info("Início do pipeline CSV->JSON")
    if not Path(ARQ_CSV).exists():
        logging.error(f"Arquivo CSV não encontrado: {ARQ_CSV}")
        print(f"Erro: {ARQ_CSV} não encontrado.")
        return

    try:
        linhas = ler_csv(ARQ_CSV)
        validas = processar_linhas(linhas)
        salvar_json(ARQ_JSON, validas)
        print(f"Concluído. Registros válidos: {len(validas)}. Veja '{ARQ_JSON}' e '{ARQ_LOG}'.")
        logging.info("Pipeline finalizado com sucesso.")
    except Exception as e:
        print("Falha no pipeline. Verifique o log para detalhes.")
        logging.exception(f"Falha geral: {e}")

if __name__ == "__main__":
    main()
