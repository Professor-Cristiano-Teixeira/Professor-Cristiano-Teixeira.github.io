Capítulo 03 — Sistemas numéricos: decimal, binário e hexadecimal

Carga: 2h

Projeto-base: Lista guiada de conversões entre decimal, binário e hexadecimal

Stack fixa: Papel, calculadora básica, planilha ou Python opcional

Resultados de aprendizagem deste capítulo:

  • Explicar as diferenças entre bases numéricas 10, 2 e 16 e seus usos na TI.
  • Converter números entre decimal, binário e hexadecimal manualmente (método das divisões sucessivas e pesos).
  • Realizar conversões binário↔hexadecimal por agrupamento de bits.
  • Aplicar conversões para interpretar endereços, máscaras e representações de dados em manutenção e configuração.

Competências e Habilidades

  • MSI18 — Fundamentos de TI (compreensão de sistemas numéricos).
  • MSI0101 — Base conceitual para montagem/diagnóstico.
  • MSI1801/1802 — Interpretação de informações técnicas.
  • MSI1809 — Resolução de problemas com raciocínio lógico.

Plano de Aula (Capítulo 03)

Objetivo geral: converter entre bases decimal (10), binária (2) e hexadecimal (16) e reconhecer aplicações em TI.

Recursos: quadro, slides, calculadora, planilha ou Python (opcional), lista de exercícios.

Estratégia:

  1. Revisão rápida de unidade de informação (bit/byte) e motivação do uso de base 2 e 16.
  2. Exposição de teoria com exemplos graduais (decimal↔binário, binário↔hex, decimal↔hex).
  3. Prática guiada em sequência (passo a passo) com correção comentada e automonitoramento.

Avaliação formativa: participação, resolução da lista guiada e quiz ao final do capítulo.

Produto: folha de respostas de conversões com anotações dos métodos utilizados.

Parte Teórica (explicação do conteúdo)

1) Por que diferentes sistemas numéricos?

O computador opera com sinais elétricos que representam dois estados. Por isso, a base 2 (binário) é natural para o hardware. A base 10 (decimal) é a usada no dia a dia. Já a base 16 (hexadecimal) é conveniente na TI porque compacta 4 bits em 1 dígito, facilitando leitura de valores binários longos.

Onde vou aplicar isso? Ao ler endereços de memória, máscaras de rede, códigos de erro e valores de configuração que aparecem em binário/hex nos manuais ou ferramentas.

2) Sistema Decimal (base 10)

Utiliza dígitos de 0 a 9. Cada posição vale uma potência de 10: unidades (10^0), dezenas (10^1), centenas (10^2), etc. Ex.: 347 = 3×10^2 + 4×10^1 + 7×10^0.

Onde vou aplicar isso? Como referência para verificar resultados das conversões e interpretar capacidades e contagens em relatórios.

3) Sistema Binário (base 2)

Usa dígitos 0 e 1 (bits). As posições valem potências de 2: 1, 2, 4, 8, 16, 32, 64, 128... Ex.: 101101₂ = 1×32 + 0×16 + 1×8 + 1×4 + 0×2 + 1×1 = 45₁₀.

Onde vou aplicar isso? Para entender como dados e instruções são representados no nível mais baixo e para interpretar flags e máscaras.

4) Sistema Hexadecimal (base 16)

Usa dígitos 0–9 e letras A–F (A=10, B=11, ..., F=15). Cada posição vale potência de 16. Hex é muito usado em endereços, cores, dumps de memória. Ex.: 2F₁₆ = 2×16 + 15 = 47₁₀.

Onde vou aplicar isso? Em BIOS/UEFI, documentação técnica, depuração e identificação de valores de configuração.

5) Conversão decimal → binário (método das divisões sucessivas)

Divida o número por 2, anote o resto (0 ou 1) e continue dividindo o quociente até chegar a 0. O binário é a leitura dos restos de baixo para cima.

Ex.: 45₁₀ → divida por 2: 45/2=22 r1; 22/2=11 r0; 11/2=5 r1; 5/2=2 r1; 2/2=1 r0; 1/2=0 r1. Resultado: 101101₂.

Onde vou aplicar isso? Para montar rapidamente o binário de um valor decimal, útil em máscaras de rede e permissões representadas por bits.

Passos:
1) n ÷ 2 → quociente q, resto r
2) n = q e repetir
3) Ler restos de trás para frente

6) Conversão binário → decimal (soma de pesos)

Some os pesos (potências de 2) onde há 1. Ex.: 11001₂ = 1×16 + 1×8 + 0×4 + 0×2 + 1×1 = 25₁₀.

Onde vou aplicar isso? Para interpretar rapidamente o valor decimal de um conjunto de bits (ex.: opções ativadas por flags).

Pesos (da direita p/ esquerda): 1, 2, 4, 8, 16, 32, ...
Somar apenas onde o bit = 1.

7) Conversão binário ↔ hexadecimal (agrupamentos de 4 bits)

Aproxime 4 bits a 1 dígito hex. Da direita para a esquerda, agrupe em quartetos e converta cada bloco pelo valor decimal 0–15, mapeando 10–15 para A–F.

Ex.: 10110110₂ → 1011 0110 → B6₁₆. Inverso: 3A₁₆ → 0011 1010₂.

Onde vou aplicar isso? Leitura de dumps e endereços onde hex é padrão, mas o raciocínio em bits é necessário.

Tabela rápida (4 bits):
0000=0 0001=1 0010=2 0011=3
0100=4 0101=5 0110=6 0111=7
1000=8 1001=9 1010=A 1011=B
1100=C 1101=D 1110=E 1111=F

8) Conversão decimal ↔ hexadecimal

Decimal → hex: método das divisões sucessivas por 16 (anotar restos 0–15 e mapear 10–15 para A–F). Hex → decimal: soma de pesos de 16 (1, 16, 256, 4096...).

Ex.: 255₁₀ ÷16 → 15 r15 (F), 15 ÷16 → 0 r15 (F) → FF₁₆. Inverso: 2F₁₆ = 2×16 + 15×1 = 47₁₀.

Onde vou aplicar isso? Interpretação de códigos e endereços em documentação técnica.

9) Dicas de verificação e erros comuns

Use estimativas: 8 bits cabem até 255 em decimal; 16 bits até 65535. No binário, conte os 1s e verifique pesos. Em hex, dois dígitos hex equivalem a 1 byte (00 a FF).

Erros comuns: inverter ordem dos restos nas divisões, agrupar bits na direção errada e esquecer o mapeamento A–F.

Passo a Passo — Convertendo entre decimal, binário e hexadecimal

Objetivo desta etapa:

Aplicar, de forma guiada, os métodos de conversão estudados e validar resultados com ferramentas simples (planilha ou script opcional).


Etapa 1 — Decimal para binário (divisões por 2)

  1. Escolha um número decimal (ex.: 75).
  2. Divida por 2, anote o resto; repita com o quociente até zero.
  3. Leia os restos de baixo para cima.
75 ÷ 2 = 37 r1
37 ÷ 2 = 18 r1
18 ÷ 2 =  9 r0
 9 ÷ 2 =  4 r1
 4 ÷ 2 =  2 r0
 2 ÷ 2 =  1 r0
 1 ÷ 2 =  0 r1
Binário: 1001011₂
Verificação rápida: 1001011₂ = 64 + 8 + 2 + 1 = 75₁₀.

Etapa 2 — Binário para decimal (soma de pesos)

  1. Liste os pesos das posições (1, 2, 4, 8, 16, ...).
  2. Some apenas os pesos das posições com bit 1.
Exemplo: 11001010₂
Pesos: 128 64 32 16 8 4 2 1
Bits:    1   1  0  0 1 0 1 0
Soma: 128 + 64 + 8 + 2 = 202₁₀

Etapa 3 — Binário para hexadecimal (grupos de 4 bits)

  1. Agrupe em quartetos da direita para a esquerda (complete com zeros à esquerda se faltar).
  2. Converta cada quarteto para hex usando a tabela.
Binário: 0010 1111₂ → 2 F → 2F₁₆
Binário: 1011 0110₂ → B 6 → B6₁₆
Dica: 0001=1, 0010=2, 0100=4, 1000=8 (ajuda a somar).

Etapa 4 — Decimal para hexadecimal (divisões por 16)

  1. Divida por 16, anote os restos (0–15). Para 10–15, use A–F.
  2. Leia os restos de baixo para cima.
Exemplo: 202₁₀
202 ÷ 16 = 12 r10  → 12 (C), 10 (A)
12 ÷ 16  = 0  r12
Lendo restos: C A → CA₁₆
Verificação: CA₁₆ = 12×16 + 10 = 192 + 10 = 202₁₀.

Etapa 5 — Hexadecimal para binário (expandir 4 bits por dígito)

Converta cada dígito hex para seu equivalente em 4 bits.

Exemplo: 7D₁₆ → 7 = 0111; D = 1101 → 0111 1101₂

Etapa 6 — Automação opcional (Python)

Use um script simples para checar seus resultados. Não substitui o método manual: apenas valida.

# Validador simples de conversões
def dec_to_bin(n):
    return bin(n)[2:]

def dec_to_hex(n):
    return hex(n)[2:].upper()

def bin_to_dec(b):
    return int(b, 2)

def hex_to_dec(h):
    return int(h, 16)

# Exemplos
n = 202
print(n, "-> bin:", dec_to_bin(n), "-> hex:", dec_to_hex(n))
print("11001010 -> dec:", bin_to_dec("11001010"))
print("CA -> dec:", hex_to_dec("CA"))
Dica: Também é possível usar uma planilha com potências de 2 e 16 para somar pesos automaticamente.

Atividades Práticas para o(a) aluno(a) (desenvolver por conta própria)

Objetivo: consolidar a habilidade de converter entre bases e interpretar valores técnicos.

  1. Converta para binário: 29, 64, 127, 200, 255. Depois converta os resultados para hexadecimal.
  2. Converta para decimal: 101011₂, 11111111₂, 10000000₂, B3₁₆, FF₁₆, 7A₁₆.
  3. Explique, em 3–5 linhas, por que hex é preferido para representar bytes ao invés de binário longo.

Critérios de avaliação

  • Aplicação correta dos métodos (divisões sucessivas e soma de pesos).
  • Exatidão dos resultados e coerência na verificação.
  • Clareza na justificativa da escolha de hexadecimal.

  • Representação de cores em hex (HTML/CSS) e sua leitura em RGB.
